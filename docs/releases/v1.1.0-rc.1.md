# Quant Lab CN/HK v1.1.0-rc.1

2026-10-13（北京时间）。本次以预发布交付数据层、行情参考终端、Quant Academy 和研究存档升级。

## 改动

- 标准化 A 股/港股代码、Market Data Provider、来源、接收时间和历史缓存。
- 自选股支持最近历史日线收盘参考、5 分钟轮询、暂停和手动刷新。行情日期只有交易日，确切延迟未知。
- 八节可手算的课程与参数实验，学习/专业模式及指标知识入口。
- SQLite 保存研究假设、参数、成交假设、两份行情快照和笔记；支持复算及 Markdown/ZIP 导出。
- 补足费用、滑点、指标、缓存和归档测试；完善开发与发布规范。

## 验证与限制

- 本次干净提交构建已通过 45 项 pytest 测试。
- 本次打包离线浏览器检查通过了服务、夏普课程切换、自选股持久化、研究笔记及子进程清理。
- 隐藏式 WebView 探针未在 30 秒内收到页面加载完成事件；GUI 窗口完整加载尚未验证，因此标记预发布。
- 真实行情端到端以及本次安装/卸载尚未执行；当前快照不是盘中实时报价。
- 保持现有 pywebview、PyInstaller 与 Inno Setup 方式。需要 WebView2 Runtime；用户数据写入 `%LOCALAPPDATA%\QuantLabCNHK`。
