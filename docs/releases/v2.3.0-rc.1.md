# v2.3.0-rc.1 桌面研究与28课学习平台预发布

本版将此前源码升级首次汇入新版安装包：统一深色研究工作台、后台任务与等待反馈、长期历史/数据质量说明、A/H及美股价格成本研究、同币种多股票比较/组合和研究验证报告。

Quant Academy现有28节课程（包含原8节），按7个专题组织：Python金融数据基础、收益与数据、风险与统计、策略与成交、研究验证、组合和综合研究。课程均使用可离线运行的固定教学样本，提供公式手算、参数实验、代码说明及思考题答案；保留85篇专业文章。先修课程可以连续跳转并逐层返回，恢复来源专题、搜索和滑块值。

首次启动默认市场数据，手册默认关闭；保留原有资料目录、凭据标识、安装AppId与旧档兼容。SQLite迁移仍升级前备份并事务执行，不重写旧行情快照。Key仅使用会话或Windows凭据管理器，不写入安装包、普通设置、数据库、日志或导出。

## 使用与已知限制

- 需要Windows x64及Microsoft Edge WebView2 Runtime；安装包未作商业代码签名。
- 本版是预发布。历史日线研究与模拟结果不是实时行情，不提供实盘下单；教学样本不代表真实股票业绩。
- 当前A/H及美股价格/成本模型不保证完整公司行动、分红现金账本或结算模拟；严格美股现金教学模型独立保留。来源异常、缺失成交日等关卡仍阻断受影响研究。
- 当前真实来源完整行情留存许可仍有限制；会话计算、摘要导出不等于完整离线实验快照。旧存档和明确获准的教学报告保留复算路径。
- 中文公式可能产生KaTeX兼容性警告，内容可见；既有日历依赖弃用警告和正式性能未达项不因本次打包自动通过。
- 只做发行所需核心测试和隔离安装/实际WebView2关键流程；本次不重做完整真实行情、付费DeepSeek或P95专项。
