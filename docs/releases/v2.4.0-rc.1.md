# v2.4.0-rc.1 内置WebView2与研究流程预发布

本版包含Microsoft WebView2 Fixed Version x64运行时157.0.4341.42。安装软件后无需另装WebView2或Python；应用固定使用自己的浏览器目录，不查找系统WebView2，也不会在缺失时静默回退。运行时损坏时请重新安装完整安装包。

新增三市场单股交易回放/结果解释与最大回撤定位、最多20只同市场候选的批量条件选股/方案保存，以及第13–24课直达真实研究。内置手册补齐上述入口、参数和边界，学院目录修正为28课。桌面面板动效、宽度同步和Ctrl＋滚轮缩放也包含在本版。

## 安装与边界

- Windows x64桌面安装包；系统仍须有正常的.NET Framework/桌面组件（pywebview后端需要），无需开发工具、Git、Python或本地大模型。
- WebView2随软件部署，启动时不联网下载、不安装系统级浏览器或更新器；固定版本安全更新需要后续软件更新。包含原微软运行时文件，来源、CAB及逐文件SHA-256见运行时清单。安装目录须为本地目录，不支持网络共享路径。
- 安装器按微软分发说明给运行时目录配置ALL APPLICATION PACKAGES和ALL RESTRICTED APPLICATION PACKAGES的只读/执行权限，供Windows 10的AppContainer渲染器使用。应用资料、缓存、浏览器用户资料及凭据仍位于用户资料目录，安装目录只读。
- 预发布、未商业签名；旧安装AppId和用户资料兼容。新安装包体积会因自带浏览器增大，旧版本附件不覆盖。
- 真实行情需联网；课程和手册离线可用，DeepSeek Key仅使用AI时需要。历史日线不是实时行情，不提供实盘下单。
- 不扩大既有来源、留存、公司行动、分红现金账本或结算资格，不把旧阶段用户验收/性能未达项自动标为通过。

## 构建与验证

从干净提交运行build_windows.ps1 -BuildInstaller，执行一次完整pytest。构建记录包括源码提交、版本、运行时清单、文件大小和SHA-256；隔离安装验证使用独立AppId/资料目录，不读取真实用户凭据或注入API。

公开前先创建草稿，上传版本化安装器、SHA256SUMS、build-manifest、validation与运行时来源清单，核对远程大小/哈希后公开预发布。实际测试与发行结果见同版本回执；不宣称未实测Windows版本或无系统运行时的干净虚拟机已验收。

官方运行时分发依据：https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution 。
