# v2.0.1-rc.1 界面整合预发布

DeepSeek 配置迁入 AI 研究助手页面，研究与问答共享连接；股票代码输入与候选搜索合为一个控件，保留代码/名称搜索、原候选排序及手输代码。

本版不更改数据库 schema 或数据指纹。会话密钥不会因跨页丢失，知识与课程追问只准备草稿、由明确发送触发模型请求。

构建命令：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build_windows.ps1 -BuildInstaller`。构建源码提交、时间、大小与 SHA-256 保存于同名 build JSON；验证和发布回执在验收后归档。

真实付费 DeepSeek 与完整联网历史回测不在本次自动验收范围，保持预发布；模拟 API 仅用于隔离安装副本，不进入发行包。
