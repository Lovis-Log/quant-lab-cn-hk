# v2.1.0-rc.1 研究笔记工作台预发布

本版新增可持久化的研究笔记资料库，并把研究笔记、新手指引和 DeepSeek 整合为三个可同时打开、调宽、排序及应用内最大化的工作台面板。全局顶栏新增设置和左侧导航栏开关，面板标题与操作在长内容滚动时保持可见。

首次启动会要求选择资料库父目录，并在其中创建结构化 `QuantLabCNHK` 目录。旧数据库只有在一致性复制并校验后才切换，原目录保留。SQLite schema 升级到 v4，新增层级分类、自动草稿、统一笔记/实验归档、回收站和托管附件；旧行情快照不会因迁移被替换。

DeepSeek Key 仍只保存在当前会话或 Windows 凭据管理器，不写入普通设置、SQLite、日志或导出。模型请求仍须用户明确发送；真实付费 DeepSeek 和完整联网历史回测不在自动验收范围，因此本版标记为预发布。

发布构建从干净提交执行完整 pytest、Windows 安装包构建、打包离线浏览器检查及独立用户目录下的实际 WebView DOM 检查。构建记录、SHA-256、详细验证结果和发布回执在发布完成后归档到本目录。

安装包需要 Windows WebView2 Runtime。正常卸载不会删除用户选择的资料库和研究数据。
