# v2.2.0-rc.1 文字手册与研究工作台预发布

本版提供离线使用手册与专业文章检索，改进研究笔记的渲染阅读、分类搜索、附件打开与另存副本，并将 DeepSeek 对话保存为可搜索的本地历史会话。输入框支持 Enter 发送、Shift+Enter 换行；流式回答遇到可恢复中断时保留已有文本并有限续答。

首次启动仍使用独立的用户资料库。SQLite schema v5 在升级前创建一致性备份，保留旧笔记、实验和行情快照。DeepSeek Key 只在会话或 Windows 凭据管理器中；聊天历史不保存 Key、思考过程、私人笔记或完整行情。

本版按预发布交付。安装包需要 Microsoft Edge WebView2 Runtime，未进行商业代码签名；软件提供历史日线研究与模拟回测，不提供实时行情或实盘交易。自动验收使用隔离资料目录和模拟 API；真实付费 DeepSeek 请求、完整联网行情、Windows 默认应用实际启动不计作自动通过。

本地浏览器运行：在仓库根目录安装 `requirements.txt` 后，执行 `./.venv/Scripts/python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501`，访问 `http://127.0.0.1:8501`。完整 PowerShell 命令和端口冲突处理见 README。

## 发布

GitHub API 上传大安装包时发生 TLS EOF，草稿保持未发布；随后以系统 `curl` 的 HTTP/1.1 将相同安装包上传到草稿。`tools/publish_release.py` 复核安装包并上传校验文件、构建记录与验收摘要，逐项核对远端大小和 SHA-256 后公开预发布版。

发布地址：[v2.2.0-rc.1](https://github.com/Lovis-Log/quant-lab-cn-hk/releases/tag/v2.2.0-rc.1)。归档文件：[构建记录](v2.2.0-rc.1-build.json)、[验证摘要](v2.2.0-rc.1-validation.json)、[发布回执](v2.2.0-rc.1-receipt.json)和 [SHA-256](v2.2.0-rc.1-SHA256SUMS.txt)。详细构建日志保存在本地 `dist/release/2.2.0-rc.1/build.log`。
