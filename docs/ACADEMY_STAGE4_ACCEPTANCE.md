## 用户验收清单

在仓库根目录运行 `.\.venv\Scripts\python.exe desktop_launcher.py`，使用源码桌面版：

1. 启动仍进入市场数据，点击Quant Academy，检查7个专题共28节；新会话默认第01课。
2. 从Python基础开始阅读，搜索“回撤”，切专题与前后课；点击先修建议能跳转，其他课程不锁定。
3. 调整第04/15/16课参数，核对信号时点、下一开盘和费用/整单位未成交说明；按需展开代码和答案。
4. 查看第23课现金/持仓/费用，再看第28课完整教学报告及复算一致；确认教学实验标识与当前生产模型的局限。
