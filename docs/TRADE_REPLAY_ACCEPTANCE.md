# 三市场交易回放操作与验收

范围：工作单41，源码功能；不更新现有安装版，不改变价格模型、来源或用户阶段验收资格。

## 操作

1. 选择A股、港股或美股，加载符合原资格的历史数据，进入研究工作台的“历史回测”，明确运行回测。
2. 在“交易回放”展开“选择订单”并点击一行，或使用上一笔/下一笔、交易日定位。首笔含未成交尝试，无订单时从首日开始。
3. 核对现金、持仓、收盘权益和当日盈亏。原始价K线默认显示选中日前后各20个交易日，边界截断；买卖成交按实际成交价标记，未成交叉号标在原始开盘价。
4. 前一日信号价、均线和目标单独显示，信号图保留其复权口径；成交与估值使用原始价。逐笔费用与原订单核对，滑点仅拆解一次。
5. 点击“定位最大回撤”，查看峰值、谷值、恢复日期或尚未恢复，净值高亮峰谷下跌区间，下方列区间订单与最多5个主要亏损日。
6. 同一实验切页后恢复日期，换股票/参数/查询或实验重置。失败保留结果时回放显示旧结果状态。此区间无回撤则禁用回撤定位并显示说明。
