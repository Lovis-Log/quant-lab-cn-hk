# 阶段七研究验证协议与兼容

日期2026-10-29；范围29–30。验证`research-validation-v1`，执行`ah-single-v1`，规则`ah-research-assumptions-v1`，指纹`validation-manifest-sha256-v1`，数据`ohlcv-snapshot-v1`，报告`quantlab-validation-report-v1`。这些是研究假设/实现版本，不是交易所全部规则或数据授权认证。

## 输入与成本诊断

新验证只用已配对不复权价格生成信号，避免研究终点复权水平影响选参。原显示口径与配对过程保留在输入清单，实际报告原始/信号CSV均为不复权。真实来源要有接收时点、已结束日线及实际范围内完整参考交易日；不跳过缺失成交日，不填可成交价格。原始价格绝对日变动≥40%时暂停研究、要求核对，不据此断言事件原因；低于阈值不等于事件已验证。

AH执行模型保留旧代码，收盘信号最早下一开盘成交、只做多/无杠杆、用户交易单位、零量与简化涨跌停均为原研究假设。没有重建A/H分红、送转或拆并；报告明确company_actions=unverified-not-modelled，不能把缺记录当无事件。真实美股继续受阶段五关卡约束，不送入AH验证。

诊断由实际本地成交/净值计算：佣金=max(最低佣金,成交金额×佣金基点/10000)，附加费按买卖方向基点；两者合计核对原订单fees。滑点估计=股数×|成交价-原始开盘价|，另列、不再次扣费。累计换手指标=累计双边成交金额/平均日权益，未年化、未除2。每日暴露=持仓股数×原始收盘价/权益，列平均/最大暴露及逐日快照。未成交按尝试订单原因计数，不声称复原交易所订单簿。

## 参数扫描、滚动与压力

- 最多36个有效参数元组、8折、10000输入行、200万预计行次。初始最大交易单位超过100万亦拒绝，以限制旧执行循环成本；仍使用可取消/超时的独立计算进程，长任务不占UI线程。
- 候选短/长周期2–250、短小于长；非法配对数量显示，不填结果。目标可选训练累计收益或训练夏普；同分按短、长周期升序。夏普全部无定义时拒绝该目标，不改用其他指标。单均线中短周期不影响信号，多组元组未必是独立经济假设。
- 固定扫描只看前缀训练比例。滚动验证独立地在每折测试开始前的固定训练窗口重新选参，采用最近最多N折；尾部不足5条不测试，实际覆盖/未覆盖数量明确记录。固定扫描和滚动覆盖可重叠，但滚动不使用固定扫描的获胜参数；各自测试期不参与各自选参。
- 已结束的前折测试观察可进入下一折训练，这是滚动定义；当前折未来测试不能进入当前训练。信号仅在此前收盘可得，下一开盘执行。跨折只运行一条连续现金/持仓路径，不免费清仓或重置资金；逐折收益来自这条连续路径对应区间。
- 成本压力最多6个0–10倍情景且包含1倍，固定基础策略，佣金、最低佣金、买卖附加费与滑点一起缩放，不重新选参。失败情景明确写失败/原因及空收益，不补0。数量取整及资金约束会改变成交，不保证收益随费用单调变化。

基础策略全样本结果、固定训练扫描、连续滚动样本外是不同对象。对比架当前比较固定基础策略，不能把基础收益当滚动收益。多次查看测试结果再改网格/窗口仍会过拟合，协议不能消除数据修订、身份或幸存者偏差。

## 2–6实验比较与AI边界

会话对比架保留最近6次实验，不自动落盘；保存的基础实验可从存档选择2–6个，先本地复算后取数值，不信任旧metrics直接作为新事实。回收站条目不进入默认选择；被淘汰/删除的选择会清理，失败时旧结果明确标为上次成功。

市场、代码、币种、日期范围、原始/信号快照或执行/规则版本、初始资金不同则不绘统一净值对比，表格标不可直接比。全样本条件相同但样本外切分不同，单独标记样本外列不可直接比。参数、费用和假设差异完整列出，不能仅归因为信号。不同币种不加总；教学/模拟输入明确标记。

AI仅能在用户明确发送后读取白名单中的当地计算摘要（收益/费用/折数或不含标题的比较事实），按实验指纹隔离。默认不附私人笔记、完整行情或数据库；没有新增自动付费请求或执行AI代码。

## 存档、ZIP和版本

使用SQLite v6已有input_manifest_json存新增版本/验证配方，未迁移schema、不重写原始BLOB和旧audit。新的UI保存显式声明原执行/规则/指纹版本；无声明旧档保持标识并走保留的兼容算法。未知/空的显式版本拒绝复算，原记录可读。

旧数据库记录复算先核对旧CSV/配置指纹；有历史机器输出时，再比统计与成交记录（数值容差1e-10），允许未成交价格合法None/NaN。不同则报错、不把当前算法输出写回原档。新导出的旧格式4成员ZIP也附机器输出；更早ZIP若没有机器输出，只能核对输入与重新计算，不声称已核对全部当时输出。

新验证ZIP含完整原始CSV、相同不复权信号CSV、来源/接收/质量/配对清单、公司行动未知状态、规则/算法/数据/指纹版本、全部参数和扫描/折/压力/成交/暴露输出。只有留存许可通过的输入才能创建完整报告/新存档；未许可真实源仍可会话计算和对比，旧档阅读/复算保留。

ZIP读取固定成员、不extractall、不执行代码/pickle，大小与解压总量≤50MB。新报告核对全部文件SHA，重算输入指纹、所有数值CSV/诊断和版本化report.md文本。格式v1文本亦属于兼容契约；未来改算法、规则或文本格式要另立版本并保留旧路由，不能直接改旧实现。

离线入口：`python -m quant_lab.research_reports report.zip`，兼容新验证ZIP与旧4成员实验ZIP。没有联网；不从文件提供的路径执行程序。对应源码/依赖环境若无法复现会拒绝匹配，不能把结果差异覆盖成成功。工作区预设仍只有原白名单，验证配方以报告或验证存档为准。

界面入口在“存档实验比较 → 完整验证配方离线复算”，显式选取一个验证存档后重跑扫描/滚动/压力并核对原验证指纹，不改旧记录、不重新取价。普通旧基础档没有该配方时明确提示，基础复算功能仍保留。失败不会保留绿色本次成功提示。
