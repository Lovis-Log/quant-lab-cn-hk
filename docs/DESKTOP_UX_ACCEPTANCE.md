# 桌面体验专项验收（2026-11-07）

保持现有深色外观与四栏横向工作区，采用 Desktop Agent UI 的适用规范。用户技能安装于 `skills/desktop-agent-ui`，来源 [Ludi-Herry/desktop-agent-ui](https://github.com/Ludi-Herry/desktop-agent-ui)，固定提交 `5ee4fea59c279965e1a6b4b967d23d302a583dcc`。入口、6份参考文档及裁切脚本完整；技能不作为软件运行依赖，不把上游所有审美规则设为本项目硬门槛。

## 交付行为

- 面板边界拖宽、顶栏拖动排序支持 Esc 撤销；取消、失焦及节点移除回滚并清理监听，取消预览不写入 localStorage。左右方向键按24px微调宽度，边界具有焦点提示。
- AI 输入保持 Enter 发送、Shift＋Enter 换行，92–240px随内容增高，超长内容内部滚动。组合输入和keyCode229不触发发送；组合结束只保护当前事件轮次，不增加固定500ms输入屏蔽。控件重建时重新绑定，不叠加旧监听。
- 消息区在距底部80px以内跟随，回溯阅读保持位置，点击“回到最新回复”恢复。首次会话落库沿用阅读键，普通重绘保持位置；状态只在前端内存保留，最多32个阅读键。
- 服务端保持单一待处理请求，busy与最多64个已消费请求ID阻止重复事件。界面变化、切页、切会话不自动调用模型；主动新问题仍可再次发送相同内容。
- 取消I/O任务明确为“已取消本次结果接收”，不声称撤回HTTP；最近有效数据不被晚到结果覆盖。无正文但携带error的模型失败也明确显示，普通重绘不重发。
- 自有辅助文字至少12px，保留等宽数字、原配色、必要金融与付费提示；精简研究助手重复说明。无计算API、数据库、金融模型、工作区格式、依赖或启动器变更。

## 保留的失败与限制

设置页签定位遗漏、自适应绑定失效、失败模拟匹配条件、空回复错误未显示及恢复请求计数假设均有失败记录，修正后仅补相应检查。第一次两尺寸验收的后续失败不能称为整段通过，采用记录中分段证据交付。

真实 Windows 输入法候选窗尚未人工验证；已通过的是实际WebView内的组合输入事件序列、keyCode229及正常键盘操作，不能替代系统级输入法兼容性承诺。未重做真实行情、付费DeepSeek、性能专项或全部课程验收；既有来源和阶段用户验收状态不变。

仅源码交付；现有安装版未更新，不打包、标签或Release。开发验证不等于用户最终验收。

## 复查入口

`.\.venv\Scripts\python.exe tools/verify_desktop_ux.py` 运行相关桌面检查；`--completion-only`、`--reading-only`、`--lifecycle-only` 分别用于失败反馈、阅读位置和节点生命周期定向补验。需已安装本次skill的审计脚本及既有桌面测试依赖；脚本只在 `.tools` 隔离副本注入模拟接口。
