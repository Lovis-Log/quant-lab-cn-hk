# 阶段六模型与交付边界

版本：`ah-cash-price-v1`；日期2026-10-28。本轮范围仅工作包26–28。原`PortfolioAnalysis`、单股回测、US模型、SQLite v6及旧档不重写。本版本是A/H同币种**价格与成本**研究，不包含现金分红、送转/拆并股份或汇兑，不能称为含分红总回报或券商实际执行。

## 比较输入与指标

市场必须同为A股或港股，代码经normalize_symbol后2–10只且不重复，币种分别CNY/HKD；格式不是证券身份认证。名称由现有基础信息服务后台获取，失败只显示名称不可用。每批最多两个取数工作者，同查询继续使用已有RefreshCache合并；立即更新传force=True，失败不向UI交付部分成功或把旧缓存混入新批次。

逐股显示请求/实际区间、条数、共同条数、排除条数、来源、接收时间、质量和缓存状态。比较对全部股票交易日期取交集，不补价格；排除记录如实显示。标准化曲线=当前价/共同起点价×100；相对基准收益=(股票期末标准化值/所选基准期末标准化值)-1，不是简单百分点相减。基准由用户指定，留空明确使用首只股票，不伪造市场指数。

回撤=价格/此前价格最高点-1。共同观测间隔收益用于相关性与样本波动（ddof=1），年化按252近似；滚动波动使用指定数量的间隔收益。共同缺口可能跨多个交易日，所以这种年化是观测近似；不能把缺口当停牌。零波动相关性和窗口不足留空，不填0。全部计算和图表使用完整数据；超过1000行使用Scattergl绘制，不对计算、表格或输入抽样。

## 现金组合与样本外

比较可以展示交集；现金模型则要求共同起止范围内各股原始交易日期严格一致。真实来源还要匹配已配置参考日历，不能以删交易日、取交集或前值填充继续成交。未收市、结构失败、日期缺口、失败旧缓存不进入新成交输入。复权比较时沿用阶段三的复权前检/原始价/复权后检，发生历史修订或源身份变化拒绝混用。

现金模型的权重训练始终用**不复权价格收益**，避免把研究终点才知道的复权水平/后续修订因子用于训练。比较图仍按用户所选价格口径显示，两者不必相同。当前历史原始价的修订、身份和幸存者偏差没有因此消除。

按比例时间切分：训练区间至少4条，样本外至少2条。训练区间收益估计固定等权与逆样本标准差权重；测试期不参与估计。零波动时逆波动率明确不可计算，等权仍可运行，不静默替代。样本外以最后训练日为现金初始点，最早在样本外首日开盘买入。等权是同成本基准，不是额外抓取的市场指数。

每日调仓或月末收盘决定调仓，下一观测交易日正常开盘尝试。买入单位逐股明确输入；数量按单位取整，允许留现金。资金不足时按各买单所需成本比例分配当前现金，再求满足费用约束的整数单位，不按代码顺序优先耗尽资金。未成交/部分成交原因保留；只在后续调仓日期再次计算，不假称必然成交。

佣金、最低佣金、买卖附加费和单边滑点为研究参数，不是现行法定或券商费率。A股简化涨跌停可关闭或设比例，零成交量不成交。日线模型每个交易日只处理一个正常开盘，不产生当日买入又当日卖出的日内循环。卖出净额假设当日可用于再投资，不模拟取款/资金清算；不能将此假设用于美股，US继续走独立结算模型和来源关卡。

本版不重建A/H公司行动；原始价绝对日变化≥40%时拒绝现金模型、提示核对或缩短区间，不直接断言原因。低于该阈值不代表公司行动已经验证。原始价成交/估值，现金和费用核心用Decimal；界面与统计转float，分项显示可能有极小浮点误差。总权益=现金+逐股持仓市值，费用在成交时扣减。指纹绑定全量原始CSV、配置、训练权重、配对输入、参考日历版本及训练终点，不修改旧算法。

## 观察列表与预设

观察列表仍是最近**已结束历史日线收盘参考**，增加来源区间质量及更新状态，保留原成功获取时间。比较页显式打开观察列表后，按已有自动刷新开关和5/10/15分钟间隔运行；关闭时不额外轮询。失败保留旧参考和质量，不把读取/重绘当新获取。各币种分别列示，不相加。

学习/单股/多股预设保存白名单参数、导航、侧栏和面板开关到当前资料库的workspace-presets.json，版本1、原子替换；不含行情、笔记、AI内容或密钥。损坏/未知版本报错且保留原文件。只保存已经提交到服务端的参数，未提交表单不会自动取数。预设按资料库隔离；现有拖宽和顺序沿用当前WebView设置，本轮不承诺跨随机端口恢复拖宽，也不引入复杂拖拽。

本环境真实港股并发曾触发py_mini_racer原生初始化崩溃。Sina历史解码入口现使用同进程共享锁（覆盖港股回退及US诊断），串行后真实港股复核通过；没有把崩溃当网络失败后静默回退。普通HTTP历史收集仍最多2个并发，UI不被持锁请求占用。

真实源留存策略沿用阶段三：没有新增自动行情归档或绕过许可的导出。完整研究快照/实验扫描属于后续关卡；当前不启动阶段七。验收证据见[TERMINAL_STAGE6_ACCEPTANCE](TERMINAL_STAGE6_ACCEPTANCE.md)。
