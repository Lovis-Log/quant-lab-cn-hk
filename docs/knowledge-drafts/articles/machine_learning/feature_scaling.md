# 特征标准化（Feature Scaling）

## 快速理解

### 一句话解释

特征标准化把每个特征减去训练集均值、再除以训练集标准差，使不同量纲的特征可以放在同一尺度上比较；Quant Lab 只在训练集拟合 `StandardScaler`，再把它应用到测试集。

### 它解决什么问题

五个特征的量纲差异很大：收益率是小数，成交量变化率可能很大，均线比值减 1 又是另一种尺度。标准化让线性回归的系数更容易比较，也避免数值优化和正则化被大量纲特征主导。更重要的是，它提供了一个明确的“只用训练信息”的预处理边界。

### 最常见的误解

- **“标准化会改变模型预测”**：对带截距的普通最小二乘，特征线性变换通常不改变拟合值；但系数会改变，正则化、距离和数值优化会受影响。
- **“可以用全部数据拟合标准化”**：那会把测试集信息带入预处理，造成数据泄漏。
- **“标准化让特征变成正态分布”**：它只改变均值和尺度，不改变分布形状；厚尾和偏斜仍然存在。
- **“标准化后所有特征一样重要”**：它只统一尺度，不消除相关性、噪声或因果方向。
- **“StandardScaler 用样本标准差”**：scikit-learn 默认使用训练列的总体口径标准差（分母 `n`），不是 pandas 的 `n−1` 样本标准差。
- **“零方差特征会报错”**：`StandardScaler` 会把零方差列的尺度设为 1，变换结果为 0；软件当前没有单独提示。

## 软件实践

### 在 Quant Lab 哪里出现

- 机器学习页使用 `Pipeline(StandardScaler(), LinearRegression())`。
- 标准化只在训练集 `train` 上拟合，再应用到测试集 `test`。
- 训练期交叉验证的每一折都新建 Pipeline，避免先对完整训练集标准化再切折。
- 页面显示“标准化特征系数表”；系数对应标准化后的特征。
- 页面说明强调：标准化只在训练集拟合，并在训练/测试边界留出一日间隔。

### 输入、输出和单位

- 输入：五个特征 `return_1`、`return_5`、`ma_gap_5_20`、`volume_change`、`volatility_10`。
- 训练集拟合：每个特征的训练均值和训练标准差。
- 变换：`z = (x − 训练均值)/训练标准差`。
- 输出：标准化后的特征，均值约为 0、标准差约为 1（在训练集上）。
- 单位：标准化后无量纲；原始特征仍有各自单位（收益率小数、变化率小数等）。
- 系数单位：对标准化特征 `z_j`，在其他特征不变的条件下，`z_j` 增加 1 个单位（即原特征增加一个训练集标准差）时，预测的 `next_return` 改变 `β_j`；`β_j` 的单位是目标收益率单位（日收益率小数），不是“目标变量每变化一个单位对应的特征变化”。

### 结果应该怎么读

- 标准化系数的大小可以横向比较，但仍受特征相关性和样本影响。
- 系数为正表示训练期内该特征与下一日收益正相关；不表示因果。
- 系数接近 0 不表示特征无用；可能与其他特征共线，或被训练区间噪声掩盖。
- 标准化不改变特征的排序，也不消除极端值；厚尾特征仍可能影响回归。
- 训练集和测试集的分布可能不同；标准化不能修正分布漂移。
- 零方差特征变换后为 0，系数可能无定义或不稳定；当前软件没有单独提示。

### 当前软件边界

- 只用 `StandardScaler`；没有 MinMaxScaler、RobustScaler、分位数变换或归一化选项。
- 只在训练集拟合；测试集使用训练均值和标准差。
- 交叉验证每折单独拟合；没有把完整训练集标准化后再切折。
- 不提供标准化参数的表格、导出或逆变换。
- 不处理缺失值；缺失行在特征生成阶段已删除。
- 不做异常值截尾、缩尾或稳健标准化。
- 不调整特征分布；标准化不改变偏度和峰度。
- 不把标准化系数自动解释为因果效应。

## 专业原理

### 正式定义

对特征 `x`，训练集均值为 `μ_train`，训练集标准差为 `σ_train`，标准化为：

`z = (x − μ_train)/σ_train`

`StandardScaler` 对每一列独立计算 `mean_` 和 `scale_`，然后变换训练集和测试集。scikit-learn 默认的 `scale_` 使用总体口径标准差（分母 `n`）；pandas 的 `std()` 默认使用样本口径（分母 `n−1`），两者数值略有不同。

### 公式与符号

- `x`：原始特征值；
- `μ_train`：训练集该特征均值；
- `σ_train`：训练集该特征标准差（`StandardScaler` 默认总体口径）；
- `z`：标准化后的特征；
- `n`：训练样本数。

含标准化的线性模型：

`ŷ = β_0 + Σ_j β_j z_j`

其中 `β_j` 是标准化特征系数。

### 可手算的小例子

训练特征 `[1, 2, 3]`。

训练均值：

`μ_train = (1 + 2 + 3)/3 = 2`

训练标准差（总体口径，分母 3）：

`σ_train = √[((1−2)² + (2−2)² + (3−2)²)/3]`

`= √[(1 + 0 + 1)/3] = √(2/3) ≈ 0.816497`

标准化训练值：

- `(1−2)/0.816497 ≈ −1.224745`
- `(2−2)/0.816497 = 0`
- `(3−2)/0.816497 ≈ 1.224745`

测试值 `4` 使用训练参数：

`(4−2)/0.816497 ≈ 2.449490`

如果误用样本标准差（分母 `n−1=2`）：

`σ_sample = √[(1+0+1)/2] = 1`

训练值会变成 `[−1, 0, 1]`，测试值变成 `2`。两种口径都能标准化，但数值不同；软件使用 `StandardScaler` 的默认口径。

**零方差例子：** 训练特征 `[5, 5, 5]` 的均值为 5、标准差为 0；`StandardScaler` 把尺度设为 1，变换结果为 `[0, 0, 0]`。这个特征没有变化，回归无法从中学习，但软件不会因此报错。

### 前提假设

- 训练集能代表测试集的均值和尺度；分布漂移会削弱标准化的意义。
- 特征在训练集和测试集使用同一变换；测试集不参与拟合。
- 特征数值有限；缺失值和无限值已在前面处理。
- 标准化不改变特征之间的线性关系，只改变尺度和截距。
- 零方差特征不会提供信息；软件不会自动删除。
- 标准化系数只描述训练期线性关联，不是因果效应。

### 边界情况

- 零方差特征：尺度设为 1，变换为 0；系数可能不稳定。
- 极端值：均值和标准差被拉动，标准化后的正常值可能被压缩。
- 厚尾/偏斜：标准化不改变分布形状；对异常值仍敏感。
- 训练/测试分布漂移：测试值可能远超训练范围，标准化后出现很大的 z 值。
- 小训练集：均值和标准差估计不稳定。
- 特征共线性：标准化不能消除共线性，系数仍可能不稳定。
- 缺失值：当前在特征生成阶段删除；标准化本身不处理缺失。
- 特征选择：标准化应放在 Pipeline 内，避免用测试数据选特征。
- 正则化/距离模型：标准化影响惩罚和距离；线性回归无正则时预测对尺度不敏感，但系数解释会变。
