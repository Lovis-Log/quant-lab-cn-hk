# 预测基线（Prediction Baseline）

## 快速理解

### 一句话解释

预测基线是一个不使用复杂模型的简单预测；Quant Lab 当前用“每天都预测 0 收益”作为基线，模型只有在样本外误差低于这个基线时，才说明它在平均误差上优于“什么都不预测”。

### 它解决什么问题

模型很容易在样本内拟合噪声。基线提供一个最低门槛：如果复杂模型连“每天预测 0”都不如，就没有证据说明它学到了可用的关系。基线也帮助研究者把“模型误差”放在可解释的尺度上。

### 最常见的误解

- **“基线太简单，没有比较价值”**：简单基线正是用来检验模型是否真的有增量价值。
- **“超过零收益基线就能盈利”**：MAE 更低不等于扣除费用、滑点后能赚钱，也不等于方向判断正确。
- **“零收益基线总是最优基线”**：如果样本平均收益明显不为 0，历史均值基线可能更强；当前软件没有计算。
- **“基线就是随机森林或复杂模型”**：当前只实现零收益基线，不是机器学习模型集合。
- **“R² 的参考也是 0”**：sklearn 的 R² 使用测试集实际值的均值作参考，不是 0；这与零收益 MAE 基线不同。
- **“基线 MAE 越低越好”**：基线误差取决于测试区间的收益幅度；不同区间、不同资产的基线不能直接比较。

## 软件实践

### 在 Quant Lab 哪里出现

- “统计与机器学习”页的“零收益基线 MAE”指标卡。
- 页面把“样本外 MAE”和“零收益基线 MAE”并列显示。
- 若模型 MAE 小于基线，页面显示信息提示；否则显示警告“预测误差尚未优于每天预测 0”。
- 基线只用于评价，不参与训练、不生成交易信号。
- 页面同时显示 R² 和方向一致率，帮助补充 MAE 之外的信息。

### 输入、输出和单位

- 输入：测试集的真实下一日收益率 `y_t`；模型预测 `ŷ_t`。
- 零收益基线预测：`ŷ_t^0 = 0`（对所有 t）。
- 基线 MAE：

`baseline_MAE = (1/n)Σ|y_t − 0| = (1/n)Σ|y_t|`

- 输出：基线 MAE 和模型 MAE，单位都是收益率误差（小数或百分比）。
- 例如基线 MAE `0.02` 表示平均绝对误差 2 个百分点，不是 2 元。

### 结果应该怎么读

- 先比较模型 MAE 和基线 MAE；模型更低，说明在该测试区间的平均绝对误差更小。
- 但 MAE 更低不代表方向判断更准、R² 为正或策略能盈利。
- 基线 MAE 受测试区间收益幅度影响；波动大的区间基线 MAE 通常更大。
- 如果测试集实际收益均值明显不为 0，零收益基线会偏向“预测 0”，可能不是最强基线。
- 基线没有使用特征；它的存在是为了防止“模型看起来很复杂，但不如简单规则”。
- 换区间、换资产后要重新比较；不能只汇报模型胜过基线的区间。

### 当前软件边界

- 只实现“恒预测 0 收益”的基线；没有历史均值基线、随机游走价格基线、买入持有基线或随机森林基线。
- 基线只用于 MAE 比较；不用于训练、调参或模型选择。
- 不提供基线的 R²、方向一致率或交易回测。
- 不校正交易成本、滑点、税费或可成交性。
- 不处理测试集分布漂移或非平稳。
- 不自动判断模型是否“有价值”；只显示 MAE 比较提示。
- 不把基线比较转成投资建议或收益预测。

## 专业原理

### 正式定义

设测试集有 `n` 个真实收益 `y_1,...,y_n`。零收益基线的预测为 `ŷ_t^0 = 0`，其平均绝对误差为：

`MAE_0 = (1/n)Σ|y_t|`

模型 `f` 的样本外平均绝对误差为：

`MAE_model = (1/n)Σ|y_t − f(x_t)|`

模型在该测试区间优于零收益基线，当且仅当：

`MAE_model < MAE_0`

更一般的基线可以是训练期均值 `ȳ_train`、随机游走价格或历史中位数；当前软件只使用 0。

### 公式与符号

- `y_t`：测试集第 t 个真实下一日收益率；
- `f(x_t)`：模型预测；
- `ŷ_t^0 = 0`：零收益基线预测；
- `n`：测试样本数；
- `MAE_0`：零收益基线 MAE；
- `MAE_model`：模型 MAE。

### 可手算的小例子

测试集实际下一日收益：

`[2%, −1%, 3%, −2%]`

**零收益基线：**

预测 `[0%, 0%, 0%, 0%]`

绝对误差：

`[2%, 1%, 3%, 2%]`

`MAE_0 = (2% + 1% + 3% + 2%)/4 = 8%/4 = 2%`

**模型 A：**

预测 `[1%, 0%, 2%, −1%]`

绝对误差：

`[1%, 1%, 1%, 1%]`

`MAE_model = 4%/4 = 1%`

模型 A 的 MAE 低于基线，说明在该测试区间平均绝对误差更小。

**模型 B：**

预测 `[5%, −5%, 5%, −5%]`

绝对误差：

`[3%, 4%, 2%, 3%]`

`MAE_model = 12%/4 = 3%`

模型 B 的 MAE 高于基线，说明它不如每天预测 0。

**与 R² 的区别：**

对模型 A，测试集实际均值是：

`(2% − 1% + 3% − 2%)/4 = 0.5%`

R² 的分母是实际值围绕 `0.5%` 的平方和 `17 %²`，残差平方和 `4 %²`，所以：

`R² = 1 − 4/17 ≈ 0.7647`

R² 的参考是测试均值 0.5%，不是零收益基线；因此 MAE 比较和 R² 回答的问题不同。

### 前提假设

- 测试集按时间顺序切分，未参与训练或调参。
- 基线预测在特征日可得；零收益永远可得。
- 评价指标与实际决策目标一致；MAE 不是唯一目标。
- 测试区间能代表模型未来使用的区间。
- 收益单位一致；不同频率、币种或复权口径不能直接比较。
- 不考虑交易成本；MAE 优势不等于净收益优势。

### 边界情况

- 测试集实际均值明显不为 0：零收益基线可能较弱；历史均值基线可能更合适。
- 测试集波动很大：基线 MAE 很大，模型容易“看起来更好”。
- 测试集波动很小：基线 MAE 很小，模型很难胜出。
- 测试样本很少：MAE 比较不稳定。
- 厚尾/极端值：MAE 比 MSE 稳健，但仍受大误差影响。
- 模型预测极端值：MAE 可能变大，R² 可能严重为负。
- 分布漂移：基线在训练期最优，不代表测试期最优。
- 交易成本：即使 MAE 更低，扣除成本后可能不盈利。
- 方向一致率：MAE 低不一定方向准；需同时看方向指标。
