# 平均绝对误差与均方根误差（MAE and RMSE）

## 快速理解

### 一句话解释

MAE 是预测误差绝对值的平均，RMSE 是误差平方平均后再开平方；两者都用目标变量的单位衡量误差。Quant Lab 当前显示样本外 MAE 和零收益基线 MAE，但**没有计算或显示 RMSE**。

### 它解决什么问题

模型评价需要一个可比较的误差尺度。MAE 直观地表示“平均差了多少个百分点”，RMSE 对大误差更敏感，常用于强调较大偏差的模型。两者结合可以判断模型是普遍小误差，还是少数大误差拖累。

### 最常见的误解

- **“MAE 的单位是元”**：当前标签是收益率，MAE 的单位是收益率误差，例如 1% 表示平均相差 1 个百分点，不是股价相差 1 元。
- **“RMSE 和 MAE 总是接近”**：误差越集中，两者越接近；存在少数大误差时，RMSE 明显大于 MAE。
- **“RMSE 一定比 MAE 好”**：RMSE 对大误差惩罚更重，但是否更好取决于决策目标；当前软件只显示 MAE。
- **“MAE 更小就能盈利”**：MAE 不含方向、费用、滑点和可成交性；误差小不等于策略赚钱。
- **“软件显示了 RMSE”**：当前页面没有 RMSE 指标；只有 MAE、基线 MAE、R² 和方向一致率。
- **“MAE 可以跨资产直接比较”**：不同资产、区间和波动水平的 MAE 不可直接比较。

- 页面没有 RMSE、MSE、MAPE 或误差分布图。

### 输入、输出和单位

- 输入：测试集真实下一日收益率 `y_t` 和模型预测 `ŷ_t`。
- MAE：

`MAE = (1/n)Σ|y_t − ŷ_t|`

- RMSE（概念公式，当前未计算）：

`RMSE = √[(1/n)Σ(y_t − ŷ_t)²]`

- 输出：MAE，单位是收益率误差；页面用百分比显示。
- 例如 MAE `1%` 表示预测与实际日收益平均相差 1 个百分点。
- 误差是“收益率之差”，不是价格之差；不能读成“平均相差 1 元”。

### 结果应该怎么读

- 先看 MAE 和基线 MAE 的比较；模型更低，说明该测试区间平均绝对误差更小。
- MAE 是绝对误差的平均，不区分高估和低估。
- MAE 不惩罚大误差特别重；如果关心极端误差，RMSE 或误差分布更有信息。
- 当前没有 RMSE；不要从 MAE 推断 RMSE，除非所有绝对误差都相同。
- 误差单位是收益率；不同频率（日/周/月）和不同资产的 MAE 不能直接比较。
- MAE 低不代表方向一致率高，也不代表扣除成本后能盈利。

## 专业原理

### 正式定义

给定 `n` 个测试观测 `(y_t, ŷ_t)`：

`MAE = (1/n)Σ|y_t − ŷ_t|`

`MSE = (1/n)Σ(y_t − ŷ_t)²`

`RMSE = √MSE`

MAE 和 RMSE 都与 `y` 同单位；MSE 是 `y` 单位的平方。

### 公式与符号

- `y_t`：第 t 个真实下一日收益率；
- `ŷ_t`：模型预测；
- `n`：测试样本数；
- `MAE`：平均绝对误差；
- `MSE`：均方误差；
- `RMSE`：均方根误差。

### 可手算的小例子

测试集实际收益：

`[2%, −1%, 3%, −2%]`

模型预测：

`[1%, −1%, 1%, −2%]`

逐项误差 `y_t − ŷ_t`：

- `2% − 1% = 1%`
- `−1% − (−1%) = 0%`
- `3% − 1% = 2%`
- `−2% − (−2%) = 0%`

绝对误差：

`[1%, 0%, 2%, 0%]`

MAE：

`(1% + 0% + 2% + 0%)/4 = 3%/4 = 0.75%`

平方误差（用百分数单位）：

`[1 %², 0 %², 4 %², 0 %²]`

MSE：

`(1 + 0 + 4 + 0)/4 = 1.25 %²`

RMSE：

`√1.25 ≈ 1.1180%`

这里 RMSE（1.1180%）大于 MAE（0.75%），因为 2% 的大误差在平方后被放大。

**对照：** 如果四个绝对误差都等于 1%，则 MAE `=1%`，RMSE `=√1 %²=1%`，两者相等。误差越集中，两者越接近。

### 前提假设

- 测试集按时间顺序切分，未参与训练或调参。
- 真实值和预测值单位一致；当前都是日收益率。
- 评价目标与决策目标一致；MAE 不包含成本和方向。
- 测试集能代表未来使用区间。
- 误差定义一致：当前是 `actual − predicted`，取绝对值后与顺序无关。
- 没有缺失值；预测表只包含有效测试行。

### 边界情况

- 所有误差为 0：MAE 和 RMSE 都为 0；模型完美拟合测试集，需警惕泄漏。
- 少数大误差：RMSE 明显大于 MAE；MAE 可能低估尾部风险。
- 厚尾/极端值：两者都受影响，RMSE 更敏感。
- 误差单位是百分数：MAE 1% 是 1 个百分点；写成小数时是 0.01。
- 跨资产比较：不同波动水平和价格区间的 MAE 不可直接比较。
- 测试样本很少：误差指标不稳定。
- 非平稳：测试区间与训练区间分布不同，误差可能被结构突变主导。
- 零收益基线：MAE 低于基线不等于 R² 为正，也不等于盈利。
- 方向：MAE 不区分高估和低估；方向一致率单独计算。
- 交易成本：MAE 不含费用、滑点和可成交性。
