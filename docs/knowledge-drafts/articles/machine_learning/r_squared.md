# 决定系数 R²（R-squared）

## 快速理解

### 一句话解释

R² 衡量模型平方误差相对于“用测试集实际均值预测”的参考误差减少了多少；它可以为负，因为样本外模型可能比简单均值参考还差。Quant Lab 显示样本外 R²，保留 3 位小数。

### 它解决什么问题

MAE 给出绝对误差尺度，R² 给出相对误差比例。它帮助判断模型是否比“只知道测试集平均收益”的简单参考更好，也提醒研究者：样本外 R² 为负是有效结果，不应删除。

### 最常见的误解

- **“R² 一定在 0 到 1 之间”**：样本外 R² 可以为负；训练集带截距的 OLS R² 通常在 `[0,1]`。
- **“R² 就是相关系数的平方”**：只有在特定条件下（例如带截距的简单线性回归、同一数据集）才成立；样本外 R² 不是相关系数平方。
- **“R² 高就说明模型能预测收益”**：R² 高可能来自泄漏、样本特殊或测试区间；不保证样本外可推广。
- **“R²=0 表示没有关系”**：它表示模型平方误差与测试均值参考相当；可能存在非线性关系或方向信息。
- **“R² 的参考是 0 收益”**：sklearn 的 `r2_score` 使用测试集实际值的均值作分母，不是 0；零收益基线是另一件事。
- **“R² 可以跨资产直接比较”**：不同资产、区间和波动水平的 R² 不可直接比较。

## 软件实践

### 在 Quant Lab 哪里出现

- “统计与机器学习”页的“样本外 R²”指标卡，显示 3 位小数。
- 计算使用 `sklearn.metrics.r2_score(actual, predicted)`。
- 页面说明：R² 为负时，模型误差比测试样本均值参考更大。
- R² 与样本外 MAE、基线 MAE、方向一致率并列显示。
- 知识解释使用 R² 值做白话说明；不提供调整 R²、训练 R² 或置信区间。

### 输入、输出和单位

- 输入：测试集真实下一日收益率 `y_t` 和模型预测 `ŷ_t`。
- 公式：

`R² = 1 − SS_res/SS_tot`

`SS_res = Σ(y_t − ŷ_t)²`

`SS_tot = Σ(y_t − ȳ_test)²`

其中 `ȳ_test` 是测试集实际收益的均值。
- 输出：无量纲的 R²，显示 3 位小数；可以为负。
- 退化测试目标：当测试集所有实际值相同（`SS_tot=0`）时，R² 没有通常的方差解释。当前直接调用 `sklearn.metrics.r2_score`，使用默认 `force_finite=True`：若预测与常数真实值完全一致，返回 1.0；否则返回 0.0。页面没有对此给出专门警告，不能把 0.0/1.0 当成普通非退化测试集中的 R² 解释。
- R² 不是百分比收益，不是概率，也不是解释方差百分比的严格因果陈述。

### 结果应该怎么读

- `R²=1`：在非退化测试集（`SS_tot>0`）中，预测完全匹配实际值；需警惕泄漏或测试集太小。
- `R²=0`：在非退化测试集（`SS_tot>0`）中，模型平方误差与“用测试均值预测”相当。
- `R²<0`：模型平方误差比测试均值参考更大；这是有效结果。
- R² 的分母使用测试集均值，不是 0；因此 R² 与零收益基线 MAE 不是同一比较。
- R² 对极端误差敏感，因为使用平方；少数大误差可能让 R² 大幅下降。
- R² 不告诉你方向、交易成本或可执行性；要结合 MAE 和方向一致率。
- 样本外 R² 为负时，不要删除区间或只汇报正值区间。

### 当前软件边界

- 只计算样本外 R²；不显示训练集 R²。
- 不提供调整 R²、预测 R²、伪 R² 或分位数 R²。
- 不提供 R² 的置信区间或显著性检验。
- 不把 R² 用于自动模型选择或超参数搜索。
- 不区分不同测试区间的基准；R² 使用当前测试集均值。
- `SS_tot=0` 时没有专门警告；直接调用 `r2_score` 默认 `force_finite=True`，按预测是否完全一致返回 1.0 或 0.0。
- 不处理异方差、自相关或非平稳下的 R² 解释。
- 不把 R² 转成策略收益、盈利概率或因果效应。

## 专业原理

### 正式定义

给定测试集 `(y_t, ŷ_t)`，`n` 个观测，测试均值为 `ȳ`：

`SS_res = Σ(y_t − ŷ_t)²`

`SS_tot = Σ(y_t − ȳ)²`

`R² = 1 − SS_res/SS_tot`

若 `SS_tot > 0`，R² 可以为负；若 `SS_tot = 0`（测试集所有实际值相同），R² 没有通常的方差解释，当前 `r2_score` 的默认 `force_finite=True` 会按预测是否完全一致返回 1.0 或 0.0。

### 公式与符号

- `y_t`：真实下一日收益率；
- `ŷ_t`：模型预测；
- `ȳ`：测试集实际收益均值；
- `SS_res`：残差平方和；
- `SS_tot`：测试集围绕均值的总平方和；
- `R²`：决定系数。

### 可手算的小例子

测试集实际收益：

`[2%, −1%, 3%, −2%]`

模型预测：

`[1%, 0%, 2%, −1%]`

测试均值：

`ȳ = (2% − 1% + 3% − 2%)/4 = 2%/4 = 0.5%`

`SS_tot`：

- `(2% − 0.5%)² = 1.5² = 2.25 %²`
- `(−1% − 0.5%)² = (−1.5)² = 2.25 %²`
- `(3% − 0.5%)² = 2.5² = 6.25 %²`
- `(−2% − 0.5%)² = (−2.5)² = 6.25 %²`

合计：

`SS_tot = 2.25 + 2.25 + 6.25 + 6.25 = 17 %²`

`SS_res`：

- `(2% − 1%)² = 1 %²`
- `(−1% − 0%)² = 1 %²`
- `(3% − 2%)² = 1 %²`
- `(−2% − (−1%))² = 1 %²`

合计：

`SS_res = 4 %²`

因此：

`R² = 1 − 4/17 ≈ 0.7647`

**负 R² 例子：** 若预测为 `[10%, −10%, 10%, −10%]`，残差平方和：

`(2−10)² + (−1+10)² + (3−10)² + (−2+10)²`

`= 64 + 81 + 49 + 64 = 258 %²`

`R² = 1 − 258/17 ≈ −14.1765`

模型比“用测试均值 0.5% 预测”差得多。负 R² 是有效结果，不是计算错误。

### 前提假设

- 测试集按时间顺序切分，未参与训练或调参。
- 真实值和预测值单位一致；当前都是日收益率。
- 测试集实际值有非零方差；否则 R² 的分母为 0，解释不成立。
- 平方误差是合适的评价目标；若更关心绝对误差，应看 MAE。
- 测试区间能代表模型未来使用区间。
- 没有数据泄漏；否则 R² 可能虚高。

### 边界情况

- 测试集所有实际值相同：`SS_tot=0`，R² 没有通常解释；当前 `r2_score(force_finite=True)` 会返回 1.0（预测完全一致）或 0.0（其它），页面没有专门警告。
- 极端值/厚尾：平方误差放大极端值，R² 可能大幅下降。
- 少数大误差：R² 对少数大误差敏感，MAE 相对稳健。
- 非线性关系：线性模型 R² 可能低，但特征仍有信息。
- 分布漂移：测试均值和方差变化会改变 R²。
- 小测试集：R² 不稳定，容易受个别观测影响。
- 负 R²：模型比测试均值参考更差；不要删除或隐藏。
- 与相关混淆：样本外 R² 不是预测值与实际值相关系数的平方。
- 与零基线混淆：R² 的分母是测试均值，不是 0；MAE 基线比较是另一回事。
- 交易成本：R² 不含费用、滑点和可成交性。
