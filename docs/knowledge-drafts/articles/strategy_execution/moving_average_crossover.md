# 均线交叉（Moving Average Crossover）

## 快速理解

### 一句话解释

本软件的双均线策略不是只在“交叉当天”交易，而是每天比较短均线和长均线：短均线高于长均线时目标持仓为 1，否则为 0；状态持续期间不会重复下单。

### 它解决什么问题

它把两条不同速度的均线放在一起，用相对位置描述趋势方向：短均线更快反映近期价格，长均线更慢；短期均价高于长期均价时，规则认为近期走势相对更强。

### 最常见的误解

- **“交叉策略每天都要交易”**：信号是持续的目标状态；短均线一直在长均线上方时，只会在状态从 0 变 1 时触发一次买入。
- **“金叉一定盈利”**：交叉是规则条件，不是收益保证；震荡市中可能反复触发并累积成本。
- **“短均线高于长均线就代表价格上涨”**：它只代表近期平均收盘价高于长期平均收盘价，方向可能已经改变。
- **“可以用任意短长周期”**：本软件要求 `2 ≤ 短周期 < 长周期 ≤ 250`。
- **“交叉发生在收盘前就能成交”**：信号在收盘后形成，最早下一交易日开盘尝试成交。

## 软件实践

### 在 Quant Lab 哪里出现

- 策略类型“双均线趋势”（代码标识 `dual_ma`）。
- 策略实验室：短周期默认 10、长周期默认 30，图中显示两条均线和信号变化标记。
- 历史回测：同一信号用于下一开盘成交、费用、基准和样本内外统计。
- 知识解释“移动平均线”和 Quant Academy 第 2 课提供均线基础。

### 输入、输出和单位

输入：收盘价序列、短窗口 `N_short`、长窗口 `N_long`。输出：每日目标持仓信号 0/1。

`MA_short,t = mean(close_{t-N_short+1..t})`

`MA_long,t = mean(close_{t-N_long+1..t})`

`signal_t = 1` 当且仅当 `MA_short,t > MA_long,t`；否则为 0。比较是严格的“大于”，相等时为 0。

- 窗口单位是交易日，不是自然日。
- 短周期默认 10，长周期默认 30；两者都可修改。
- 窗口不足时均线为空，信号为 0。
- 均线值单位是价格；信号无量纲，只有 0 和 1。

### 结果应该怎么读

- 先看两条均线是否都已形成；长周期决定预热长度。
- 短均线在长均线上方时信号为 1；下方或相等时为 0。
- 信号从 0 变 1 是买入状态开始，从 1 变 0 是卖出状态开始；图表三角标记只是状态变化，不是成交。
- 震荡区间内信号可能频繁变化，交易次数和费用会增加。
- 回测结果取决于窗口、样本区间、成本和成交规则，不是“金叉”这个名称本身。

### 当前软件边界

- 只实现短均线 > 长均线的状态规则；没有价格突破、成交量确认、波动率过滤或止损。
- 没有参数优化器；短/长周期由用户设置，参数敏感性表只做样本内网格展示。
- 只做多；信号 0 表示空仓，不是做空。
- 不区分“金叉/死叉”的传统叫法，也不把交叉事件单独存表。
- 信号可以使用复权收盘价；成交和估值使用不复权价格。

## 专业原理

### 正式定义

设 `MA_s(t)` 和 `MA_l(t)` 分别为短、长简单移动平均，满足 `2 ≤ s < l ≤ 250`。双均线目标持仓为：

`S_t = 1`，若 `MA_s(t) > MA_l(t)`；

`S_t = 0`，若 `MA_s(t) ≤ MA_l(t)`。

这里的“交叉”是两条均线相对位置发生变化，不是一个独立的成交事件。

### 公式与符号

- `s`：短窗口长度；
- `l`：长窗口长度；
- `MA_s(t)`：t 日短均线；
- `MA_l(t)`：t 日长均线；
- `S_t`：t 日收盘后的目标持仓信号；
- `>`：严格大于；相等时信号为 0。

状态变化：

`buy_signal_t = 1` 当 `S_t=1` 且 `S_{t-1}=0`；

`sell_signal_t = 1` 当 `S_t=0` 且 `S_{t-1}=1`。

但实际订单由回测引擎在 t+1 开盘根据 `S_t` 和当前持股产生，不由图表标记直接产生。

### 可手算的小例子

收盘价：10、11、12、11、13；短窗口 2、长窗口 3。

| 日期 | 收盘价 | MA2 | MA3 | 短 > 长 | 信号 |
| --- | --- | --- | --- | --- | --- |
| t1 | 10 | 空 | 空 | 否 | 0 |
| t2 | 11 | 10.5 | 空 | 否 | 0 |
| t3 | 12 | 11.5 | 11.0 | 是 | 1 |
| t4 | 11 | 11.5 | 11.3333 | 是 | 1 |
| t5 | 13 | 12.0 | 12.0 | 否（相等） | 0 |

计算：

- t3：`MA2=(11+12)/2=11.5`；`MA3=(10+11+12)/3=11.0`；11.5 > 11.0，信号 1。
- t4：`MA2=(12+11)/2=11.5`；`MA3=(11+12+11)/3=11.3333`；11.5 > 11.3333，信号 1。
- t5：`MA2=(11+13)/2=12.0`；`MA3=(12+11+13)/3=12.0`；相等，严格大于不成立，信号 0。

若 t3 收盘信号为 1，最早在 t4 开盘尝试买入；t5 收盘信号变为 0，最早在下一交易日开盘尝试卖出。这个例子没有计入费用和滑点。

### 前提假设

- 收盘价为正且按交易日升序排列。
- 均线窗口内数据完整；缺失数据会让预热或均线值发生变化。
- 短周期严格小于长周期；不满足时策略构造会报错。
- 只做多；信号 0 时卖出全部持股并持有现金。
- 复权口径在信号生成期间固定；成交和估值使用原始价格。

### 边界情况

- 短周期等于长周期：不允许，构造策略时直接报错。
- 长周期大于样本长度：长均线长期为空，信号恒为 0。
- 两条均线相等：信号为 0，因为条件是严格大于。
- 价格恒定或震荡：可能频繁在 0/1 之间切换，交易成本和滑点影响更明显。
- 停牌、缺失交易日、除权除息：均线可能跨过事件，需要检查复权口径。
- 极端行情：均线滞后，状态变化可能晚于价格转折。
