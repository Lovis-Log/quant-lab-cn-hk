# 移动平均线（Moving Average）

## 快速理解

### 一句话解释

移动平均线把最近 N 个交易日的收盘价取算术平均，得到一条平滑的价格线；Quant Lab 使用简单移动平均（SMA），窗口内必须凑满 N 个收盘价才开始有值。

### 它解决什么问题

它把每天波动的收盘价平滑成较稳定的趋势参照，让研究者可以用“价格在均线上方还是下方”“短均线在长均线上方还是下方”来描述状态，而不是只看单日涨跌。

### 最常见的误解

- **“均线能预测下一日价格”**：均线只是过去收盘价的平均，是滞后描述，不是预测模型。
- **“第一天就有均线”**：本软件要求窗口内凑满 N 个收盘价；前 N−1 个交易日均线为空，信号为 0。
- **“均线用的是当天最高价或最低价”**：当前策略只用收盘价计算均线。
- **“短均线和长均线必须一起使用”**：单均线和趋势过滤只使用长均线；短周期参数仍会被校验，但不参与这两类信号条件。
- **“均线周期越长越好”**：周期越长越平滑、越滞后；没有适用于所有市场和个人目标的固定最优周期。

## 软件实践

### 在 Quant Lab 哪里出现

- 策略实验室：图中显示收盘价、短均线和长均线；表格显示“目标持仓信号（1=持有）”。
- 历史回测：使用同一组均线信号，在下一交易日开盘尝试成交。
- 知识解释“移动平均线”：显示定义、当前长均线值和样本不足提示。
- Quant Academy 第 2 课：用固定教学价格演示不同窗口的均线。

### 输入、输出和单位

输入是一段按交易日升序排列、日期唯一的收盘价序列，以及窗口 `N`。输出是每个交易日的均线值，单位与价格相同（CNY/股或 HKD/股）：

`MA_N(t) = (1/N) × Σ_{i=0}^{N-1} close_{t-i}`

- `N` 必须是 2 到 250 之间的整数。
- 当前代码使用 `rolling(window=N, min_periods=N).mean()`；不足 N 个观测时返回空值。
- 窗口包含当日收盘价；不是“前 N 日但不含当日”。
- 百分数、收益率和均线值不是同一单位；均线是价格，不是收益率。

### 结果应该怎么读

- 先看均线是否已经形成：前 N−1 个交易日为空是正常预热，不是数据错误。
- 均线上升表示最近 N 日收盘价的平均水平在提高；均线下降表示在降低。
- 价格在均线上方只说明当前收盘价高于过去 N 日均值，不保证继续上涨。
- 短均线对近期价格更敏感，长均线更平滑；两者差得越大，近期价格相对长期均值偏离越多。
- 比较不同股票时，均线值受价格水平和币种影响，不能直接把 CNY 均线和 HKD 均线相加。

### 当前软件边界

- 只实现简单移动平均（SMA），没有指数移动平均（EMA）、加权移动平均（WMA）或自适应均线。
- 只使用收盘价，不使用开盘价、最高价、最低价、成交量或成交额。
- 不自动选择最优窗口，不按市场、板块或波动率自动调整窗口。
- 不处理停牌、缺失交易日或公司行动现金流；均线只对输入的价格序列做滚动平均。
- 信号价格可以使用前复权/后复权；均线本身不判断复权口径，成交和估值仍使用不复权价格。

## 专业原理

### 正式定义

给定收盘价序列 `close_1, ..., close_T` 和窗口 `N`，简单移动平均定义为：

`MA_N(t) = (1/N) × Σ_{i=0}^{N-1} close_{t-i}`，当 `t ≥ N`。

当 `t < N` 时，本软件返回空值；信号列用 `fillna(False)` 转为 0。

### 公式与符号

- `close_t`：t 日收盘价；
- `N`：窗口长度（交易日数）；
- `MA_N(t)`：t 日 N 期简单移动平均；
- `Σ`：求和；
- 若价格使用前复权或后复权，`close_t` 是调整后的收盘价；均线值也随口径变化。

展开形式：

`MA_N(t) = (close_t + close_{t-1} + ... + close_{t-N+1}) / N`

### 可手算的小例子

收盘价：10、12、14、13、15。

3 日均线：

- t1：不足 3 个观测，空值；
- t2：不足 3 个观测，空值；
- t3：`(10+12+14)/3 = 36/3 = 12.00`；
- t4：`(12+14+13)/3 = 39/3 = 13.00`；
- t5：`(14+13+15)/3 = 42/3 = 14.00`。

若使用单均线策略且 `close_t > MA_3(t)`：

- t3：14 > 12，条件为真，信号 1；
- t4：13 > 13 不成立（严格大于），信号 0；
- t5：15 > 14，条件为真，信号 1。

这个例子只说明均线和条件，不代表 t3 收盘能成交；信号要到下一交易日开盘才尝试执行。

### 前提假设

- 收盘价为正且有限；均线本身不处理零价或负价。
- 交易日按时间升序且唯一；缺失交易日不会被自动补齐为自然日。
- 窗口内每个交易日都有一个收盘价；停牌或缺失会让窗口跨越更长的自然时间。
- 均线是历史描述，不是未来收益预测。
- 复权口径在比较和信号生成期间保持不变；不同口径的均线不能直接比较。

### 边界情况

- 观测数少于 N：整条均线为空，信号恒为 0；这不是程序故障。
- N=1：本软件不允许；最小窗口为 2。
- N 大于 250：本软件不允许。
- 价格恒定：均线等于价格，`close > MA` 不成立；双均线可能出现相等，严格大于为假。
- 零波动或价格不变化：均线条件可能长期不触发，不代表数据错误。
- 缺失交易日、停牌、除权除息：均线可能跨过事件，需要结合复权口径和数据质量阅读。
- 不同币种、不同市场、不同复权口径：不能把均线值直接相加或比较。
