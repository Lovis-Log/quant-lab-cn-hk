# 组合权重与约束（Portfolio Weights and Constraints）

## 快速理解

### 一句话解释

组合权重是每只资产占组合资金的比例；Quant Lab 当前只生成正权重、合计 100% 的等权或训练期逆波动率权重，没有做空、杠杆、权重上下限或优化器。

### 它解决什么问题

权重决定组合的收益和风险来源。同样的资产集合，不同权重会产生不同的波动、回撤和样本外路径。明确权重约束可以防止把“组合研究”误解成可以随意做空、加杠杆或自动求最优配置的系统。

### 最常见的误解

- **“权重可以是负数”**：当前软件只生成正权重；没有做空。
- **“权重合计可以超过 100%”**：当前权重合计为 100%，没有杠杆。
- **“软件会自动求最优权重”**：当前只有等权和训练期逆波动率，没有均值—方差优化器。
- **“核心函数会校验币种”**：`analyze_portfolio` 只接收历史表，不掌握证券币种；同市场、同币种限制由界面上下文保证。
- **“权重用了全部样本”**：权重只使用训练期收益率；协方差/相关矩阵才使用全部共同日期。
- **“权重就是持仓股数”**：权重是资金比例；当前软件不生成持仓股数、订单或成交记录。

## 软件实践

### 在 Quant Lab 哪里出现

- “风险与组合”页的“组合股票代码（逗号分隔，2–4 只）”输入框。
- “组合权重训练比例”滑块，范围 0.50–0.85，默认 0.70。
- “分析同市场组合”按钮触发 `analyze_portfolio`。
- “组合权重”表格显示“等权”和“逆波动率”两列，按百分比格式显示，合计 100%。
- 组合页下方的样本外曲线和统计表使用这两组固定权重。

### 输入、输出和单位

输入：

- 2–4 个不重复的当前市场股票代码；A 股为六位数字，港股为五位数字；
- 当前市场上下文：界面只允许同一市场的代码，不混合 CNY 与 HKD；
- 各股票的历史日线，至少 8 个共同收盘日；
- 训练比例 `f`，范围 0.50–0.85。

输出：

- 权重表，每列按精确权重合计 100%；百分数显示可能有四舍五入误差（例如 1/3 显示为 33.3%）；
- 训练期最后一个共同日期，用于说明权重截至哪一天；
- 后续样本外曲线和统计。

单位：权重是组合资金的比例，不是股数、手数或金额。`57.14%` 表示每 100 元组合资金中约 57.14 元配置到该资产（概念上；当前软件不生成真实订单）。

### 结果应该怎么读

- 先确认权重为正且合计 100%；若不是，说明不是当前软件的输出。
- 看权重使用的是哪段训练期；训练期越短，逆波动率估计越不稳定。
- 等权与逆波动率是两种不同假设，不是“谁更正确”。
- 权重表不包含交易成本、税费、整手约束或滑点；不能直接当作可执行配置。
- 权重是资金比例，不是持仓股数；当前没有订单和成交记录。
- 样本外曲线按固定权重每日再平衡的数学假设绘制；真实组合会漂移并产生换手。

### 当前软件边界

- 只支持 2–4 只资产；少于 2 或多于 4 会报错。
- 只支持同一市场、同一币种；界面负责限制，核心函数本身没有币种字段。
- 只支持多头、无杠杆；权重为正且合计 100%。
- 没有权重上下限、行业约束、换手约束、风险预算或因子约束。
- 没有均值—方差优化、风险平价、Black–Litterman 或机器学习配置。
- 权重只使用训练期日收益率估计；没有滚动再估计、收缩估计或稳健估计。
- 不生成持仓股数、订单、成交、换手率或调仓成本。
- 共同收盘价不足 8 天、训练收益不足 3 天或测试收益不足 2 天时报错。

## 专业原理

### 正式定义

设组合有 `n` 个资产，权重向量为 `w = (w_1,...,w_n)`。当前软件的多头、无杠杆约束为：

`w_i ≥ 0`，`Σ w_i = 1`

等权：

`w_i = 1/n`

逆波动率：

`w_i = (1/s_i) / Σ_j(1/s_j)`

其中 `s_i` 是资产 `i` 在训练期的日收益率样本标准差（分母 `n−1`）。

### 公式与符号

- `n`：资产数量，当前为 2–4；
- `w_i`：资产 `i` 的权重；
- `s_i`：训练期日收益率样本标准差；
- `f`：训练比例，0.50–0.85；
- `split = int(len(returns) × f)`：训练/测试切分索引；
- `Σ`：求和。

权重之和为 1，因此组合日收益为：

`r_p,t = Σ_i w_i r_i,t`

### 可手算的小例子

假设三只资产的训练期日收益率样本标准差分别为：

- A：`s_A = 1% = 0.01`
- B：`s_B = 2% = 0.02`
- C：`s_C = 4% = 0.04`

**等权：**

`w_A = w_B = w_C = 1/3 ≈ 33.33%`

合计：

`33.33% + 33.33% + 33.33% ≈ 100%`（按精确分数 `1/3` 合计为 1）。

**逆波动率：**

`1/s_A = 100`

`1/s_B = 50`

`1/s_C = 25`

合计 `100 + 50 + 25 = 175`

因此：

- `w_A = 100/175 ≈ 57.14%`
- `w_B = 50/175 ≈ 28.57%`
- `w_C = 25/175 ≈ 14.29%`

合计：

`57.14% + 28.57% + 14.29% = 100.00%`

低波动资产获得更高权重。这个例子只使用训练期标准差；若某个资产训练期波动率为 0、负数或 NaN，逆波动率权重不能计算，软件会报错。

### 前提假设

- 2–4 只资产来自同一市场、同一币种，并按共同交易日对齐。
- 训练期足够长，样本标准差能代表配置时的风险。
- 权重只使用训练期信息，样本外不再根据测试结果调整。
- 组合按固定权重每日再平衡；这只是一个数学假设，不是真实交易流程。
- 不考虑整手、碎股、费用、滑点、税费、停牌和流动性。
- 资产收益的波动结构在样本外相对稳定；结构突变会削弱权重依据。

### 边界情况

- 代码重复、数量不在 2–4 之间、格式不符合当前市场：界面拒绝并提示。
- 共同收盘日少于 8 天：软件报错。
- 训练收益少于 3 天或测试收益少于 2 天：软件报错。
- 任一训练期波动率为 0、负数或 NaN：逆波动率权重报错。
- 权重接近 0：可能只是训练期波动率极高，不代表资产不重要。
- 权重集中：逆波动率可能把大部分资金配置到低波动资产。
- 不同币种：界面不允许；核心函数本身不校验币种。
- 真实资金规模、整手和最小交易单位：当前不建模。
- 权重漂移：样本外持有期间权重会随价格变化；曲线假设每日恢复固定权重。
