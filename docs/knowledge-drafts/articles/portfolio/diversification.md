# 分散化（Diversification）

## 快速理解

### 一句话解释

分散化是通过组合多个不完全同向变动的资产来降低整体风险的做法；关键在于资产之间的共同变动，而不是资产数量本身。Quant Lab **当前软件未实现**单独的分散化指标、风险贡献分解或组合优化器，只能用相关矩阵和两条样本外曲线辅助讨论。

### 它解决什么问题

单一资产的风险里，有一部分来自该资产自身，另一部分来自市场共同因素。把不同资产放在一起，若它们不是完全同向变动，组合波动可能低于各资产波动的加权平均。分散化讨论关注的是这种风险抵消是否真实存在、是否稳定、是否被成本和币种问题抵消。

### 最常见的误解

- **“买的股票越多越分散”**：如果所有股票同涨同跌，增加数量不降低共同风险；集中度和相关性比数量更重要。
- **“相关系数为负就一定分散”**：负相关可能只在样本内成立；危机时相关性可能上升，分散效果减弱。
- **“分散化能消除所有风险”**：它主要分散个体风险，市场共同风险仍然存在。
- **“分散化保证收益”**：它讨论风险，不保证收益；组合仍可能亏损。
- **“软件有分散化评分或按钮”**：当前没有单独指标；相关矩阵和组合曲线只是辅助材料。
- **“跨币种组合也能直接分散”**：当前组合限制同一市场、同一币种，不处理汇率。

### 输入、输出和单位

当前软件没有“分散化”输入或输出。概念上，讨论分散化至少需要：

- 各资产权重 `w_i`，合计为 1；
- 各资产波动率 `σ_i`；
- 两两相关系数 `ρ_ij` 或协方差矩阵 `Σ`。

输出可以是组合波动率、分散化比率或风险贡献，但这些都**不是当前软件输出**。当前页面只能显示权重、相关矩阵、协方差矩阵和组合净值曲线。

### 结果应该怎么读

- 看到低相关矩阵时，不要直接说“已经分散”；还要看权重、波动率、样本区间和样本外表现。
- 看到组合曲线比单资产平滑时，也不要直接归因于分散化；可能只是权重不同、区间不同或现金比例不同。
- 等权不是“最分散”的同义词；它只是不做估计的一种简单配置。
- 逆波动率会偏向低波动资产，可能降低组合波动，但不等于风险贡献相等。
- 相关性在危机期可能上升，历史相关矩阵不能保证未来分散效果。

## 专业原理

### 正式定义

对两个资产，组合方差为：

`σ_p² = w_1²σ_1² + w_2²σ_2² + 2w_1w_2ρ_{12}σ_1σ_2`

其中 `w_1 + w_2 = 1`。当 `ρ_{12} < 1` 时，组合波动率通常低于两个资产波动率的加权平均；这就是分散化收益的来源。

对 `N` 个资产，组合方差写成矩阵形式：

`σ_p² = wᵀΣw`

其中 `w` 是权重列向量，`Σ` 是协方差矩阵。

### 公式与符号

- `w_i`：资产 `i` 的权重，合计为 1；
- `σ_i`：资产 `i` 的波动率；
- `ρ_ij`：资产 `i` 与 `j` 的相关系数；
- `Σ`：协方差矩阵；
- `σ_p`：组合波动率；
- `wᵀ`：权重向量的转置。

两资产、等权、`ρ=0` 时：

`σ_p² = 0.5²σ_1² + 0.5²σ_2² = 0.25(σ_1² + σ_2²)`

### 可手算的小例子

假设两个资产的年化波动率分别为 `σ_1 = 20%`、`σ_2 = 10%`，权重各 50%。

**例 1：相关系数 `ρ = 0`。**

`σ_p² = 0.5² × 0.20² + 0.5² × 0.10² + 2 × 0.5 × 0.5 × 0 × 0.20 × 0.10`

`= 0.25 × 0.04 + 0.25 × 0.01 = 0.01 + 0.0025 = 0.0125`

`σ_p = √0.0125 ≈ 0.1118 = 11.18%`

两个资产波动率的加权平均是：

`0.5 × 20% + 0.5 × 10% = 15%`

组合波动率比加权平均低约 `3.82` 个百分点。

**例 2：相关系数 `ρ = 1`。**

`σ_p² = 0.01 + 0.0025 + 2 × 0.25 × 1 × 0.20 × 0.10 = 0.0125 + 0.01 = 0.0225`

`σ_p = 15%`

完全正相关时，组合波动率等于加权平均，没有分散化收益。

**例 3：相关系数 `ρ = −1`。**

`σ_p² = 0.0125 − 0.01 = 0.0025`

`σ_p = 5%`

完全负相关时，等权组合波动率是两者波动率之差的一半；这是数学上的极端情形，不代表现实中可以稳定获得。

这些数字只说明公式。当前软件不计算分散化收益，也不保证样本外出现同样的风险降低。

### 前提假设

- 资产收益的方差、协方差在样本期和持有期内相对稳定。
- 权重合计为 1，且没有杠杆、做空或资金流。
- 组合按同一币种计量；跨币种需要汇率换算。
- 相关关系是线性的，且没有遗漏共同风险因子。
- 交易成本、税费和流动性不影响再平衡。
- 历史协方差矩阵能代表未来风险；这一点在结构突变和危机期往往不成立。

### 边界情况

- 相关系数在危机期上升：金融危机、流动性冲击和政策事件可能让资产同跌。
- 尾部依赖：平常相关低，极端日却同时大跌；Pearson 相关可能低估尾部共同风险。
- 估计误差：样本短、资产多时，协方差矩阵估计不稳定；优化器可能放大误差。
- 资产数量增加：若新增资产与原有资产高度相关，分散效果有限。
- 集中度：少数资产占有大部分权重时，组合仍可能高度集中。
- 波动率差异：逆波动率权重会偏向低波动资产，但风险贡献不一定相等。
- 交易成本：频繁再平衡可能侵蚀分散化收益。
- 跨币种：汇率变化会改变投资者本币收益，当前未建模。
- 杠杆与做空：当前组合不允许；加入后会改变风险结构。
