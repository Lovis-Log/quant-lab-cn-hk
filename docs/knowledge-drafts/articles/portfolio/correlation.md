# 相关系数（Correlation）

## 快速理解

### 一句话解释

相关系数把协方差除以两个标准差，得到 −1 到 1 之间的无量纲数，用来比较两组收益率同向或反向变动的程度；它描述同期线性关系，不证明因果，也不保证未来分散效果。

### 它解决什么问题

协方差带单位，不能直接比较不同资产或不同频率下的关系强弱。相关系数消除了尺度，让研究者可以快速看出两个资产在样本内是同涨同跌、关系很弱，还是反向变动，从而辅助讨论组合分散化。

### 最常见的误解

- **“相关系数 0.8 说明一个资产导致另一个”**：相关不等于因果；可能存在共同驱动因素，也可能只是样本巧合。
- **“相关为负就一定能对冲”**：负相关在样本内可能不稳定；极端行情下相关性可能上升或反转。
- **“软件算的是价格相关性”**：软件先计算日收益率，再计算同日收益率之间的 Pearson 相关系数。
- **“相关系数只用了训练期”**：权重只用训练期估计；相关矩阵使用全部共同日期的收益率。
- **“相关系数 0 表示完全无关”**：它只表示没有线性关系；可能存在非线性依赖或尾部共同变动。
- **“相关系数可以外推到未来”**：历史相关是样本描述，不是未来分散效果的承诺。

## 软件实践

### 在 Quant Lab 哪里出现

- “风险与组合”页的“相关系数”表格，显示组合内各资产两两相关系数，保留 3 位小数。
- 相关系数矩阵和协方差矩阵来自同一组共同交易日收益率。
- 知识解释“相关系数”在组合页读取第一对资产的相关系数，用于白话说明。
- 组合曲线和样本外统计用于辅助观察，不自动证明相关性带来了分散收益。

### 输入、输出和单位

- 输入：同一市场、同一币种的 2–4 只股票，按日期内连接后的共同收盘价；再计算日收益率。
- 输出：一个对称的相关系数矩阵，对角线为 1，非对角线在 −1 到 1 之间。
- 相关系数无量纲；它不随收益率写成小数或百分数而改变。
- 页面使用 pandas 的 Pearson 相关系数，基于全部共同日期收益率，不按训练/测试切分。
- 样本量是共同交易日收益数 `n`；页面不显示每对资产的有效样本量差异，因为内连接后各对使用同一日期集合。

### 结果应该怎么读

- 接近 `+1`：样本内同日收益率近似同向线性变动；接近 `−1`：近似反向；接近 `0`：线性关系弱。
- 相关系数不是斜率；它不告诉你一个资产变动 1% 时另一个变动多少。
- 先看样本区间和共同交易日数量；短样本的相关系数很不稳定。
- 极端值可能把相关系数拉高或拉低；应回看散点图和异常日。
- 相关矩阵对称；`corr(A,B)=corr(B,A)`。
- 相关系数为负不等于组合一定盈利；还要看权重、波动率、成本和样本外表现。
- 同一资产与自己的相关系数为 1；这是定义，不是发现。

### 当前软件边界

- 只计算 Pearson 线性相关系数；没有 Spearman 秩相关、Kendall 相关、偏相关或尾部相关。
- 不提供相关系数的显著性检验、置信区间、滚动窗口或时间变化图。
- 不做领先—滞后相关；所有配对都是同一日收益率。
- 不把相关矩阵用于自动优化；权重只有等权和训练期逆波动率两种。
- 不检测相关结构突变、非线性依赖或共同因子。
- `analyze_portfolio` 只接收历史表，不掌握币种；同市场、同币种限制由界面上下文保证。
- 当前没有跨币种相关；混合 CNY 与 HKD 的组合不会由该页面生成。

## 专业原理

### 正式定义

给定两个收益率序列 `x` 和 `y`，样本 Pearson 相关系数为：

`ρ(x,y) = cov(x,y) / (s_x s_y)`

其中 `cov(x,y)` 是样本协方差，`s_x`、`s_y` 是样本标准差（分母 `n−1`）。等价地：

`ρ(x,y) = Σ[(x_i − x̄)(y_i − ȳ)] / √[Σ(x_i − x̄)² × Σ(y_i − ȳ)²]`

相关系数矩阵的第 `(i,j)` 个元素是资产 `i` 与 `j` 的相关系数，对角线为 1。

### 公式与符号

- `x_i`、`y_i`：同一交易日的日收益率，小数；
- `x̄`、`ȳ`：样本均值；
- `s_x`、`s_y`：样本标准差；
- `ρ(x,y)`：样本 Pearson 相关系数，无量纲，范围 `[−1,1]`；
- `n`：共同交易日收益数；
- `corr`：相关系数矩阵。

### 可手算的小例子

沿用协方差文章的三个共同交易日：

- 资产 A：`[0.01, −0.01, 0.02]`
- 资产 B：`[0.02, 0.00, 0.01]`

已经算得：

- `cov(A,B) = 0.0001`
- `s_A ≈ 0.0152753`
- `s_B = 0.01`

因此：

`ρ(A,B) = 0.0001 / (0.0152753 × 0.01) ≈ 0.6547`

这表示样本内 A 与 B 存在中等偏强的正向线性关系，但不表示 A 的涨跌导致 B 的涨跌。

再看一个完全反向的例子：

- A：`[−0.01, 0.00, 0.01]`
- C：`[0.01, 0.00, −0.01]`

两者均值都为 0，偏差乘积为 `−0.0001 + 0 + −0.0001 = −0.0002`；协方差为 `−0.0002/2 = −0.0001`。各自标准差都是 1%，所以：

`ρ(A,C) = −0.0001 / (0.01 × 0.01) = −1`

如果只看数值，`0.6547` 和 `−1` 都只是样本描述；是否稳定、是否可外推，需要更多区间和独立检验。

### 前提假设

- 两个序列按同一频率、同一交易日对齐，且样本量足够。
- 关系主要是线性的；相关系数不能完整描述非线性或尾部依赖。
- 样本来自相对稳定的联合分布；结构突变会改变相关结构。
- 两个序列都至少有非零方差；零方差时相关系数无定义。
- 同期相关系数不用于推断领先—滞后关系或因果关系。

### 边界情况

- 任一序列方差为 0：相关系数无定义或为 NaN；软件不会把它解释为“无关”。
- 样本太短：少数观测可能产生接近 ±1 的偶然相关。
- 极端值：一个异常日可能显著改变相关系数。
- 非线性关系：例如 U 形关系可能存在很强的依赖，但 Pearson 相关系数接近 0。
- 范围受限：只在窄区间取样会压低相关系数。
- 非同步交易：不同市场或停牌会让“同日”收益不同步；当前只允许同市场。
- 非平稳：波动率聚集、政策变化和结构突变会让历史相关失效。
- 多重比较：查看很多资产对时，总会看到一些偶然的高相关；需要独立样本复核。
- 交易成本：相关为负也不保证扣除成本后仍有分散收益。
