# 多币种组合（Multi-Currency Portfolio）

## 快速理解

### 一句话解释

多币种组合把不同货币计价的资产放在同一个组合里，必须先把它们换算成统一的投资者本币，才能计算权重、收益和风险。Quant Lab **当前软件未实现**多币种组合：界面限制同一市场、同一币种，没有汇率数据、换算、对冲或跨币种净值。

### 它解决什么问题

跨境投资中，资产以当地货币计价，投资者的收益同时受资产价格和汇率影响。多币种组合需要处理汇率换算、币种敞口、对冲、结算和不同交易日历；忽略这些会把不同单位的金额错误相加。

### 最常见的误解

- **“100 CNY + 100 HKD = 200”**：没有汇率时，这个加法没有统一单位，不能解释为 200 元。
- **“汇率只影响收益，不影响风险”**：汇率波动会显著增加本币收益的波动和相关性结构。
- **“组合里多加一种货币就自动分散”**：货币敞口可能同向变动，也可能在危机时同时贬值。
- **“软件可以自动换算”**：当前没有汇率数据、换算按钮或跨币种净值。
- **“对冲后就没有货币风险”**：对冲有成本、基差和期限问题，也可能只对冲部分敞口。
- **“不同市场的共同日期就是同一批日期”**：交易日历、时区和结算周期可能不同。

## 软件实践

### 在 Quant Lab 哪里出现

- **当前软件未实现**多币种组合、汇率换算、货币对冲或跨币种净值。
- 市场页给 A 股标注 CNY、港股标注 HKD；“风险与组合”页要求 2–4 只同一市场股票，不混合 CNY 与 HKD。
- 组合页说明“不同市场与币种不可直接相加”，但界面没有汇率输入或换算步骤。
- `analyze_portfolio` 只接收历史表，不掌握证券币种；同市场、同币种限制由界面上下文保证。
- 当前没有跨币种基准、跨币种风险比较或汇率损益分解。

### 输入、输出和单位

当前软件没有多币种组合输入或输出。概念上，多币种组合至少需要：

- 各资产的本地货币价格 `P_i,t`；
- 汇率 `S_i,t`：1 单位资产货币折合投资者本币的比率；
- 各资产的权重 `w_i`，按统一本币市值计算；
- 汇率时间戳和来源；
- 对冲比例和成本假设（如果做对冲）。

输出应是统一本币的组合市值、收益、波动和币种敞口；这些**不是当前软件输出**。

### 结果应该怎么读

- 看到不同币种的金额时，先问“这是哪种货币”；不要直接相加。
- 看到收益率时，区分本地资产收益率和投资者本币收益率。
- 看到组合权重时，确认权重是按统一本币市值计算，还是按各资产本币金额计算。
- 看到“对冲”时，确认对冲比例、成本、期限和基差；当前软件没有这些字段。
- 看到跨市场曲线时，不要假设不同市场的交易日和汇率日期已经对齐。

### 当前软件边界

- **当前软件未实现**汇率数据、汇率时间戳、汇率来源或汇率损益分解。
- 不支持 CNY/HKD 或其他货币之间的换算、跨币种加总或统一净值。
- 不支持跨市场组合；界面限制同一市场、同一币种。
- 不支持货币对冲、货币敞口、跨境结算、双重上市、ADR/GDR 处理。
- 不处理不同交易日历、时区、结算周期和资本管制。
- 不计算跨币种基准、跨币种风险比较或汇率调整后的夏普比率。
- 不把港币回测结果换算成人民币；也不把人民币结果换算成港币。

## 专业原理

### 正式定义

设资产以本地货币计价的价格为 `P_t`，投资者本币/资产货币的汇率为 `S_t`（1 单位资产货币折合多少本币）。资产折算成本币的价值为：

`V_t = P_t × S_t`

本地价格收益率：

`r_local = P_t/P_{t−1} − 1`

汇率变化率：

`r_fx = S_t/S_{t−1} − 1`

投资者本币收益率：

`r_investor = V_t/V_{t−1} − 1 = (1 + r_local)(1 + r_fx) − 1`

展开后：

`r_investor = r_local + r_fx + r_local × r_fx`

其中交叉项 `r_local × r_fx` 通常较小，但不能在所有情形下忽略。

### 公式与符号

- `P_t`：资产本地货币价格；
- `S_t`：1 单位资产货币折合投资者本币的汇率；
- `V_t`：折算成本币的资产价值；
- `r_local`：本地价格收益率；
- `r_fx`：汇率变化率；
- `r_investor`：投资者本币收益率；
- `w_i`：按统一本币市值计算的组合权重。

### 可手算的小例子

**例 1：本地收益与汇率收益。**

假设某资产本地价格上涨 5%，同期资产货币相对投资者本币升值 2%：

`r_local = 5% = 0.05`

`r_fx = 2% = 0.02`

`r_investor = (1.05)(1.02) − 1 = 1.071 − 1 = 0.071 = 7.1%`

简单相加是 `5% + 2% = 7%`，交叉项是：

`0.05 × 0.02 = 0.001 = 0.1%`

所以精确结果是 `7.1%`，不是 `7%`。

**例 2：港股资产、人民币投资者。**

假设某港股以 HKD 计价上涨 3%，同期 HKD 相对 CNY 升值 1%：

`r_investor = (1.03)(1.01) − 1 = 1.0403 − 1 = 4.03%`

如果 HKD 相对 CNY 贬值 1%，则：

`r_investor = (1.03)(0.99) − 1 = 1.0197 − 1 = 1.97%`

同一个本地涨幅，因汇率方向不同，本币收益可以从 4.03% 变为 1.97%。当前软件不执行这一步换算，也不提供示例中的汇率。

**例 3：不同币种不能直接相加。**

- A 股市值 100 CNY；
- 港股市值 100 HKD；
- 若 `1 HKD = 0.92 CNY`（仅用于说明），港股折算为 92 CNY，合计 192 CNY。
- 不做换算时，`100 + 100 = 200` 是混合单位，不是 200 CNY 或 200 HKD。

### 前提假设

- 汇率与价格来自可核验的来源，并有明确时间戳。
- 汇率方向一致：明确是“资产货币/本币”还是“本币/资产货币”。
- 组合权重按统一本币市值计算，而不是按各资产本币金额直接相加。
- 不同市场的交易日历已对齐；汇率日期与价格日期匹配。
- 不考虑或另行建模交易成本、结算费用、税费和资本管制。
- 若做对冲，需明确对冲比例、工具、成本、期限和基差风险。

### 边界情况

- 汇率方向写反：结果会系统性错误。
- 汇率日期与价格日期不一致：使用哪一天的汇率会改变收益。
- 不同交易日历：共同日期减少，权重和净值可能不同步。
- 资本管制、换汇额度、结算延迟：可能限制实际可执行性。
- 货币贬值与资产下跌同时发生：本币损失可能放大。
- 对冲成本、基差和对手方风险：当前未建模。
- 双重上市、ADR/GDR：同一资产可能有多个价格和货币，需明确口径。
- 通货膨胀：不同货币的购买力变化不同；名义本币收益不等于实际购买力收益。
- 多币种相关性：汇率之间的相关性会改变组合风险；当前没有相关矩阵。
