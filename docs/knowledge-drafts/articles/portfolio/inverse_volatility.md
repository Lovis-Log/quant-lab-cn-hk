# 逆波动率（Inverse Volatility）

## 快速理解

### 一句话解释

逆波动率把权重按训练期日收益率标准差的倒数分配：波动率越低的资产权重越高，所有倒数归一化后合计 100%；它不使用预期收益，也不考虑资产之间的相关性。

### 它解决什么问题

等权会让高波动资产贡献更多组合风险。逆波动率是一种简单的风险调整配置：在不预测收益、不做优化的前提下，让低波动资产获得更多资金，以降低组合对高波动资产的暴露。

### 最常见的误解

- **“逆波动率就是风险平价”**：风险平价要求各资产风险贡献相等，需要考虑协方差；逆波动率只看单资产方差，相关性不为零时风险贡献通常不相等。
- **“必须先用年化波动率”**：权重只用相对大小；日标准差同乘 `√252` 后归一化结果不变。
- **“权重用了全部样本”**：当前只使用训练期日收益率估计标准差。
- **“逆波动率会自动分散”**：它不考虑相关性；两个高相关资产仍可能共同下跌。
- **“低波动等于低风险”**：低历史波动可能来自流动性差、停牌或价格平滑，也可能是样本偶然。
- **“权重会一直保持”**：曲线假设每日恢复固定权重；真实持有会漂移并产生换手。

## 软件实践

### 在 Quant Lab 哪里出现

- “风险与组合”页的“组合权重”表，“逆波动率”列显示训练期逆波动率权重。
- 权重只使用截至 `train_last_date` 的训练期收益率；样本外曲线从该日期之后的第一个共同交易日收益开始。
- 组合页的样本外曲线和统计表包含“逆波动率”方法。
- 知识解释和页面说明强调：权重只由更早的训练区间估计。

### 输入、输出和单位

- 输入：2–4 只同一市场、同一币种的股票；共同收盘价至少 8 天；训练比例 0.50–0.85。
- 计算：`returns = closes.pct_change().dropna()`；`split=int(len(returns)×f)`；`train = returns.iloc[:split]`。
- 每只资产的训练期日收益率样本标准差 `s_i`（分母 `n−1`）。
- 输出：权重 `w_i = (1/s_i)/Σ(1/s_j)`，以百分比显示，全部为正且合计 100%。
- 单位：权重是资金比例；标准差是日收益率小数；归一化后权重无量纲。

### 结果应该怎么读

- 低波动资产通常获得更高权重；但权重差异取决于各资产标准差的相对大小。
- 权重不是“风险贡献”；相关性不为零时，低波动资产的实际风险贡献可能仍与权重不同。
- 训练期越短，标准差估计越不稳定，权重越容易随区间变化。
- 如果某资产训练期波动率接近 0，逆波动率权重会非常大，甚至主导组合；软件在波动率为 0 或无效时报错，但很小的正波动率仍可能造成集中。
- 权重表不包含整手、费用、滑点或税费；不能直接当作可执行配置。
- 样本外曲线按固定权重每日再平衡的数学假设绘制。

### 当前软件边界

- 只使用训练期日收益率样本标准差；没有年化、收缩、指数加权或稳健估计。
- 不考虑资产之间的协方差/相关性；不是风险平价，也不是均值—方差优化。
- 只支持 2–4 只同市场、同币种资产；权重为正、合计 100%，没有做空和杠杆。
- 没有权重上下限、换手约束、风险预算或行业约束。
- 不生成持仓股数、订单、成交、换手率或调仓成本。
- 任一训练期波动率为 0、负数或 NaN 时报错，不计算权重。
- 不处理跨币种、汇率、对冲或跨境结算。

## 专业原理

### 正式定义

设训练期资产 `i` 的日收益率样本标准差为 `s_i > 0`。逆波动率权重为：

`w_i = (1/s_i) / Σ_j(1/s_j)`

等价地，先令 `inv_i = 1/s_i`，再归一化：

`w_i = inv_i / Σ_j inv_j`

组合日收益为：

`r_p,t = Σ_i w_i r_i,t`

### 公式与符号

- `s_i`：资产 `i` 训练期日收益率样本标准差（分母 `n−1`）；
- `inv_i = 1/s_i`：逆波动率分数；
- `w_i`：归一化后的权重；
- `n`：资产数量，当前为 2–4；
- `r_i,t`：样本外第 t 日资产收益率；
- `r_p,t`：组合日收益率。

如果改用年化标准差 `s_i^ann = s_i × √252`，则：

`(1/s_i^ann) / Σ(1/s_j^ann) = (1/s_i) / Σ(1/s_j)`

因为 `√252` 在分子分母中约掉，所以不需要先年化。

### 可手算的小例子

**例 1：三只资产。**

训练期日收益率样本标准差：

- A：`1% = 0.01`
- B：`2% = 0.02`
- C：`4% = 0.04`

逆波动率分数：

- `1/0.01 = 100`
- `1/0.02 = 50`
- `1/0.04 = 25`

合计 `175`。权重：

- `w_A = 100/175 ≈ 57.14%`
- `w_B = 50/175 ≈ 28.57%`
- `w_C = 25/175 ≈ 14.29%`

合计 `100.00%`。

**例 2：两只资产与组合波动。**

设 `s_A = 2%`、`s_B = 1%`，则：

- `inv_A = 50`
- `inv_B = 100`
- `w_A = 50/150 = 1/3 ≈ 33.33%`
- `w_B = 100/150 = 2/3 ≈ 66.67%`

若两者相关系数为 0，组合方差：

`σ_p² = (1/3)² × 0.02² + (2/3)² × 0.01²`

`= (1/9) × 0.0004 + (4/9) × 0.0001`

`≈ 0.00004444 + 0.00004444 = 0.00008889`

`σ_p ≈ 0.009428 = 0.9428%`

而波动率的加权平均是：

`(1/3) × 2% + (2/3) × 1% = 1.3333%`

这个例子说明逆波动率降低了组合波动，但权重并不等于风险贡献；若相关性不为 0，结果会改变。

### 前提假设

- 训练期日收益率标准差能代表样本外的相对波动。
- 2–4 只资产同市场、同币种，按共同交易日对齐。
- 所有训练期标准差为正且有限；零波动或无效值不能计算。
- 不考虑相关性；资产之间的共同变动不进入权重公式。
- 组合按固定权重每日再平衡；这是数学假设，不是真实交易流程。
- 不考虑整手、碎股、费用、滑点、税费、停牌和流动性。
- 波动结构在样本外相对稳定；结构突变会让训练期权重失效。

### 边界情况

- 任一 `s_i = 0`、负数或 NaN：软件报错，不生成权重。
- `s_i` 很小但大于 0：权重可能极端集中，组合风险并不一定低。
- 训练期太短：标准差估计不稳定，权重对单日异常敏感。
- 资产数量变化：加入或移除资产会改变所有归一化权重。
- 相关性上升：逆波动率不考虑相关，危机期组合波动可能高于预期。
- 收益非正态、厚尾、波动聚集：标准差不能完整描述风险。
- 权重漂移：样本外价格变化会改变实际权重；曲线假设每日恢复。
- 交易成本：频繁再平衡会侵蚀净收益；当前未计。
- 不同币种：界面不允许；汇率风险未建模。
