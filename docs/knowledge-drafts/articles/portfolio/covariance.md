# 协方差（Covariance）

## 快速理解

### 一句话解释

协方差衡量两个收益率序列是否同向变动：一个高于自己的均值时，另一个是否也倾向于高于自己的均值；它的数值带单位，正负表示方向，大小不能直接当作“相关强弱”。

### 它解决什么问题

组合风险不是各资产风险的简单相加。两个资产的收益可能同涨同跌，也可能互相抵消；协方差把这种共同变动纳入组合方差的计算，是相关矩阵、组合波动和分散化讨论的基础。

### 最常见的误解

- **“协方差就是相关系数”**：相关系数是协方差除以两个标准差，范围在 −1 到 1；协方差没有固定范围。
- **“协方差 0.0001 比 0.01 小，所以关系更弱”**：数值受收益率单位影响；把收益率从 1% 写成 0.01，协方差的数值会改变。
- **“正协方差说明因果”**：协方差只描述同期线性共同变动，不说明谁导致谁。
- **“软件算的是价格协方差”**：组合页先用收盘价计算日收益率，再对同日收益率计算协方差。
- **“只用训练区间算协方差”**：权重只用训练收益估计，但协方差矩阵和相关系数矩阵使用全部共同日期的收益率。
- **“协方差为负就一定分散”**：负协方差在样本内可能只是短期现象；未来关系可能变化。

## 软件实践

### 在 Quant Lab 哪里出现

- “风险与组合”页的“日收益率协方差”表格，显示组合内各资产两两协方差，保留 6 位小数。
- 组合页的相关系数表由同一组日收益率计算，协方差除以两个标准差得到。
- 知识解释“协方差”在组合页读取一对资产的协方差值，用于白话说明。
- 组合权重本身只使用训练期收益；协方差表使用全部共同日期的收益，两者不要混读。

### 输入、输出和单位

- 输入：同一市场、同一币种的 2–4 只股票历史日线；按日期内连接后得到共同收盘价，再计算日收益率 `close.pct_change().dropna()`。
- 输出：一个对称的协方差矩阵，单位是“日收益率小数”的平方。
- 对角线是各资产日收益率的样本方差；非对角线是两两样本协方差。
- 如果收益率用百分数表示，协方差单位是“百分数的平方”（`%²`），数值与小数口径相差 10,000 倍。
- 页面按 pandas 默认样本口径计算，分母为 `n−1`，其中 `n` 是共同交易日收益数。

### 结果应该怎么读

- 先看符号：正协方差表示样本内同向变动，负协方差表示样本内反向变动。
- 再看数值：协方差大小受两个资产各自波动尺度影响；比较“关系强弱”应看相关系数。
- 协方差矩阵是对称的；`cov(A,B)=cov(B,A)`。
- 对角线是方差，不是标准差；开平方才回到收益率单位。
- 样本量、极端日和共同日期区间都会改变协方差；它不是未来共同变动的保证。
- 协方差矩阵没有显示显著性、置信区间或稳定窗口，不能据此声称关系稳定。

### 当前软件边界

- 只计算同日收益率的线性协方差；没有领先—滞后协方差、滚动协方差或条件协方差。
- 不提供协方差显著性检验、收缩估计、指数加权、稳健估计或缺失值插补。
- 不把协方差年化；页面显示的是日频样本协方差。
- 协方差矩阵使用全部共同日期收益，不按训练/测试切分；组合权重才使用训练期收益。
- `analyze_portfolio` 只接收历史表，不掌握证券币种；同市场、同币种限制由界面上下文保证，核心函数没有独立币种校验。
- 当前没有均值—方差优化器；协方差矩阵只用于展示和辅助解释，不自动求最优权重。

## 专业原理

### 正式定义

给定两个收益率序列 `x_1,...,x_n` 和 `y_1,...,y_n`，样本协方差为：

`cov(x,y) = Σ[(x_i − x̄)(y_i − ȳ)] / (n−1)`

其中 `x̄`、`ȳ` 是各自样本均值。总体协方差把分母换成 `n`。本软件使用样本口径。

协方差矩阵 `Σ` 的第 `(i,j)` 个元素是资产 `i` 与资产 `j` 的协方差；对角线是方差。

### 公式与符号

- `x_i`、`y_i`：同一交易日的两个日收益率，小数；
- `x̄`、`ȳ`：样本均值；
- `n`：共同交易日收益数；
- `cov(x,y)`：样本协方差，单位是收益率小数的平方；
- `Σ`：协方差矩阵；
- `Σ_ii`：资产 `i` 的样本方差；
- `Σ_ij`：资产 `i` 与 `j` 的样本协方差。

相关系数由协方差标准化得到：

`ρ(x,y) = cov(x,y) / (s_x s_y)`

其中 `s_x`、`s_y` 是样本标准差。

### 可手算的小例子

取三个共同交易日的日收益率：

- 资产 A：`[0.01, −0.01, 0.02]`
- 资产 B：`[0.02, 0.00, 0.01]`

先算均值：

- `x̄ = (0.01 − 0.01 + 0.02)/3 = 0.0066667`
- `ȳ = (0.02 + 0 + 0.01)/3 = 0.01`

偏差乘积：

- 第 1 日：`(0.01 − 0.0066667) × (0.02 − 0.01) = 0.0033333 × 0.01 = 0.0000333333`
- 第 2 日：`(−0.01 − 0.0066667) × (0 − 0.01) = (−0.0166667) × (−0.01) = 0.0001666667`
- 第 3 日：`(0.02 − 0.0066667) × (0.01 − 0.01) = 0.0133333 × 0 = 0`

乘积之和：

`0.0000333333 + 0.0001666667 + 0 = 0.0002`

样本协方差：

`cov(A,B) = 0.0002 / (3−1) = 0.0001`

同一组数据的方差和相关系数可用于核对：

- `var(A) = 0.0004666667 / 2 = 0.0002333333`，`s_A ≈ 0.0152753`
- `var(B) = 0.0002 / 2 = 0.0001`，`s_B = 0.01`
- `ρ(A,B) = 0.0001 / (0.0152753 × 0.01) ≈ 0.6547`

用百分数表示同一组数据时，协方差是 `1 %²`，相关系数仍是 `0.6547`。这说明协方差数值依赖单位，相关系数不依赖。

### 前提假设

- 两个序列按同一频率、同一交易日对齐；软件使用共同日期内连接。
- 样本来自相对稳定的联合分布；结构突变会让历史协方差失去参考意义。
- 关系主要是线性的；协方差不能刻画非线性依赖或尾部共同极端。
- 至少两个共同观测；样本量越大，估计通常越稳定，但不消除偏差。
- 同期收益的协方差不能直接解释跨期领先关系。

### 边界情况

- 共同交易日少于 8 天：软件报错，不计算组合。
- 任一系列方差为 0：协方差可能为 0，相关系数无定义；逆波动率权重也会报错。
- 极端值：协方差对偏离乘积敏感，单日异常可能主导估计。
- 非同步交易：不同市场休市日不同，内连接后样本变短；当前只允许同市场。
- 不同币种：当前界面不允许混合；即使计算了数值，也不能直接相加或比较。
- 缺失值：内连接和 `dropna` 会删除不完整日期，剩余日期可能不连续。
- 非平稳：波动率聚集、结构突变和政策变化会改变协方差。
- 多重比较：对很多资产对逐一查看协方差，容易把噪声当关系。

### 前置概念

- `simple_return`：协方差作用于收益率，不作用于价格。

- `variance` 方差

`correlation`：把协方差除以两个标准差，才能比较不同资产、不同单位下的线性关系强弱。
