# 样本与总体（Sample and Population）

## 快速理解

### 一句话解释

总体是研究对象的完整集合，样本是从中观察到的一部分；Quant Lab 用历史日收益率作为样本，计算样本均值、样本方差和样本标准差（分母 `n−1`），但没有计算或显示总体参数公式。

### 它解决什么问题

统计推断的核心问题是：能否用有限的观察推断更大的总体。区分样本和总体，能避免把“历史样本的均值”说成“真实总体均值”，也能解释为什么方差分母有时是 `n`、有时是 `n−1`。

### 最常见的误解

- **“软件算的是总体方差”**：当前软件使用样本方差，分母 `n−1`；总体公式没有计算或显示。
- **“`n` 和 `n−1` 只是写法不同”**：分母不同会改变数值；样本方差用 `n−1` 是对总体方差的无偏估计（在随机抽样等假设下）。
- **“样本均值就是总体均值”**：样本均值是估计量，会随样本变化；它不是总体参数本身。
- **“样本越大就一定越有代表性”**：样本量增加不消除幸存者偏差、前视偏差或非随机抽样。
- **“历史日收益率是一个随机样本”**：金融时间序列有顺序、自相关和非平稳性，简单随机抽样假设通常不成立。
- **“总体公式更精确，所以应该用总体公式”**：是否用总体公式取决于你拥有的是完整总体还是样本，不是哪个看起来更精确。

## 软件实践

### 在 Quant Lab 哪里出现

- “统计与机器学习”页显示“日收益率样本量”，即 `close.pct_change().dropna()` 后的有效日收益个数。
- 同一页显示“日均收益率”和“年化波动率估计”；后者由日收益率样本标准差乘 `√252`。
- “风险与组合”页显示“日收益率样本方差”和“日收益率样本标准差”，使用 `var(ddof=1)`、`std(ddof=1)`。
- 单样本 t 检验内部使用样本标准差 `s` 和样本量 `n` 构造标准误。
- 组合页的协方差/相关矩阵使用样本口径；权重使用训练期样本标准差。

### 输入、输出和单位

- 输入：按日期排序的收盘价；转换为日收益率 `r_t = close_t/close_{t−1} − 1`。
- 有效样本：至少 3 个有效日收益率（t 检验）；组合至少 8 个共同收盘日。
- 输出：样本量 `n`、样本均值 `x̄`、样本方差 `s²`、样本标准差 `s`、年化波动率估计。
- 单位：收益率小数；方差是收益率小数的平方；标准差和均值回到收益率单位；年化波动率是收益率单位。
- 当前没有输出总体均值、总体方差、总体标准差或有限总体校正。

### 结果应该怎么读

- 先看样本量；样本太短时，均值和方差都不稳定。
- 看到“样本方差”时，确认分母是 `n−1`；看到“总体方差”时，分母才是 `n`。
- 样本均值是历史区间的算术平均，不是未来期望收益。
- 年化波动率是样本标准差乘 `√252` 的近似，不是总体波动率。
- 样本区间、复权口径和缺失日期会改变样本；不同区间的结果不能直接比较。
- 样本不是随机抽取的交易日；时间序列依赖会削弱“无偏估计”的通常解释。

### 当前软件边界

**分层结论：样本均值、样本方差、样本标准差和年化波动率已计算/显示；总体公式未在软件中计算或显示；抽样设计、有限总体校正和参数置信区间未实现。**

**软件已经计算或显示什么**

- 日收益率样本量；
- 日均收益率（算术平均）；
- 日收益率样本方差（`ddof=1`）；
- 日收益率样本标准差（`ddof=1`）；
- 年化波动率估计（样本标准差 × `√252`）；
- t 检验内部使用样本标准差和样本量。

**软件只间接使用什么**

- `n−1` 分母通过 pandas `ddof=1` 和 t 检验标准误间接体现；
- 样本量影响 t 检验的 p 值和组合训练期长度；
- 样本区间影响所有描述统计，但软件不显示抽样误差或参数不确定性。

**软件没有提供或没有建模什么**

- 总体均值、总体方差、总体标准差的公式或指标；
- 有限总体校正、分层抽样、整群抽样或加权抽样；
- 样本代表性检验、随机性检验或缺失机制分析；
- 均值、方差、波动率的置信区间；
- 幸存者偏差、前视偏差、数据修订和样本选择偏差的自动控制；
- 时间序列自相关、异方差和非平稳性对标准误的修正。

## 专业原理

### 正式定义

总体参数（population parameters）描述完整总体，常用符号：

- 总体均值 `μ`；
- 总体方差 `σ²`；
- 总体标准差 `σ`。

样本统计量（sample statistics）由样本计算：

- 样本均值 `x̄ = (1/n)Σx_i`；
- 样本方差 `s² = Σ(x_i − x̄)²/(n−1)`；
- 样本标准差 `s = √s²`。

总体方差（如果拥有完整总体）为：

`σ² = Σ(x_i − μ)²/n`

在简单随机抽样和有限方差等条件下，`E[s²] = σ²`，即样本方差是总体方差的无偏估计；`E[x̄] = μ`。

### 公式与符号

- `n`：样本观测数；
- `N`：总体观测数（如果已知）；
- `x_i`：第 i 个观测；
- `x̄`：样本均值；
- `μ`：总体均值；
- `s²`：样本方差；
- `σ²`：总体方差；
- `E[·]`：期望。

### 可手算的小例子

**例 1：把五个收益率视为完整总体。**

假设总体是 `[−2%, −1%, 0%, 1%, 2%]`，用小数表示为 `[−0.02, −0.01, 0, 0.01, 0.02]`。

总体均值：

`μ = (−0.02 − 0.01 + 0 + 0.01 + 0.02)/5 = 0`

总体方差：

`σ² = [(−0.02)² + (−0.01)² + 0² + 0.01² + 0.02²]/5`

`= (0.0004 + 0.0001 + 0 + 0.0001 + 0.0004)/5`

`= 0.001/5 = 0.0002`

`σ = √0.0002 ≈ 0.014142 = 1.4142%`

**例 2：把同一组数据视为样本。**

样本均值仍是 0。样本方差：

`s² = 0.001/(5−1) = 0.00025`

`s = √0.00025 ≈ 0.015811 = 1.5811%`

样本方差比总体方差大，因为分母从 5 变成 4。两者都不是“更精确”的版本；它们回答不同问题：你拥有完整总体，还是只观察到样本。

**例 3：三个观测。**

`[−1%, 0%, 1%]`：

- 样本方差 `= (0.0001 + 0 + 0.0001)/(3−1) = 0.0001`，`s = 1%`；
- 总体方差 `= 0.0002/3 ≈ 0.00006667`，`σ ≈ 0.8165%`。

这组数字与方差文章一致，可用于核对 `n` 与 `n−1` 的差异。

### 前提假设

- 样本能代表总体；简单随机抽样或可忽略的抽样偏差。
- 观测之间近似独立；金融时间序列常有自相关和波动聚集。
- 总体方差有限；厚尾分布可能使样本方差估计不稳定。
- 样本期与推断期相对稳定；结构突变会改变总体参数。
- 样本量足够；小样本的均值和方差估计不确定性大。
- 没有幸存者偏差、前视偏差或数据修订等系统性选择问题。

### 边界情况

- `n=1`：样本方差无定义（分母为 0）；软件至少需要 3 个日收益做 t 检验。
- `n=0`：无法计算均值和方差。
- 总体未知且不可观测：只能用样本估计，不能声称得到真实总体参数。
- 非随机样本：历史区间、当前上市股票、可得数据源都会引入选择偏差。
- 自相关/非平稳：样本方差的“无偏”解释需要独立同分布等假设。
- 厚尾/极端值：样本方差对异常值敏感。
- 缺失数据：删除缺失日期会改变样本和样本量。
- 不同频率：日、周、月收益的样本不能直接混合。
- 不同币种：金额和收益的总体定义不同，不能直接合并。
