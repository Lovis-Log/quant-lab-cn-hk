# 置信区间（Confidence Interval）

## 快速理解

### 一句话解释

置信区间用样本均值和标准误给出一个区间，表示在重复抽样下该构造方法覆盖真实参数的概率；它补充 p 值只回答“是否显著”的不足。Quant Lab **当前软件未实现**置信区间，页面没有均值、波动率、相关系数或预测误差的区间估计。

### 它解决什么问题

p 值只告诉你在某个零假设下结果是否不寻常，不告诉你效应可能有多大。置信区间同时给出中心估计和不确定性范围，帮助判断“统计显著”是否也具有实际意义，以及样本量是否足够。

### 最常见的误解

- **“95% 置信区间有 95% 概率包含真实参数”**：在频率学派框架下，真实参数是固定的；95% 指重复抽样时该构造方法的覆盖频率，不是当前区间的概率。
- **“置信区间是数据的范围”**：它是对参数的估计区间，不是观测值的 95% 范围。
- **“置信区间就是预测区间”**：前者描述参数（如均值）的不确定性，后者描述未来单个观测的不确定性；预测区间通常更宽。
- **“两个置信区间重叠就一定不显著”**：区间重叠与假设检验的关系取决于具体设计和比较方式，不能简单等同。
- **“软件显示了置信区间”**：当前页面没有均值、波动率、相关系数、权重、MAE 或 R² 的置信区间。
- **“区间越窄越好”**：区间窄可能来自样本量大，也可能来自模型假设错误；覆盖率比宽度更重要。

## 软件实践

### 在 Quant Lab 哪里出现

- **当前软件未实现**置信区间：统计页、组合页、机器学习页都没有区间估计。
- 统计页显示日均收益率、年化波动率和 p 值，但不显示均值的置信区间。
- 组合页显示权重、相关矩阵、协方差矩阵和样本外曲线，但不显示这些估计的区间。
- 机器学习页显示 MAE、基线 MAE、R²、方向一致率和交叉验证 MAE，但不显示评价指标的区间。
- t 检验使用理论 t 分布计算 p 值；置信区间可以使用同一分布构造，但软件没有实现。

### 输入、输出和单位

当前软件没有置信区间输入或输出。概念上，均值置信区间需要：

- 样本均值 `x̄`；
- 样本标准差 `s`；
- 样本量 `n`；
- 置信水平 `1−α`；
- 自由度 `n−1` 和 t 临界值。

输出应是区间 `[L, U]`，单位与均值相同（日收益率）。当前页面没有这个输出。

### 结果应该怎么读

- 如果未来软件显示置信区间，先看置信水平和样本量；95% 和 99% 区间宽度不同。
- 区间包含 0 时，不能在同一定义的双侧检验中拒绝“均值为 0”；区间不包含 0 时，通常对应 p 值小于 α。
- 区间宽度反映估计精度，不直接反映未来收益范围。
- 置信区间不是“未来收益有 95% 概率落在这里”；那是预测区间或贝叶斯可信区间的问题。
- 当前软件没有区间；不要从 p 值反推唯一的置信区间，因为区间还取决于置信水平和分布假设。

### 当前软件边界

- **当前软件未实现**均值、方差、标准差、波动率、相关系数、协方差、权重、MAE、R²、方向一致率的置信区间。
- 不提供 bootstrap 置信区间、置换置信区间或贝叶斯可信区间。
- 不提供预测区间或未来收益区间。
- 不提供 Newey–West 等稳健标准误下的区间。
- 不提供多重比较同时置信区间。
- 不把置信区间自动转成交易决策或收益预测。

## 专业原理

### 正式定义

在观测近似独立同分布、均值未知、方差未知且分布近似正态的条件下，总体均值 `μ` 的 `1−α` 置信区间为：

`x̄ ± t_{1−α/2, n−1} × (s/√n)`

其中 `t_{1−α/2, n−1}` 是自由度 `n−1` 的 t 分布的上侧 `1−α/2` 分位数。

区间为：

`[x̄ − t × SE, x̄ + t × SE]`

在重复抽样中，按同一方法构造的区间约有 `1−α` 的比例覆盖真实 `μ`。

### 公式与符号

- `x̄`：样本均值；
- `s`：样本标准差（分母 `n−1`）；
- `n`：样本量；
- `SE = s/√n`：均值标准误；
- `α`：显著性水平；
- `1−α`：置信水平；
- `t`：t 临界值；
- `[L,U]`：置信区间上下限。

### 可手算的小例子

假设：

- 日均收益率 `x̄ = 0.05% = 0.0005`
- 样本标准差 `s = 1.5% = 0.015`
- 样本量 `n = 100`
- 置信水平 95%，`α = 0.05`

标准误：

`SE = 0.015/√100 = 0.0015 = 0.15%`

自由度 `df = 99`，双侧 95% 的 t 临界值约为 `1.9842`。

误差范围：

`1.9842 × 0.0015 ≈ 0.0029763 = 0.29763%`

置信区间：

`[0.05% − 0.29763%, 0.05% + 0.29763%]`

`≈ [−0.2476%, 0.3476%]`

区间包含 0，与同一检验在 5% 水平下不拒绝“均值为 0”一致（对应 p 值约 0.7396）。

再看 `x̄ = 0.3%`：

`[0.3% − 0.29763%, 0.3% + 0.29763%]`

`≈ [0.0024%, 0.5976%]`

区间不包含 0，对应 p 值约 0.0482，在 5% 水平下拒绝零假设。

这两个例子说明置信区间和双侧 t 检验的联系：区间是否包含 0 与检验结论对应，但区间还告诉你效应大小的可能范围。

### 前提假设

- 观测近似独立同分布；金融收益常有自相关和厚尾。
- 均值在样本期稳定；结构突变会改变参数。
- 分布近似正态，或样本量足够使 t 近似适用。
- 样本标准差能合理估计总体标准差。
- 置信水平在看过数据前确定。
- 多次比较需要多重比较校正，否则同时覆盖率下降。

### 边界情况

- 小样本：t 临界值较大，区间较宽；正态近似可能不佳。
- 厚尾/极端值：均值和标准差不稳定，区间可能失真。
- 自相关：标准误低估，区间过窄，覆盖率低于名义水平。
- 异方差：简单标准误不适用。
- 非平稳：参数随时间变化，单一区间的意义有限。
- 零标准差：标准误为 0，区间退化为一个点；软件当前不计算。
- 参数有界：例如相关系数在 `[−1,1]`，普通正态近似区间可能越界。
- 多重比较：同时看很多区间时，至少一个不覆盖的概率上升。
- 样本选择偏差：区间只反映抽样波动，不修正系统性偏差。
- 预测区间：未来单个观测的区间通常比均值置信区间宽，不能用前者替代后者。

### 前置概念

- `standard_error`：置信区间的宽度由标准误和临界值决定。
- `sampling_distribution`：置信区间的覆盖率来自统计量的抽样分布。

### 相关词条

- `standard_error` 标准误
- `p_value` p 值
- `sampling_distribution` 抽样分布
- `t_test` t 检验

### 建议下一篇

`p_value`：置信区间和 p 值从不同角度描述同一检验；p 值回答“是否显著”，区间回答“效应可能多大”。
