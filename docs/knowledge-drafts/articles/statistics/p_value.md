# p 值（p-Value）

## 快速理解

### 一句话解释

p 值是在原假设成立、检验假设也近似成立的前提下，得到当前或更极端检验结果的概率；它不是“原假设为真的概率”，不是“上涨概率”，也不是“策略盈利概率”。

### 它解决什么问题

p 值把 t 统计量映射成一个统一的尾部概率，便于在不同样本量和不同检验之间比较“证据有多不寻常”。它帮助研究者决定是否拒绝原假设，但不能替代效应大小、置信区间、研究设计和经济意义。

### 最常见的误解

- **“p 值是原假设为真的概率”**：p 值是 `P(数据或更极端结果 | H0)`，不是 `P(H0 | 数据)`。
- **“p 值是结果由偶然造成的概率”**：它是在零假设下结果出现的概率，不是“偶然导致”的后验概率。
- **“p 值小就是上涨概率高”**：p 值不区分上涨和下跌；双侧检验对两个方向都计数。
- **“p<0.05 就是策略能赚钱”**：p 值不含交易成本、滑点、风险和样本外表现。
- **“p 值大就证明原假设为真”**：p 值大只表示证据不足，不证明没有效应。
- **“p=0.049 和 p=0.051 有本质区别”**：阈值是人为约定；两个值非常接近，结论不应被当成天壤之别。
- **“页面显示 0.000 就是 p 恰好为 0”**：那是四舍五入后的显示；真实 p 值可能很小但不为 0。

## 软件实践

### 在 Quant Lab 哪里出现

- “统计与机器学习”页的“均值为零检验 p 值”，显示 3 位小数。
- 页面说明使用 `p < 0.05` 解释“在检验假设下对零均值的反证较强”。
- 知识解释“p 值”读取当前 p 值和样本量，用于白话说明。
- p 值来自单样本双侧 t 检验；标准差为 0 时返回 `None`，页面显示“—”。
- 当前没有显著性水平滑块、多重检验校正、效应量或置信区间。

### 输入、输出和单位

- 输入：日收益率样本；至少 3 个有效值；零假设均值 0；双侧检验。
- 输出：p 值，范围 `[0,1]`，无量纲；页面显示 3 位小数。
- p 值不是百分比收益、不是概率预测、不是置信水平。
- 页面同时显示样本量、日均收益率和年化波动率，但 p 值本身不包含这些信息。

### 结果应该怎么读

- 先看 p 值和样本量、日均收益率一起；p 值小但效应很小，可能没有经济意义。
- p 值小表示在零假设下当前结果较不寻常；它不表示零假设为真的概率。
- 双侧检验：极端上涨和极端下跌都会让 p 值变小；p 值小不代表方向。
- 阈值 0.05 是常用约定，不是自然定律；0.049 和 0.051 的差别不应被夸大。
- p 值受样本量影响：样本很大时，很小的均值也可能产生很小的 p 值。
- 反复查看不同股票、区间或策略再挑 p 值最小的结果，会制造假阳性。
- 页面显示“0.000”时，应理解为小于 0.0005 的舍入结果，不是精确的 0。

### 当前软件边界

- 只计算单样本、双侧、均值为 0 的 t 检验 p 值。
- 不提供单侧 p 值、其他零假设值或等效性检验。
- 不提供效应量、置信区间、检验功效或样本量规划。
- 不做多重检验校正（Bonferroni、Holm、FDR 等）。
- 不做稳健标准误、bootstrap、置换检验或贝叶斯因子。
- 不自动判断经济显著性、策略盈利性或样本外可推广性。
- 不检测 p 值操纵、可选停止或数据窥探。

## 专业原理

### 正式定义

设检验统计量为 `T`，观测值为 `t_obs`。p 值是在原假设 `H0` 下，得到与 `t_obs` 至少同样极端结果的概率：

`p = P(T 至少与 t_obs 一样极端 | H0)`

对双侧 t 检验：

`p = 2 × min(P(T ≤ t_obs), P(T ≥ t_obs))`

其中 `T` 服从自由度 `n−1` 的 t 分布（在 `H0` 和近似独立正态等条件下）。

若 `p < α`，在显著性水平 `α` 下拒绝 `H0`；否则不拒绝。`α` 是第一类错误概率上限，由研究者在看数据前选定。

### 公式与符号

- `T`：检验统计量；
- `t_obs`：由样本计算得到的统计量；
- `H0`：原假设；
- `p`：p 值；
- `α`：显著性水平；
- `n`：样本量；
- `df = n−1`：自由度。

### 可手算的小例子

**例 1：t=2.0，df=99。**

双侧 p 值：

`p = 2 × P(T ≥ 2.0) ≈ 2 × 0.02412 = 0.0482`

在 `α=0.05` 下拒绝 `H0`；在 `α=0.01` 下不拒绝。同一个 t 值，因阈值不同而结论不同。

**例 2：效应很小但样本很大。**

假设日收益率样本标准差 `s = 1% = 0.01`，样本量 `n = 1,000,000`，日均收益率 `x̄ = 0.002% = 0.00002`。

标准误：

`SE = 0.01/√1,000,000 = 0.01/1000 = 0.00001`

t 统计量：

`t = 0.00002/0.00001 = 2.0`

自由度约 `999,999`，双侧 p 值约为 `0.0455`，在 5% 水平下显著。但日均 0.002% 的均值非常小，扣除交易成本后未必有经济意义。

**例 3：p 值不是方向概率。**

双侧检验中，均值显著大于 0 和显著小于 0 都可能产生小 p 值。p 值本身不告诉你上涨概率，也不告诉你盈利概率。

### 前提假设

- 原假设和备择假设在看数据前确定。
- 检验统计量在零假设下的分布已知或近似正确。
- 观测近似独立同分布；金融收益常有自相关和厚尾。
- 模型设定正确；遗漏变量和错误分布会扭曲 p 值。
- 只做一次检验，或对多重检验做校正。
- 显著性水平事先确定，不根据结果反复调整。

### 边界情况

- 样本量很小：p 值不稳定，检验功效低。
- 样本量很大：很小的效应也可能显著；统计显著不等于经济显著。
- 厚尾/极端值：t 分布近似可能不准，p 值可能被少数观测主导。
- 自相关/异方差：标准误估计错误，p 值失真。
- 非平稳：零假设下的分布可能随时间变化。
- 多重检验：检验次数增加，至少一次假阳性的概率上升。
- 可选停止：看到显著就停止实验，会抬高假阳性率。
- 模型选择后再检验：同一数据反复调参会让 p 值失去通常解释。
- 舍入：页面 3 位小数会把很小的 p 值显示为 0.000。
- 零标准差：p 值无定义；软件返回 `None`。
