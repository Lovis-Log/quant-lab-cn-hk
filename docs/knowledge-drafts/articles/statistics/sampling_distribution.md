# 抽样分布（Sampling Distribution）

## 快速理解

### 一句话解释

抽样分布是“如果反复从同一总体抽取同样大小的样本，某个统计量（例如均值）会怎样分布”；它描述的是统计量的不确定性，不是某一次样本里单个观测的分布。Quant Lab **当前软件未实现**重采样、模拟或抽样分布图。

### 它解决什么问题

样本均值、标准差和 t 统计量都会随样本变化。抽样分布把这种波动变成可计算的概率结构，是标准误、置信区间和 p 值的理论基础。理解它有助于区分“收益率的分布”和“均值的分布”。

### 最常见的误解

- **“抽样分布就是样本里收益率的分布”**：前者是统计量在重复抽样下的分布，后者是单次样本中观测的分布。
- **“样本量越大，抽样分布越宽”**：在独立同分布条件下，均值抽样分布的标准差按 `1/√n` 缩小。
- **“中心极限定理意味着任何样本量都近似正态”**：它描述样本量增大时的极限行为；小样本、厚尾和强依赖下近似可能很差。
- **“软件画了抽样分布”**：当前没有重采样、模拟、bootstrap 或抽样分布图。
- **“p 值来自实际重复抽样”**：t 检验使用理论 t 分布作为零假设下的参照，不是从数据中模拟抽样分布。
- **“历史日收益率是独立同分布样本”**：金融收益常有自相关、波动聚集和厚尾。

### 输入、输出和单位

当前软件没有抽样分布输入或输出。概念上，构造抽样分布需要：

- 一个总体或数据生成假设；
- 样本量 `n`；
- 统计量 `T(X_1,...,X_n)`，例如样本均值；
- 重复抽样或重采样机制；
- 重复次数。

输出应是统计量的分布、标准差（标准误）或分位数；这些**不是当前软件输出**。

### 结果应该怎么读

- 看到“标准误”时，想到它是统计量抽样分布的标准差，不是单个观测的标准差。
- 看到 p 值时，想到它依赖零假设下的抽样分布；不是当前样本的经验频率。
- 看到样本量增加时，均值的抽样分布通常变窄，但偏差不会自动消失。
- 看到厚尾或强自相关时，不要假设 `1/√n` 缩小规律仍然准确。
- 当前软件没有抽样分布图；任何类似图都来自外部工具或自定义代码。

## 专业原理

### 正式定义

设 `X_1,...,X_n` 是从总体中抽取的样本，统计量 `T = T(X_1,...,X_n)`。`T` 的抽样分布是 `T` 在重复抽样下的概率分布。

对样本均值 `x̄`，若观测独立同分布，且总体均值为 `μ`、方差为 `σ²`，则：

`E[x̄] = μ`

`Var(x̄) = σ²/n`

`SE(x̄) = σ/√n`

当 `n` 增大时，中心极限定理给出 `x̄` 近似正态（在有限方差等条件下）。

### 公式与符号

- `n`：样本量；
- `μ`：总体均值；
- `σ²`：总体方差；
- `x̄`：样本均值；
- `SE(x̄)`：样本均值的标准误；
- `T`：任意统计量；
- `E[·]`、`Var(·)`：期望和方差。

若 `σ` 未知，用样本标准差 `s` 估计：

`SE_hat(x̄) = s/√n`

### 可手算的小例子

取一个很小的总体 `{1, 2, 3, 4}`，总体均值：

`μ = (1 + 2 + 3 + 4)/4 = 2.5`

总体方差：

`σ² = [(1−2.5)² + (2−2.5)² + (3−2.5)² + (4−2.5)²]/4`

`= (2.25 + 0.25 + 0.25 + 2.25)/4 = 5/4 = 1.25`

`σ = √1.25 ≈ 1.1180`

现在有放回地抽取 `n=2` 个观测，共有 `4×4=16` 种等可能样本。样本均值的分布：

| 样本均值 | 出现次数 | 概率 |
| --- | --- | --- |
| 1.0 | 1 | 1/16 |
| 1.5 | 2 | 2/16 |
| 2.0 | 3 | 3/16 |
| 2.5 | 4 | 4/16 |
| 3.0 | 3 | 3/16 |
| 3.5 | 2 | 2/16 |
| 4.0 | 1 | 1/16 |

抽样分布的均值：

`(1×1 + 1.5×2 + 2×3 + 2.5×4 + 3×3 + 3.5×2 + 4×1)/16`

`= (1 + 3 + 6 + 10 + 9 + 7 + 4)/16 = 40/16 = 2.5`

等于总体均值 `μ`。

抽样分布的方差：

`E[x̄²] − 2.5²`

其中 `E[x̄²] = (1²×1 + 1.5²×2 + 2²×3 + 2.5²×4 + 3²×3 + 3.5²×2 + 4²×1)/16`

`= (1 + 4.5 + 12 + 25 + 27 + 24.5 + 16)/16 = 110/16 = 6.875`

所以：

`Var(x̄) = 6.875 − 6.25 = 0.625`

`SE(x̄) = √0.625 ≈ 0.7906`

这也可以用公式核对：

`σ²/n = 1.25/2 = 0.625`

`σ/√n = 1.1180/√2 ≈ 0.7906`

这个例子说明：抽样分布描述的是“样本均值”的分布，不是原始 `{1,2,3,4}` 的分布；它的标准差比单个观测的标准差小。

### 前提假设

- 样本来自定义明确的总体，抽样机制可重复或可近似。
- 观测独立同分布，或至少有可建模的依赖结构。
- 总体方差有限；厚尾分布可能使均值和方差估计不稳定。
- 样本量足够，或使用正确的有限样本分布。
- 统计量的定义在重复抽样中保持不变。
- 历史金融数据不是从固定总体中随机抽取的；时间顺序、结构突变和幸存者偏差会破坏该类比。

### 边界情况

- 小样本：中心极限定理近似可能很差；t 分布也只是一种近似。
- 厚尾：极端值使样本均值和方差的抽样分布不稳定。
- 自相关：有效样本量小于名义样本量，`σ/√n` 低估标准误。
- 异方差：波动率变化使简单标准误失效。
- 非平稳：总体参数随时间变化，抽样分布的概念需要重新定义。
- 选择偏差：样本不是随机抽取时，抽样分布的中心可能偏离总体参数。
- 有限总体：无放回抽样需要有限总体校正；当前未实现。
- 多重统计量：同时查看很多统计量会改变“极端”的含义。
- bootstrap：重采样不是万能的；依赖结构、块长度和样本量会影响结果。
