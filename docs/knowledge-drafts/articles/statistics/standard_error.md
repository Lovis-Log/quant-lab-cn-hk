# 标准误（Standard Error）

## 快速理解

### 一句话解释

标准误衡量样本统计量（通常是均值）在重复抽样下的波动，公式是样本标准差除以 `√n`；它描述“均值有多不稳定”，不是单个日收益率的波动。Quant Lab 在 t 检验内部使用标准误，但**当前页面没有单独显示标准误指标**。

### 它解决什么问题

日均收益率的数值会随样本变化。标准误把样本量和波动率结合起来，告诉我们均值估计的精度；t 检验的分子是均值，分母就是标准误。没有标准误，就无法判断一个均值离 0 是“实质差异”还是“样本噪声”。

### 最常见的误解

- **“标准误就是标准差”**：标准差描述单个观测的离散程度；标准误描述统计量的抽样波动，通常更小。
- **“样本量翻倍，标准误减半”**：标准误按 `1/√n` 缩小；样本量翻倍只把标准误乘以 `1/√2 ≈ 0.707`，要减半需要样本量变为 4 倍。
- **“标准误是未来收益的不确定性”**：它描述样本均值的估计精度，不是未来单日收益的分布。
- **“软件显示了标准误”**：当前页面只显示样本量、日均收益率、年化波动率和 p 值；标准误在 t 检验内部使用，不单独显示。
- **“标准误小就说明策略能赚钱”**：标准误小只说明均值估计更精确；均值可能仍接近 0，且不含交易成本。
- **“自相关下标准误仍然有效”**：正自相关通常使有效样本量变小，简单 `s/√n` 会低估不确定性。

### 输入、输出和单位

- 输入：日收益率样本；样本标准差 `s`（日收益率单位，分母 `n−1`）；样本量 `n`。
- 计算：`SE = s/√n`；`t = (x̄ − 0)/SE`，自由度 `n−1`。
- 输出：标准误本身没有单独显示；p 值显示 3 位小数；均值和波动率按百分比显示。
- 单位：标准误与均值相同，是日收益率单位（小数或百分比）；它不是方差，也不是年化波动率。

### 结果应该怎么读

- 如果页面只显示 p 值，不要反推标准误的唯一值；p 值还取决于自由度和检验方向。
- 日均收益率很小但样本量很大时，标准误可能很小，p 值也可能很小；这不等同于经济上重要。
- 日均收益率较大但波动率很高时，标准误可能很大，p 值不显著；这也不等于“没有收益”。
- 年化波动率是单日收益的标准差乘 `√252`，不是标准误。
- 标准误没有显示，不能用页面上的年化波动率直接替代。
- 比较不同股票或区间时，样本量和自相关结构不同，标准误不可直接比较。

## 专业原理

### 正式定义

设样本 `x_1,...,x_n` 的样本均值为 `x̄`，样本标准差为 `s`。均值标准误的估计为：

`SE(x̄) = s/√n`

在独立同分布、有限方差等条件下，`E[x̄]=μ`，`Var(x̄)=σ²/n`，所以 `SE(x̄)=σ/√n`；用 `s` 估计 `σ` 得到上式。

单样本 t 统计量：

`t = (x̄ − μ_0) / SE(x̄) = (x̄ − μ_0) / (s/√n)`

在零假设 `μ=μ_0` 下，若观测近似独立正态，`t` 服从自由度 `n−1` 的 t 分布。

### 公式与符号

- `x̄`：样本均值；
- `s`：样本标准差（分母 `n−1`）；
- `n`：样本量；
- `SE(x̄)`：均值标准误；
- `μ_0`：零假设下的均值，当前软件为 0；
- `t`：t 统计量；
- `df = n−1`：自由度。

### 可手算的小例子

假设日收益率样本标准差 `s = 1.5% = 0.015`，样本量 `n = 100`。

标准误：

`SE = 0.015/√100 = 0.015/10 = 0.0015 = 0.15%`

如果日均收益率 `x̄ = 0.05% = 0.0005`，则：

`t = 0.0005/0.0015 = 0.3333`

自由度 `df = 99`。双侧 p 值约为 `0.7396`，远大于常用的 0.05，不能拒绝“平均日收益率为 0”。

如果日均收益率 `x̄ = 0.3% = 0.003`，标准误不变：

`t = 0.003/0.0015 = 2.0`

双侧 p 值约为 `0.0482`，在 5% 水平下刚好低于阈值。这个例子说明：同样的波动率和样本量，均值大小改变 t 值和 p 值。

再看样本量：

- `n=100` 时，`SE=0.15%`；
- `n=400` 时，`SE=0.015/20=0.075%`；
- 标准误减半需要样本量变为 4 倍，而不是 2 倍。

### 前提假设

- 观测近似独立同分布，或依赖结构可忽略。
- 样本标准差 `s` 是总体标准差 `σ` 的合理估计。
- 样本量足够，t 分布近似适用。
- 零假设下的均值 `μ_0` 明确；当前为 0。
- 检验是双侧的；当前软件没有方向选择。
- 没有多重检验、数据窥探或根据结果反复调参。

### 边界情况

- `n<2`：样本标准差无定义；软件至少需要 3 个日收益做 t 检验。
- `s=0`：标准误为 0，t 值无定义；软件返回 `None`，不显示 p 值。
- 小样本：t 分布尾部较厚，p 值对正态近似敏感。
- 厚尾：极端值影响 `s` 和标准误；t 检验可能低估尾部风险。
- 正自相关：有效样本量小于 `n`，`s/√n` 低估标准误，p 值偏小。
- 异方差：波动率变化使简单标准误失效。
- 非平稳：均值和方差随时间变化，标准误的解释不稳定。
- 多重检验：反复检验会提高假阳性概率。
- 样本选择偏差：标准误只描述抽样波动，不修正系统性偏差。
