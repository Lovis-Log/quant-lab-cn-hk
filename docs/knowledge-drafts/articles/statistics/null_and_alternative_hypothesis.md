# 原假设与备择假设（Null and Alternative Hypothesis）

## 快速理解

### 一句话解释

原假设 `H0` 是检验开始时假定成立的基准命题，备择假设 `H1` 是与它竞争的方向；Quant Lab 当前固定检验“平均日收益率为 0”，备择假设是“平均日收益率不等于 0”，使用双侧 t 检验，页面没有方向选择器。

### 它解决什么问题

假设检验需要一个明确的基准，才能判断样本结果是否“足够不寻常”。把 `H0`、`H1` 和显著性水平写清楚，可以避免把“没有发现显著差异”误读成“证明了没有差异”，也可以避免事后改变假设方向。

### 最常见的误解

- **“H0 为真的概率就是 p 值”**：p 值是在 `H0` 成立时得到当前或更极端结果的概率，不是 `P(H0|数据)`。
- **“不拒绝 H0 就等于 H0 为真”**：可能只是样本量不足、波动太大或检验功效不够。
- **“H1 一定是我希望成立的方向”**：假设应在看数据前确定；事后选择方向会造成偏差。
- **“H0: 均值=0 表示股票没有收益”**：它只针对日收益率的算术均值，不涵盖风险、复利、成本或未来收益。
- **“双侧和单侧可以随便选”**：方向必须在检验前确定；当前软件固定双侧，没有单侧选项。
- **“p<0.05 就有经济意义”**：统计显著不等于经济显著；还要看效应大小、成本和样本外表现。

## 软件实践

### 在 Quant Lab 哪里出现

- “统计与机器学习”页的“均值为零检验 p 值”。
- 单样本 t 检验的零假设：平均日收益率等于 0；备择假设：平均日收益率不等于 0。
- 当前调用 `scipy.stats.ttest_1samp(..., popmean=0.0)`，使用默认双侧检验。
- 页面没有备择方向选择器（大于 0 / 小于 0）、显著性水平输入或正式的“拒绝/不拒绝”结论按钮。
- 页面说明用“p < 0.05”解释较强反证，但没有把 0.05 做成可调参数。

### 输入、输出和单位

- 输入：日收益率样本；至少 3 个有效值；零假设均值 `μ_0 = 0`。
- 输出：p 值，显示 3 位小数；样本量、日均收益率和年化波动率作为辅助信息。
- 零假设和备择假设都针对“日收益率的算术均值”，单位是日收益率（小数或百分比），不是价格、累计收益或年化收益。
- 当前没有输出检验功效、效应量或置信区间。

### 结果应该怎么读

- 先确认检验的是日收益率的均值，不是中位数、累计收益或年化收益。
- p 值小表示在 `H0` 下当前结果较不寻常；它不表示 `H0` 为真的概率。
- “不拒绝 H0”只表示证据不足，不表示 `H0` 已被证明。
- 双侧检验关注偏离 0 的任一方向；当前没有“只检验上涨”或“只检验下跌”的选项。
- 显著性水平是研究者的决策阈值，不是数据内在属性；页面用 0.05 做解释，但没有让用户选择。
- 统计显著不等于经济显著；日均收益率的绝对值可能很小，扣除成本后没有意义。

### 当前软件边界

- 零假设固定为“平均日收益率为 0”；不能输入其他 `μ_0`。
- 备择假设固定为双侧“不等于 0”；没有单侧方向选择。
- 没有显著性水平滑块、拒绝/不拒绝标签或检验功效计算。
- 不提供等效性检验、非劣效性检验或贝叶斯假设检验。
- 不校正多重检验；反复查看不同股票或区间会增加假阳性。
- 不处理自相关、异方差、厚尾或非平稳下的稳健检验。
- 标准差为 0 时 t 值和 p 值返回 `None`，页面显示“—”。

## 专业原理

### 正式定义

单样本均值检验的假设：

`H0: μ = μ_0`

`H1: μ ≠ μ_0`（双侧）

当前 `μ_0 = 0`。检验统计量：

`t = (x̄ − μ_0) / (s/√n)`

在 `H0` 和近似独立正态等条件下，`t` 服从自由度 `n−1` 的 t 分布。双侧 p 值为：

`p = 2 × min(P(T ≤ t), P(T ≥ t))`

若 `p < α`，在显著性水平 `α` 下拒绝 `H0`；否则不拒绝。`α` 是事先选定的第一类错误概率上限。

### 公式与符号

- `μ`：总体平均日收益率；
- `μ_0`：零假设值，当前为 0；
- `H0`：原假设；
- `H1`：备择假设；
- `x̄`：样本日均收益率；
- `s`：样本标准差；
- `n`：有效日收益数；
- `t`：t 统计量；
- `α`：显著性水平；
- `p`：p 值。

### 可手算的小例子

假设日收益率样本标准差 `s = 1.5%`，样本量 `n = 100`，标准误：

`SE = 1.5%/√100 = 0.15%`

**情形 1：`x̄ = 0.05%`。**

`t = 0.05%/0.15% = 0.3333`

双侧 p 值约为 `0.7396`。在 `α=0.05` 下，`p > α`，不拒绝 `H0`。这表示当前样本没有提供足够证据说明平均日收益率不为 0；不表示平均日收益率一定为 0。

**情形 2：`x̄ = 0.3%`。**

`t = 0.3%/0.15% = 2.0`

双侧 p 值约为 `0.0482`。在 `α=0.05` 下，`p < α`，拒绝 `H0`；但在 `α=0.01` 下，`p > α`，不拒绝 `H0`。同一个样本，结论取决于事先选择的显著性水平。

**情形 3：标准差为 0。**

若所有日收益率相同，`s=0`，t 统计量无定义；软件返回 `None`，不报告无穷大或虚假的显著性。

### 前提假设

- 样本来自定义明确的总体，或至少能代表研究区间。
- 观测近似独立；金融收益常有自相关。
- 分布近似正态，或样本量足够使 t 近似可用。
- 零假设和备择假设在看数据前确定。
- 显著性水平事先确定，不根据 p 值反复调整。
- 只检验一个假设；多重检验需要额外校正。

### 边界情况

- `n<3`：软件报错，不进行检验。
- `s=0`：t 和 p 无定义；软件返回 `None`。
- 厚尾/极端值：t 检验的 p 值可能不可靠。
- 正自相关：标准误被低估，p 值偏小。
- 异方差：波动率变化使简单 t 检验失效。
- 非平稳：均值可能随时间变化，单一 `μ` 的假设不成立。
- 多重检验：反复检验不同股票、区间或策略会提高至少一次假阳性的概率。
- 样本选择偏差：幸存者偏差和前视偏差不会因假设检验而消失。
- 经济显著性：统计显著不等于扣除成本后仍有收益。
