# t 检验（t-Test）

## 快速理解

### 一句话解释

t 检验用“样本均值离假设值有多远”除以“均值的标准误”，得到一个标准化统计量；Quant Lab 当前做单样本、双侧检验，零假设是平均日收益率为 0，页面显示 p 值。

### 它解决什么问题

日均收益率很少恰好为 0。t 检验把均值的大小、样本波动和样本量放在同一个尺度上，帮助判断观察到的均值是否可能只是抽样噪声。它是标准误、p 值和置信区间的共同应用。

### 最常见的误解

- **“t 检验能证明均值不为 0”**：它只能衡量证据强弱；不拒绝不等于证明为 0，拒绝也不等于经济上有意义。
- **“p 值小就是 t 值大”**：p 值还取决于自由度；同样的 t 值，样本量不同，p 值不同。
- **“样本量越大，t 值一定越大”**：样本量增大会缩小标准误，但均值本身也可能变化；t 值不一定单调。
- **“t 检验检验的是价格”**：当前检验的是日收益率的算术均值，不是价格水平。
- **“t 检验对任何收益分布都可靠”**：它依赖近似独立、同分布和有限方差等条件；自相关、厚尾和异方差会削弱解释。
- **“页面显示了 t 值和自由度”**：当前页面显示 p 值；t 值在内部计算，但未单独显示，自由度也未显示。

## 软件实践

### 在 Quant Lab 哪里出现

- “统计与机器学习”页加载历史数据后自动运行单样本 t 检验。
- 指标卡显示“均值为零检验 p 值”；标准差为 0 时显示“—”。
- 检验使用 `scipy.stats.ttest_1samp(daily.to_numpy(), popmean=0.0)`，默认双侧。
- 至少需要 3 个有效日收益率；少于 3 个或含非有限值时，软件报错。
- 知识解释和页面说明强调 p 值不是盈利概率。

### 输入、输出和单位

- 输入：日收益率 `r_t = close_t/close_{t−1} − 1`；有效样本至少 3 个。
- 零假设：平均日收益率 `μ = 0`；备择假设：`μ ≠ 0`（双侧）。
- 计算：样本均值 `x̄`、样本标准差 `s`（分母 `n−1`）、标准误 `s/√n`、`t = x̄/(s/√n)`、自由度 `n−1`。
- 输出：p 值，显示 3 位小数；t 统计量不单独显示。
- 单位：均值和标准误是日收益率单位；t 值无量纲；p 值是无量纲概率。

### 结果应该怎么读

- 先看样本量和日均收益率；p 值必须结合效应大小解释。
- p 值小表示在零假设下当前 t 值或更极端值不常见；它不表示零假设为真的概率。
- 当前是双侧检验；它同时关注均值大于 0 和小于 0 的偏离。
- 标准差为 0 时，软件返回 `None`，不报告无穷大的 t 值。
- 年化波动率高不代表 t 检验一定不显著；标准误还取决于样本量。
- 日均收益率显著不为 0 也不等于策略能盈利；还要考虑成本、滑点、风险和样本外表现。

### 当前软件边界

- 只做单样本 t 检验；没有两样本、配对样本或方差齐性检验。
- 只检验均值是否为 0；不能输入其他零假设值。
- 固定双侧；没有单侧方向选择器。
- 页面显示 p 值；t 值、自由度和标准误未单独显示。
- 不提供置信区间、效应量、检验功效或样本量规划。
- 不做自相关/异方差稳健 t 检验、bootstrap 或置换检验。
- 不校正多重检验；反复查看不同股票或区间会增加假阳性。
- 不处理非平稳、厚尾、生存偏差或前视偏差。

## 专业原理

### 正式定义

单样本 t 检验的原假设为：

`H0: μ = μ_0`

双侧备择假设为：

`H1: μ ≠ μ_0`

检验统计量：

`t = (x̄ − μ_0) / (s/√n)`

其中 `x̄` 是样本均值，`s` 是样本标准差（分母 `n−1`），`n` 是样本量。在 `H0` 和近似独立正态等条件下，`t` 服从自由度 `n−1` 的 t 分布。

当前软件 `μ_0 = 0`，使用双侧 p 值。

### 公式与符号

- `x̄`：样本日均收益率；
- `μ_0`：零假设均值，当前为 0；
- `s`：日收益率样本标准差；
- `n`：有效日收益数；
- `s/√n`：均值标准误；
- `t`：t 统计量；
- `df = n−1`：自由度；
- `p`：双侧 p 值。

### 可手算的小例子

取五个日收益率：

`[1%, −0.5%, 2%, 0%, 1.5%]`

用小数表示：

`[0.01, −0.005, 0.02, 0, 0.015]`

**均值：**

`x̄ = (0.01 − 0.005 + 0.02 + 0 + 0.015)/5 = 0.04/5 = 0.008 = 0.8%`

**偏差：**

`[0.002, −0.013, 0.012, −0.008, 0.007]`

**偏差平方和：**

`0.000004 + 0.000169 + 0.000144 + 0.000064 + 0.000049 = 0.00043`

**样本方差：**

`s² = 0.00043/(5−1) = 0.0001075`

**样本标准差：**

`s = √0.0001075 ≈ 0.0103682 = 1.03682%`

**标准误：**

`SE = 0.0103682/√5 ≈ 0.0046368 = 0.46368%`

**t 统计量：**

`t = 0.008/0.0046368 ≈ 1.7253`

自由度 `df = 4`。双侧 p 值约为 `0.1596`。在 `α=0.05` 下，`p > α`，不拒绝“平均日收益率为 0”。

这个例子说明：日均收益率 0.8% 看起来不小，但样本只有 5 天、波动较大，标准误约 0.464%，所以 t 值只有约 1.73，证据不足以在 5% 水平拒绝零假设。

**边界例子：** 若五个日收益率全为 `0%`，样本标准差为 0，t 值无定义；软件返回 `None`，页面显示“—”，不报告无穷大。

### 前提假设

- 观测近似独立；金融收益常有自相关。
- 观测来自同一分布，均值 `μ` 在样本期稳定。
- 分布近似正态，或样本量足够使 t 分布近似适用。
- 样本标准差能合理估计总体标准差。
- 零假设和备择假设在看数据前确定。
- 没有多重检验、数据窥探或根据 p 值反复调参。

### 边界情况

- `n<3`：软件报错；t 检验至少需要 3 个有效日收益。
- `s=0`：t 和 p 无定义；软件返回 `None`。
- 厚尾/极端值：均值和标准差都可能被少数观测主导。
- 正自相关：标准误低估，p 值偏小。
- 异方差：波动率变化使简单 t 检验失效。
- 非平稳：均值随时间变化，单一 `μ` 的假设不成立。
- 多重检验：反复检验会提高假阳性概率。
- 样本选择偏差：幸存者偏差和前视偏差不会因 t 检验消失。
- 经济显著性：统计显著不等于扣除成本后盈利。
- 频率：检验的是日收益率均值，不是年化收益或累计收益。
