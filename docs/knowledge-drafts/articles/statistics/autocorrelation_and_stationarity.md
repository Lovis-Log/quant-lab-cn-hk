# 自相关与平稳性（Autocorrelation and Stationarity）

## 快速理解

### 一句话解释

自相关是同一序列在不同滞后期的相关性，平稳性是序列的均值、方差和自协方差不随时间系统性变化；两者决定简单 t 检验、独立同分布假设和时间序列交叉验证能否成立。Quant Lab **当前软件未实现** ACF、Ljung–Box、ADF、KPSS、单位根或平稳性检验，只在方法局限中提及相关问题。

### 它解决什么问题

金融收益常有波动聚集、趋势和结构突变。如果收益正自相关，样本均值的标准误会被低估，p 值偏小；如果序列非平稳，历史均值和方差不能代表未来。理解这两个概念可以避免把“独立同分布”当成默认事实。

### 最常见的误解

- **“自相关为 0 就独立”**：零自相关只表示没有线性相关；可能存在非线性依赖或波动聚集。
- **“价格有趋势，所以收益不平稳”**：价格和收益是不同序列；随机游走价格非平稳，但其收益可能接近白噪声。
- **“平稳就是没有趋势”**：弱平稳要求均值、方差和自协方差不随时间变化；没有确定性趋势只是其中一部分。
- **“软件已经做了 ACF、ADF 或 Ljung–Box”**：当前没有这些检验，也没有相关图表。
- **“单位根检验通过就说明可以预测”**：检验结论依赖模型、样本和显著性水平；不保证可预测或可盈利。
- **“自相关只影响描述统计”**：它还会影响标准误、t 检验、交叉验证和回测可信度。

## 专业原理

### 正式定义

给定时间序列 `r_t`，滞后 `k` 的自协方差为：

`γ_k = Cov(r_t, r_{t−k})`

自相关为：

`ρ_k = γ_k / γ_0`

其中 `γ_0 = Var(r_t)`。样本自相关通常用配对观测的样本相关系数估计。

弱平稳（weak stationarity）要求：

- `E[r_t] = μ`，均值不随时间变化；
- `Var(r_t) = γ_0`，方差有限且不随时间变化；
- `Cov(r_t, r_{t−k}) = γ_k`，自协方差只取决于滞后 `k`，不取决于 `t`。

严平稳要求整个联合分布随时间平移不变；弱平稳只约束前两阶矩。

### 公式与符号

- `r_t`：第 t 期收益率；
- `k`：滞后阶数；
- `γ_k`：滞后 k 的自协方差；
- `γ_0`：方差；
- `ρ_k`：滞后 k 的自相关；
- `μ`：均值；
- `T`：样本长度。

随机游走价格：

`P_t = P_{t−1} + ε_t`

价格水平非平稳；若 `ε_t` 是白噪声，价格收益 `P_t/P_{t−1}−1` 近似由 `ε_t/P_{t−1}` 决定，其性质与价格水平不同。

### 可手算的小例子

**例 1：滞后 1 自相关。**

取四个收益率：

`[1%, 2%, 0%, 1%]`

滞后 1 的配对是：

- `(1%, 2%)`
- `(2%, 0%)`
- `(0%, 1%)`

按配对样本 Pearson 相关系数计算：

- 配对 x：`[1%, 2%, 0%]`，均值 `1%`
- 配对 y：`[2%, 0%, 1%]`，均值 `1%`
- x 偏差：`[0, 1%, −1%]`
- y 偏差：`[1%, −1%, 0]`
- 偏差乘积：`0×1% + 1%×(−1%) + (−1%)×0 = −0.0001`
- 样本协方差：`−0.0001/2 = −0.00005`
- x、y 的样本标准差都是 `1% = 0.01`
- 相关系数：`−0.00005/(0.01×0.01) = −0.5`

所以这组小样本的滞后 1 自相关约为 `−0.5`。样本只有 3 个配对，这个数值很不稳定，只用于演示计算，不是统计结论。

**例 2：非平稳的水平序列。**

价格序列 `[10, 11, 12, 13]` 的均值是 11.5，但前两个点的均值是 10.5，后两个点的均值是 12.5。不同子区间的均值不同，说明该水平序列不具备常数均值；这类序列不适合直接用“全样本均值”描述长期中心。

**例 3：平稳性不等于可预测。**

一个白噪声序列可以满足弱平稳，但自相关接近 0，过去值对未来的线性预测能力很弱。平稳性是许多时间序列模型的前提，不是盈利信号。

### 前提假设

- 讨论自相关时，序列的均值和方差不发生结构突变。
- 弱平稳要求前两阶矩稳定；严平稳要求整个分布稳定。
- 样本足够长，滞后阶数远小于样本量。
- 检验模型设定正确；趋势、季节性和结构突变会影响结论。
- 线性自相关不能刻画所有依赖；波动聚集和非线性关系需要其他工具。
- 历史平稳性不保证未来平稳；政策和市场结构会变化。

### 边界情况

- 小样本：自相关估计噪声大，置信带很宽。
- 趋势/结构突变：均值和方差变化会让自相关和单位根检验失真。
- 波动聚集：收益自相关可能接近 0，但平方收益自相关很高。
- 季节性：固定周期的自相关需要季节性模型。
- 近单位根：ADF 等检验功效低，难以区分强持久性和单位根。
- 非线性依赖：零自相关不代表独立。
- 多重检验：对不同滞后逐一检验会增加假阳性。
- 重叠收益：重叠窗口会人为制造自相关。
- 非同步交易：不同资产的价格更新时点不同，会产生交叉自相关。
- 样本选择偏差：幸存者偏差和停牌会改变时间序列结构。
