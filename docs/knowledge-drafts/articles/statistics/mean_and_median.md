# 均值与中位数（Mean and Median）

## 快速理解

### 一句话解释

均值把所有观测相加后除以个数，中位数把观测排序后取中间位置；均值对极端值敏感，中位数更稳健。Quant Lab 显示日均收益率，但**当前没有显示中位数**。

### 它解决什么问题

两者都描述“中心位置”，但回答的问题不同。均值适合继续做代数运算（例如 t 检验的分子），中位数适合在厚尾、偏斜或存在极端值时描述“典型”水平。把两者并列，能避免只看均值而被少数异常日误导。

### 最常见的误解

- **“均值和中位数总是一样”**：对称分布中二者通常接近；偏斜和极端值常使二者分离；非对称样本也可能偶然得到相同或接近的均值与中位数。
- **“均值越大，投资越好”**：均值不含风险、复利路径和成本；高均值可能伴随高波动或极端亏损。
- **“中位数一定比均值更准确”**：中位数更稳健，但不使用全部数值信息；它不一定是更好的收益估计。
- **“日均收益率可以直接乘以 252 得到年化收益”**：算术平均乘以 252 不是复利年化；复利要用几何增长。
- **“软件显示了中位数”**：当前统计页只显示日均收益率；中位数未计算或显示。
- **“均值就是未来期望收益”**：历史样本均值是描述统计，不是未来收益保证。

## 软件实践

### 在 Quant Lab 哪里出现

- “统计与机器学习”页的“日均收益率”，显示日收益率的算术平均值。
- 单样本 t 检验的分子使用日均收益率；标准误使用样本标准差。
- “风险与组合”页的方差/标准差以均值为中心计算偏差，但不单独显示中位数。
- 知识解释和页面说明使用“平均日收益”描述零假设，不使用中位数。
- 组合页的资产收益和组合收益使用算术加权，不计算收益中位数。

### 输入、输出和单位

- 输入：按日期排序的日收益率 `r_t = close_t/close_{t−1} − 1`；t 检验至少 3 个有效收益。
- 输出：日均收益率，单位是日收益率（小数或百分比）。
- 页面按百分比格式显示；例如 `0.0005` 显示为 `0.05%`。
- 中位数当前没有输出；如果计算，单位与日收益率相同。
- 均值是算术平均，不是几何平均，也不是年化收益。

### 结果应该怎么读

- 日均收益率是样本内每一天等权平均的结果，不是投资者实际持有获得的收益。
- 少数极端日可能显著拉动均值；把均值和中位数并列思考，可以判断中心位置是否被极端值主导。
- 日均收益率的符号和大小要结合波动率、样本量和 p 值解释。
- 日均收益率不是“每天都能赚这么多”；实际路径会有涨有跌。
- 日均收益率乘以 252 只是粗略的算术年化，不是复利年化，也不等于累计收益。
- 中位数未显示；不要从页面数字推断中位数。

### 当前软件边界

**分层结论：日均收益率已计算并显示；中位数未计算或显示；几何平均、截尾均值、缩尾均值等稳健中心指标未提供。**

**软件已经计算或显示什么**

- 日均收益率 `mean(r)`；
- 该均值作为 t 检验的分子；
- 方差和标准差以该均值为中心计算偏差；
- 组合日收益是资产日收益的加权平均。

**软件只间接使用什么**

- 均值通过 t 检验影响 p 值；
- 均值通过方差计算影响标准差，但页面不显示均值对风险的分解；
- 组合收益使用资产收益的算术加权，不涉及收益中位数。

**软件没有提供或没有建模什么**

- 日收益率中位数、众数、截尾均值、缩尾均值；
- 均值和中位数的置信区间；
- 均值与中位数的差异检验；
- 几何平均收益、复利年化（统计页不显示）；
- 偏度、峰度、分位数和箱线图；
- 缺失值插补、异常值处理或稳健统计。

## 专业原理

### 正式定义

给定 `n` 个观测 `x_1,...,x_n`，算术均值为：

`x̄ = (1/n)Σx_i`

中位数 `med(x)` 是排序后位于中间的值：

- `n` 为奇数时，中位数是第 `(n+1)/2` 个观测；
- `n` 为偶数时，中位数是第 `n/2` 和第 `n/2+1` 个观测的平均。

### 公式与符号

- `x_i`：第 i 个日收益率；
- `n`：观测数；
- `x̄`：样本均值；
- `med(x)`：样本中位数；
- `Σ`：求和。

中位数对极端值不敏感：把最大观测改得更大，中位数可能不变，均值会改变。

### 可手算的小例子

**例 1：没有极端值。**

日收益率 `[−5%, 0%, 1%, 2%, 3%]`：

- 均值 `= (−5% + 0% + 1% + 2% + 3%)/5 = 1%/5 = 0.2%`
- 排序后仍是 `[−5%, 0%, 1%, 2%, 3%]`，第 3 个是 `1%`，所以中位数 `= 1%`

均值 0.2% 低于中位数 1%，因为 −5% 的亏损拉低了均值。

**例 2：加入一个极端值。**

日收益率 `[−5%, 0%, 1%, 2%, 100%]`：

- 均值 `= (−5% + 0% + 1% + 2% + 100%)/5 = 98%/5 = 19.6%`
- 中位数仍是第 3 个值 `1%`

一个 100% 的极端日把均值从 0.2% 拉到 19.6%，中位数不变。这个例子说明均值对极端值敏感。

**例 3：偶数个观测。**

日收益率 `[1%, 2%, 3%, 10%]`：

- 均值 `= 16%/4 = 4%`
- 排序后中间两个是 `2%` 和 `3%`，中位数 `= (2% + 3%)/2 = 2.5%`

偶数样本的中位数是两个中间值的平均。

### 前提假设

- 均值作为描述统计，不要求正态分布；但作为估计量和检验统计量时，需要抽样假设。
- 中位数只要求可排序；对极端值和厚尾更稳健。
- 观测应代表同一总体、同一频率、同一币种和同一复权口径。
- 收益率是单期简单收益率；多期复合不能直接用均值相加。
- 样本期相对稳定；结构突变会改变中心位置。

### 边界情况

- 空样本：均值和中位数都无定义。
- 全部相同：均值和中位数相同；方差为 0。
- 极端值：均值被拉动，中位数较稳定。
- 偏斜分布：均值和中位数分离；不能互相替代。
- 偶数样本：中位数需要平均两个中间值。
- 缺失值：删除或插补会改变样本和中心位置。
- 不同频率/币种：均值的单位不同，不能直接比较。
- 自相关/非平稳：样本均值的时间位置可能不代表稳定中心。
- 复利：算术均值不是复合收益；多期增长要用几何平均。
