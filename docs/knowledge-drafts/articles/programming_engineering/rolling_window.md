# 滚动窗口（Rolling Window）

## 快速理解

### 一句话解释

滚动窗口沿着序列逐行移动，每次只看最近 N 行做计算；Quant Lab 用 `rolling(window=N, min_periods=N).mean()` 计算均线，用滚动标准差计算 10 日波动率。

### 它解决什么问题

单日价格噪声大，研究者想看“最近一段时间”的平均或波动。滚动窗口把固定长度的历史片段逐日更新，得到随时间变化的平滑指标；窗口长度和最少观测数决定结果的滞后与预热。

### 最常见的误解

- **“窗口按自然日计算”**：当前按行/交易日计算；停牌或缺失行不会被自然日补齐。
- **“第一天就有完整窗口”**：前 N−1 行通常不足 N 个观测，结果是 NaN。
- **“`rolling` 会自动补齐缺失交易日”**：不会；它只处理输入中已有的行。
- **“`min_periods` 默认是 1”**：pandas 的 `rolling(window).mean()` 默认要求窗口内足够观测；项目在均线函数中显式写 `min_periods=N`。
- **“滚动均值能预测未来”**：它只是过去 N 行的平均，不包含未来信息。
- **“窗口越大越好”**：窗口越大越平滑、越滞后；没有通用最优值。

## 软件实践

### 在 Quant Lab 哪里出现

- `strategy.moving_average` 使用 `close.rolling(window=window, min_periods=window).mean()`。
- 单均线、双均线和趋势过滤都依赖这条均线。
- `statistics.supervised_frame` 使用 `close.rolling(5).mean() / close.rolling(20).mean() - 1` 生成 5/20 日均线差。
- 同一函数使用 `return_1.rolling(10).std(ddof=1)` 生成 10 日收益波动率。
- `metrics.performance_stats` 不直接使用 `rolling`，但用全样本标准差计算年化波动率；两者口径不同。
- 回测的移动止损或滚动风控没有实现；当前滚动窗口主要用于均线、特征和教学。

### 输入、输出和单位

- 输入是按时间升序排列的数值序列，通常为收盘价或收益率。
- `window` 是观测行数，不是自然日数；`N=20` 表示最近 20 个交易日。
- 均值输出与输入同单位；价格均线的单位是每股价格。
- 标准差输出与输入同单位；收益率标准差是收益率单位，不是价格。
- 窗口不足时输出 NaN；`min_periods` 决定最少需要多少非缺失观测。
- `ddof=1` 表示样本标准差，分母为 `n-1`。

### 结果应该怎么读

- 前 N−1 行 NaN 是预热，不是数据错误。
- 5/20 日均线差要等 20 日均线形成后才有效；虽然 5 日均线更早形成，但比值仍需两者都有效。
- 10 日波动率需要 10 个有效收益观测；第一行收益率 NaN 会让窗口进一步后移。
- 窗口跨越停牌或缺失行时，实际覆盖的自然时间可能超过 N 天。
- 滚动标准差为 0 表示窗口内收益不变；这不代表未来没有波动。

### 当前软件边界

- 均线只使用简单移动平均，不使用指数加权或自适应窗口。
- 窗口长度在策略中限制为 2 到 250 个交易日。
- `rolling` 不补齐停牌日、节假日或缺失交易日。
- 当前没有滚动回归、滚动相关、滚动夏普或滚动最大回撤指标。
- 滚动窗口不自动做年化；年化因子由其他函数单独乘上。
- 文章中的 `rolling` 示例是通用 pandas，不代表软件提供任意窗口配置界面。

## 专业原理

### 正式定义

给定序列 `x_1, ..., x_T` 和窗口 `N`，滚动统计量在每个位置 `t` 使用最近的 `N` 个观测：

`window_t = (x_{t-N+1}, ..., x_t)`

滚动均值：

`MA_N(t) = (1/N) × Σ_{i=0}^{N-1} x_{t-i}`

滚动样本标准差：

`s_N(t) = sqrt( (1/(N-1)) × Σ_{i=0}^{N-1} (x_{t-i} - MA_N(t))^2 )`

当 `t < N` 或窗口内有效观测少于 `min_periods` 时，结果为 NaN。

### 公式与符号

- `N`：窗口长度（行数）；
- `x_t`：t 行数值；
- `MA_N(t)`：滚动均值；
- `s_N(t)`：滚动样本标准差；
- `min_periods`：窗口内最少有效观测数；
- `ddof=1`：样本标准差分母 `N-1`。

### 可手算的小例子

序列：10、12、14、13、15；窗口 `N=3`。

3 日滚动均值：

- t1：不足 3 行，NaN；
- t2：不足 3 行，NaN；
- t3：`(10+12+14)/3 = 12.00`；
- t4：`(12+14+13)/3 = 13.00`；
- t5：`(14+13+15)/3 = 14.00`。

3 日滚动样本标准差（`ddof=1`）：

- t3：`sqrt(((10-12)² + (12-12)² + (14-12)²)/2) = sqrt(8/2) = 2.00`；
- t4：`sqrt(((12-13)² + (14-13)² + (13-13)²)/2) = sqrt(2/2) = 1.00`；
- t5：`sqrt(((14-14)² + (13-14)² + (15-14)²)/2) = sqrt(2/2) = 1.00`。

5/20 日均线差示例：

- 5 日均线从第 5 行起有效；
- 20 日均线从第 20 行起有效；
- 两者比值从第 20 行起才有效，前 19 行为 NaN；
- 因此 `ma_gap_5_20` 的预热由较长窗口决定。

### 前提假设

- 输入按时间升序排列，行与行之间是相邻观察期。
- 窗口内观测足以计算所选统计量；不足时返回 NaN。
- 缺失值不会被自动填补；含 NaN 的窗口通常产生 NaN。
- 窗口长度在研究期间保持不变；改变窗口会改变指标含义。
- 滚动统计量只使用窗口内及更早的数据，不使用未来数据。

### 边界情况

- 观测数少于 N：整列 NaN；策略信号为 0。
- `N=1`：均值等于原值，标准差通常无法计算（`ddof=1` 分母为 0）；项目均线最小窗口为 2。
- 窗口内价格恒定：标准差为 0；均线仍可计算。
- 窗口内有 NaN：默认结果可能为 NaN，除非设置 `min_periods` 小于窗口并允许部分观测。
- 停牌或缺失交易日：窗口跨越更长自然时间，但行数仍是 N。
- 最后一行：滚动统计量可以使用到最后一行，不需要未来数据。
- 不同频率：日线窗口和月线窗口不可直接比较。
- 不同复权口径：均线值不可直接比较；收益率窗口也可能因复权跳变而失真。
