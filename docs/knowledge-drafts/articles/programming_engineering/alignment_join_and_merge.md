# 对齐、连接与合并（Alignment, Join, and Merge）

## 快速理解

### 一句话解释

对齐是按索引或键把来自不同表的值配对；Quant Lab 的组合分析按日期内连接，只保留所有资产都有收盘价的共同交易日，回测则要求原始价格与信号价格的日期序列完全一致。

### 它解决什么问题

不同股票的交易日可能不完全相同：A 股和港股节假日不同，个股也可能停牌。直接把两列价格相减或拼接，会让日期错位。连接规则明确“保留哪些日期、缺失日期怎么办”，避免把不同日期的值配在一起。

### 最常见的误解

- **“内连接会补齐缺失日期”**：内连接只保留两边都有的键；缺失日期被排除，不是补值。
- **“外连接更安全，因为保留所有数据”**：外连接会引入 NaN 行；后续计算若未处理，会产生错误结果。
- **“按行号对齐和按日期对齐一样”**：pandas 默认按索引标签对齐，不是按位置；行号相同不代表日期相同。
- **“`merge` 和 `concat` 完全一样”**：`concat` 主要沿轴拼接，`merge` 按键做数据库式连接；语义不同。
- **“重复日期只会多一行”**：重复键在连接时可能产生笛卡尔式膨胀，导致行数成倍增加。
- **“日期相同就能直接计算”**：还要确认时区、复权口径、币种和数值单位一致。

## 软件实践

### 在 Quant Lab 哪里出现

- `portfolio.align_closes`：每只股票用 `set_index("date")["close"]` 变成日期索引 Series，再用 `pd.concat(..., axis=1, join="inner").dropna()` 得到共同收盘价表。
- 组合要求 2–4 只股票，共同收盘日至少 8 天；不足时抛出 `ValueError`。
- `research.run_experiment`：比较 `raw_history["date"]` 与 `signal_history["date"]`，要求逐行完全相等，否则报“信号价格与原始成交价格的交易日不一致”。
- `processing.clean_stock_history`：按日期排序并拒绝重复交易日。
- `strategy.build_signals` 和 `statistics.supervised_frame` 要求日期唯一且升序。
- 组合核心函数不掌握币种；同市场、同币种限制由界面上下文保证。

### 输入、输出和单位

- 输入是多只股票的行情表，每只表包含 `date` 和 `close`。
- 输出是日期索引的共同收盘价表；列名是股票代码，值是每股价格。
- 共同日期数量是输出的行数；不是任何单只股票的全部日期数。
- 价格单位由市场决定；同一组合要求同币种，避免 CNY 与 HKD 直接相加。
- 信号和原始价格对齐时，日期序列长度和顺序都必须逐行完全一致；两者单位相同（均为对应市场币种/股），但价格口径和数值尺度可能不同（复权信号价 vs 不复权成交价）。

### 结果应该怎么读

- 输出日期变少是正常的：只有所有资产都有收盘价的日期才保留。
- 如果共同日期少于 8 天，组合分析会拒绝；这不是程序崩溃，而是样本不足。
- 如果信号与原始价格日期不一致，回测会拒绝；不能强行截断或填补。
- 如果两只股票的共同日期很少，相关性和组合曲线只代表这些日期，不代表整个区间。
- 如果一只股票停牌，内连接会排除该日；不会用前一日收盘价代替。

### 当前软件边界

- 组合使用日期内连接，不使用外连接、前向填充或插值。
- 回测研究不是任意 `merge`；它要求原始价格与信号价格日期序列完全相等。
- 当前没有多表按多个键连接、模糊匹配、时间区间连接或最近邻连接。
- 不同市场、不同币种不能直接组成一个组合；界面限制同市场。
- 当前不建模停牌日的持仓估值或交易延迟；停牌只表现为日期缺失或零成交量。
- 文章中的 `merge` 示例是通用 pandas，不代表软件提供任意数据连接界面。

## 专业原理

### 正式定义

- 对齐（alignment）：按索引标签把两个对象的元素配对；标签不匹配的位置产生缺失值。
- 连接（join）：按索引或键合并两个表；常见类型为 inner、left、right、outer。
- 合并（merge）：按键列做数据库式连接，可指定 `on`、`left_on`、`right_on`、`how` 等参数。
- 内连接（inner join）：只保留两边键都存在的行。
- 外连接（outer join）：保留任一边存在的键，缺失一侧填 NaN。
- 左连接/右连接：保留左表/右表的所有键。

### 公式与符号

共同日期集合：

`D_common = D_1 ∩ D_2 ∩ ... ∩ D_n`

内连接结果的行数：

`rows_inner ≤ min(rows_1, rows_2, ..., rows_n)`

若键重复，连接结果可能大于任一边的行数；因此日期唯一性是重要前提。

### 可手算的小例子

两只资产的收盘价：

- A：2026-10-19 = 10，2026-10-20 = 11，2026-10-21 = 12；
- B：2026-10-20 = 20，2026-10-21 = 21，2026-10-22 = 22。

内连接后的共同日期：

- 2026-10-20：A=11，B=20；
- 2026-10-21：A=12，B=21。

共 2 天；10-19 只有 A，10-22 只有 B，均被排除。

通用 Python 示例（不是软件功能）：

```python
import pandas as pd

a = pd.Series([10.0, 11.0, 12.0], index=pd.to_datetime(["2026-10-19", "2026-10-20", "2026-10-21"]))
b = pd.Series([20.0, 21.0, 22.0], index=pd.to_datetime(["2026-10-20", "2026-10-21", "2026-10-22"]))
inner = pd.concat([a, b], axis=1, join="inner")
print(inner.shape)   # (2, 2)
```

若改用 `join="outer"`，结果会有 4 天，并在缺失位置出现 NaN；那不是当前组合的做法。

外连接示意：

| 日期 | A | B |
| --- | --- | --- |
| 2026-10-19 | 10 | NaN |
| 2026-10-20 | 11 | 20 |
| 2026-10-21 | 12 | 21 |
| 2026-10-22 | NaN | 22 |

### 前提假设

- 日期索引唯一；重复日期会让连接结果膨胀或报错。
- 日期已排序；排序不会改变日期集合，但会影响时间序列计算。
- 同一组合内的价格使用同一币种和相近的复权口径。
- 内连接后的样本量足以支持后续计算；组合要求至少 8 天。
- 信号与原始价格来自同一交易日序列；复权口径可以不同，但日期必须一致。
- 缺失日期不会被自动解释为停牌或休市；需要结合交易日历和数据源判断。

### 边界情况

- 日期集合完全不相交：内连接结果为空，组合分析报样本不足。
- 一只资产只有 1 天数据：内连接最多 1 天，低于 8 天门槛。
- 重复日期：项目在清洗和组合输入阶段拒绝；不要依赖连接自动去重。
- 时区不一致：同一交易日在不同时区可能显示为不同日期；应先统一。
- 不同频率：日线连接月线会产生大量缺失；当前不处理。
- 键名冲突：`concat` 的列名重复时需要区分；当前用股票代码作为列名，要求代码不重复。
- 外连接后直接计算：NaN 会传播到收益率和相关性；当前不使用外连接。
- 汇率不同：即使日期对齐，CNY 和 HKD 价格也不能直接相加；当前界面限制同币种。
