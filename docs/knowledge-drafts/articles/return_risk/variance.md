# 方差（Variance）

## 快速理解

### 一句话解释

方差是“每个观测离均值有多远”的平方的平均；它衡量收益率的离散程度，单位是收益率的平方，所以不能直接读成百分比波动。

### 它解决什么问题

它把“波动大小”变成一个可计算的数，是标准差、协方差、波动率和夏普比率的基础。它也提醒我们：只看平均收益不看离散程度，会忽略风险。

### 最常见的误解

- **“方差是百分比”**：方差单位是收益率的平方；标准差才回到收益率单位。
- **“样本方差和总体方差一样”**：样本方差分母是 `n−1`，总体方差分母是 `n`；本软件使用样本方差。
- **“方差越大，收益越高”**：方差只描述离散程度，不描述方向或收益水平。
- **“方差可以直接年化”**：在独立同分布近似下，方差可按 252 缩放，但软件显示的是日样本方差/标准差和年化波动率，不是年化方差指标。
- **“只有一个观测也能算方差”**：至少需要两个观测；样本方差在 `n=1` 时无定义。

## 软件实践

### 在 Quant Lab 哪里出现

- “风险与组合”页“日收益率样本方差”，显示 6 位小数。
- 指标模块和统计模块的 `var(ddof=1)`。
- 知识解释“方差”。
- 组合页的协方差矩阵以方差为对角线基础。
- 波动率和夏普比率使用标准差（方差的平方根）。

### 输入、输出和单位

- 输入：按时间排序的日收益率，通常用小数表示（`1% = 0.01`）。
- 输出：样本方差，单位是“收益率小数”的平方。
- 页面显示 6 位小数；例如 `0.000100` 对应收益率标准差 `0.01 = 1%`。
- 如果用百分数计算，方差单位是“百分数的平方”（`%²`）；数值会相差 10,000 倍。
- 样本方差分母 `n−1`；总体方差分母 `n`。软件当前使用样本口径。

### 结果应该怎么读

- 先把方差开平方得到标准差，再换成百分数，才有直观的“波动百分比”。
- 不要把 `0.0001` 读成 0.01%；它的平方根是 `0.01 = 1%`。
- 方差对极端值敏感；一个异常日可能显著抬高方差。
- 比较不同频率（日/周/月）的方差时，不能直接比较；年化波动率使用日标准差 × `√252`。
- 方差是历史样本描述，不是未来风险预测。

### 当前软件边界

- 当前只使用样本方差（分母 `n−1`），不提供总体方差按钮或切换。
- 风险页显示日收益率样本方差；年化波动率由标准差换算，不直接显示年化方差。
- 不提供稳健方差、GARCH、已实现波动率或置信区间。
- 不处理非同步交易、自相关、厚尾或缺失数据带来的偏差；这些会削弱方差解释。
- 复权/币种/频率口径变化会影响方差；相关行为 NEEDS_REVIEW（核验日期：2026-10-22）。

## 专业原理

### 正式定义

给定 `n` 个收益率观测 `x_1, ..., x_n`，样本均值：

`x̄ = (1/n)Σx_i`

样本方差：

`s² = Σ(x_i − x̄)² / (n−1)`

总体方差（如果 `x` 是完整总体）：

`σ² = Σ(x_i − μ)² / n`

其中 `μ` 是总体均值。样本方差使用 `n−1`，是对总体方差的无偏估计。

### 公式与符号

- `x_i`：第 i 个收益率观测，小数；
- `x̄`：样本均值；
- `n`：观测数；
- `s²`：样本方差；
- `σ²`：总体方差；
- `Σ`：求和。

标准差是 `s = √s²`；单位回到收益率。年化波动率近似：

`σ_annual ≈ s_daily × √252`

这是标准差的缩放，不是方差的直接显示。

### 可手算的小例子

**例 1：收益率 −1%、0、1%。**

用小数：

- `x = [−0.01, 0, 0.01]`；
- 均值 `x̄ = 0`；
- 偏差 `[−0.01, 0, 0.01]`；
- 平方 `[0.0001, 0, 0.0001]`；
- 平方和 `0.0002`；
- 样本方差 `s² = 0.0002/(3−1) = 0.0001`；
- 总体方差 `σ² = 0.0002/3 ≈ 0.00006667`；
- 样本标准差 `s = √0.0001 = 0.01 = 1%`；
- 总体标准差 `σ = √0.00006667 ≈ 0.008165 = 0.8165%`。

用百分数：

- `x = [−1%, 0%, 1%]`；
- 均值 0%；
- 平方 `[1, 0, 1]`，单位 `%²`；
- 样本方差 `2/(3−1)=1 %²`；
- 总体方差 `2/3≈0.6667 %²`；
- 样本标准差 `1%`，总体标准差约 `0.8165%`。

两种写法描述同一组数据；不要把小数方差 `0.0001` 和百分数方差 `1 %²` 混为不同风险。

**例 2：样本 1、2、3。**

- 均值 2；
- 偏差 `−1, 0, 1`；
- 平方和 `2`；
- 样本方差 `2/(3−1)=1`；
- 总体方差 `2/3≈0.6667`；
- 标准差分别为 1 和 0.8165。

**例 3：方差不是百分比。**

- 若日收益率方差为 `0.0001`，标准差是 `0.01=1%`；方差本身不是 1%。
- 若把方差写成 `1%`，再开平方会得到错误结果。

### 前提假设

- 至少两个有效观测；收益率有限且同一频率。
- 样本方差使用 `n−1`；总体方差使用 `n`，两者不能混用。
- 收益率近似独立同分布时，年化波动率才可用 `√252` 缩放；自相关、厚尾和非平稳会削弱该近似。
- 方差描述历史离散程度，不描述方向、未来收益或因果关系。

### 边界情况

- `n=1`：样本方差无定义（分母为 0）。
- 所有收益率相同：方差为 0；标准差为 0；夏普比率可能无定义。
- 极端值/异常值：方差被平方放大，可能由单日主导。
- 缺失数据、停牌、不同频率：有效样本数和间隔改变。
- 自相关、波动聚集、厚尾：简单方差可能低估或高估风险。
- 百分数和小数混用：数值相差 10,000 倍。
- 样本/总体分母混用：数值不同，解释不同。
