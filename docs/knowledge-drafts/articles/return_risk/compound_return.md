# 复合收益（Compound Return）

## 快速理解

### 一句话解释

复合收益是多期收益连续乘起来的结果：每一期的收益都改变下一期的本金，所以多期收益不能直接相加；100 先涨 10% 再涨 10% 是 121，不是 120。

### 它解决什么问题

它描述财富随时间累积的真实路径，是累计收益、净值曲线、年化收益和最大回撤的基础。它也让“先涨后跌”的非对称性变得清楚：跌 50% 后要涨 100% 才回本。

### 最常见的误解

- **“多期收益可以直接相加”**：`10%+10%=20%` 只在极短或近似情形下接近；实际复合是 `1.1×1.1−1=21%`。
- **“平均收益就是最终收益”**：算术平均不包含复利和波动拖累；最终财富由乘积决定。
- **“先涨 10% 再跌 10% 回到原值”**：`1.1×0.9=0.99`，最终 −1%。
- **“跌 50% 后涨 50% 就回本”**：`0.5×1.5=0.75`，仍亏 25%；回本需要涨 100%。
- **“累计收益和年化收益是一回事”**：累计收益看整段，年化收益按年换算；短样本年化可能被放大。

## 软件实践

### 在 Quant Lab 哪里出现

- 历史回测“策略累计收益”和净值曲线。
- 风险与组合的样本外累计净值。
- Quant Academy 第 1 课“简单收益率与复利”。
- 知识解释“复利”和“年化收益估计”。

### 输入、输出和单位

输入是一段按时间排序的收益率 `r_1, ..., r_n` 或净值序列 `V_0, ..., V_n`。输出是累计收益：

`R_cum = V_n/V_0 − 1`

- `0.21` 是小数，等于 `21%`。
- 净值 `V` 的币种与市场一致（CNY 或 HKD）；收益率无量纲。
- 收益率序列的观测数、净值观测数和收益间隔数要分清：`n` 期收益对应 `n+1` 个净值点。
- 计算多期收益的样本方差时，分母是收益观测数减一（`n−1`），见 `variance`。

### 结果应该怎么读

- 先看累计收益的起点和终点，再看中间路径；同样的累计收益可能有完全不同的回撤。
- 把百分比换成小数再乘：`+10%` 是 `×1.10`，`−10%` 是 `×0.90`。
- 多期收益的顺序不影响最终乘积（忽略费用和现金流），但会影响路径和回撤。
- 累计收益不是年化收益；跨不同长度比较时要看年化和样本长度。
- 分红、费用、滑点和汇率是否包含，取决于净值序列的构建；当前价格收益率不自动包含这些。

### 当前软件边界

- 回测累计收益基于净值序列，净值已扣模拟费用和滑点；但不是真实可实现收益。
- 市场页区间收益率是价格收益率，不含分红、费用和滑点。
- 年化收益另算，使用 252 个年交易日近似；不是未来预测。
- 当前不处理外部现金流（申购/赎回）的 time-weighted return 或 money-weighted return；输入被当作一次性本金。
- 复权、分红和公司行动会影响价格序列；相关行为 NEEDS_REVIEW（核验日期：2026-10-22）。

## 专业原理

### 正式定义

给定各期简单收益率 `r_1, ..., r_n`，期末财富为：

`V_n = V_0 × (1+r_1)(1+r_2)...(1+r_n)`

复合收益（累计收益）为：

`R_cum = V_n/V_0 − 1 = ∏_{i=1}^{n}(1+r_i) − 1`

若每期收益率固定为 `r`，则：

`V_n = V_0(1+r)^n`

`R_cum = (1+r)^n − 1`

复合收益是几何增长；它不是各期收益的算术和。

### 公式与符号

- `V_0`：期初财富/本金；
- `V_n`：期末财富；
- `r_i`：第 i 期简单收益率，小数；
- `n`：期数；
- `∏`：连乘；
- `R_cum`：累计收益率，小数。

与算术平均的关系：若 `a = (1/n)Σr_i`，则一般情况下 `R_cum` 不等于 `(1+a)^n−1`；波动越大，差异越明显。

### 可手算的小例子

**例 1：连续上涨。**

- 本金 100，连续两期各涨 10%：
  - 第 1 期：`100×1.10=110`；
  - 第 2 期：`110×1.10=121`；
  - 累计收益：`121/100−1=0.21=21%`；
  - 不是 `10%+10%=20%`。

**例 2：先涨后跌。**

- `100 → 110 → 99`：
  - 第 1 期 `+10%`；
  - 第 2 期 `99/110−1=−10%`；
  - 累计：`99/100−1=−0.01=−1%`；
  - 不是 0%。

**例 3：跌后回本。**

- `100 → 50 → 100`：
  - 第 1 期 `−50%`；
  - 第 2 期 `100/50−1=+100%`；
  - 累计：`100/100−1=0%`；
  - 跌 50% 后需要涨 100% 才回本，不是涨 50%。

**例 4：多期三连。**

- `100 → 110 → 121 → 108.9`：
  - 收益：`+10%`、`+10%`、`−10%`；
  - 累计：`108.9/100−1=8.9%`；
  - 连乘：`1.10×1.10×0.90=1.089`；
  - 不是 `10%+10%−10%=10%`。

### 前提假设

- 收益率序列按时间排序，且每期收益作用于上一期期末财富。
- 没有外部现金流（追加投资、赎回）打断复合；否则需要 time-weighted 或 money-weighted 方法。
- 收益率与净值使用同一币种、同一复权口径、同一费用口径。
- 历史复合收益不是未来收益预测。

### 边界情况

- 期初财富为零或负数：比值无定义或不可解释。
- 某一期收益率为 −100%：财富归零，后续乘法仍为零。
- 收益率小于 −100%：价格/净值不能为负，通常意味着数据或模型有误。
- 分红、费用、税费、滑点：是否包含取决于净值口径。
- 外部现金流、定投、赎回：简单复合公式不适用。
- 百分数和小数混用：`0.10` 是 10%，`10` 是 1000%。
