# 年化收益（Annualized Return）

## 快速理解

### 一句话解释

年化收益是把一段区间的累计收益按固定年交易日数换算成“每年增长多少”的几何比率；它是历史换算，不是未来一年预测，短样本会把数值放大。

### 它解决什么问题

它让不同长度的区间可以在“每年”这个统一尺度上比较。比如 100 到 110 的 10% 累计收益，在 1 年和半年里的年化结果不同；年化让时间长度进入比较。

### 最常见的误解

- **“年化收益就是未来一年收益”**：它是把历史累计收益按年换算，不预测未来。
- **“半年 10% 等于年化 10%”**：半年 10% 若继续复利，年化约 21%，不是 10%。
- **“年化收益可以脱离样本长度和波动单独看”**：短样本、剧烈波动和高费用会让年化数值失真。
- **“252 是每年实际交易日”**：252 是年化近似假设，不自动适应每个市场、年份或停牌。
- **“年化收益是算术平均”**：年化复合收益是几何换算，不是把日收益简单平均后乘 252。

## 软件实践

### 在 Quant Lab 哪里出现

- 历史回测“年化收益估计”指标。
- 指标模块 `performance_stats` 的 `annualized_return`。
- 知识解释“年化收益估计”和 Quant Academy 的复利课程。
- 风险与组合页的样本外统计表包含累计收益、年化波动率和最大回撤；年化收益主要在回测页显示。

### 输入、输出和单位

输入是净值/价格序列的起点和终点，以及收益间隔数 `n`。输出是年化收益小数：

`R_annual = (V_end/V_start)^(252/n) − 1`

- `0.10` 是小数，等于 `10%`。
- `n` 是收益间隔数，等于净值/价格观测数减一；不是自然日数。
- 252 是假设的年交易日数；不同市场、年份和停牌会影响实际交易日数。
- 若 `n=0` 或净值非正，公式无定义；当前指标至少需要两个正的有限净值。

### 结果应该怎么读

- 先看样本长度：同样的累计收益，区间越短，年化数值越容易被放大。
- 再看波动和回撤：年化收益不描述路径，不能单独作为风险判断。
- 把年化收益和累计收益一起读：`(1+R_annual)^(n/252)−1` 应回到累计收益。
- 年化收益不是费用后的可实现收益；回测净值已扣模拟费用，但不是实盘。
- 不要用年化收益比较不同币种、不同复权口径或不同市场而不说明口径。

### 当前软件边界

- 年化收益是按 252 个年交易日换算的几何近似，不是未来预测。
- 当前不提供年化收益的置信区间、显著性检验或概率表述。
- 不自动适应市场日历、停牌、半日市或个股交易日数量。
- 不处理外部现金流；输入被当作一次性本金。
- 252 假设、费用/分红/复权口径和上游数据可能变化；NEEDS_REVIEW（核验日期：2026-10-22）。

## 专业原理

### 正式定义

年化收益（annualized return，常与 CAGR 概念相近）把一段区间的累计增长换算成每年固定复利增长率。给定期初值 `V_0`、期末值 `V_n` 和收益间隔数 `n`，年化收益为：

`R_annual = (V_n/V_0)^(252/n) − 1`

它假设每年有 252 个交易日，并把区间增长按相同比例复利到一年。

### 公式与符号

- `V_0`：期初净值/价格；
- `V_n`：期末净值/价格；
- `n`：收益间隔数（净值观测数 − 1）；
- `252`：假设的年交易日数；
- `R_annual`：年化收益率，小数。

与累计收益 `R_cum = V_n/V_0 − 1` 的关系：

`1 + R_annual = (1 + R_cum)^(252/n)`

若区间正好 252 个收益间隔，年化收益等于累计收益；126 个间隔时，年化是累计增长因子的平方再减一，即 `(1+R_cum)^2−1`。

### 可手算的小例子

**例 1：252 个收益间隔。**

- `V_0=100`，`V_n=110`，`n=252`。
- 累计收益：`110/100−1=10%`。
- 年化：`(1.10)^(252/252)−1=10%`。

**例 2：126 个收益间隔。**

- `V_0=100`，`V_n=110`，`n=126`。
- 累计收益仍是 10%。
- 年化：`(1.10)^(252/126)−1=1.10²−1=0.21=21%`。
- 这表示“如果按同样的半年增长复利一年”的换算值，不是承诺未来一年赚 21%。

**例 3：63 个收益间隔。**

- `V_0=100`，`V_n=110`，`n=63`。
- 年化：`(1.10)^(252/63)−1=1.10⁴−1=1.4641−1=46.41%`。
- 区间越短，同样的 10% 被放大得越多；短样本年化要谨慎。

**例 4：下跌。**

- `V_0=100`，`V_n=90`，`n=126`。
- 累计收益：`−10%`。
- 年化：`(0.90)²−1=0.81−1=−19%`。
- 不是 `−10%`；几何换算对亏损也会放大。

**例 5：收益间隔数不是观测数。**

- 价格序列有 127 个观测（126 个收益间隔），累计从 100 到 110。
- `n=126`，不是 127；年化 21%，不是 `(1.10)^(252/127)−1`。
- 如果误用自然日数（例如 365），会得到另一组数值；必须明确 `n` 是收益间隔数。

### 前提假设

- 期初/期末值为正且有限；收益率按几何复利理解。
- 区间内没有外部现金流；否则需要 time-weighted/money-weighted 方法。
- 252 是年交易日近似；不声称适用于每个市场、年份或个股。
- 历史年化不是未来收益预测；样本长度、波动、费用和偏差会影响解释。

### 边界情况

- `n=0`：没有收益间隔，无法年化。
- 期初或期末为零/负数：比值无定义。
- 极短样本：年化数值可能极大或极小；不应单独汇报。
- 高波动、费用、税费、滑点、分红、汇率：会影响净值口径。
- 不同市场/年份的实际交易日数不同；252 只是近似。
- 百分数和小数混用：`0.21` 是 21%，`21` 是 2100%。
