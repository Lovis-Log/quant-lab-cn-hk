# 夏普比率（Sharpe Ratio）

## 快速理解

### 一句话解释

夏普比率是“每承担一单位历史波动，平均获得多少超额收益”；本软件用日超额收益均值除以日收益样本标准差，再乘 `√252` 年化，默认无风险利率为零。

### 它解决什么问题

它把收益和波动放在同一个比值里，便于比较不同策略或资产的风险调整表现。但它只描述历史样本，不保证未来，也不是“赚钱概率”。

### 最常见的误解

- **“夏普比率高就一定赚钱”**：它只是历史风险调整比值；高夏普可能来自短样本、低波动或过拟合。
- **“夏普比率是收益预测”**：它不预测未来收益或回撤。
- **“无风险利率总是零”**：软件默认零，但真实研究应明确无风险利率和频率。
- **“零波动时夏普无穷大”**：软件在日收益方差为零时不显示夏普，避免无穷大/无定义。
- **“不同频率、不同区间的夏普可以直接比较”**：年化方式、样本长度、无风险利率和策略频率都会影响数值。

## 软件实践

### 在 Quant Lab 哪里出现

- 历史回测“夏普比率”指标。
- 样本内/样本外表中的夏普列。
- 知识解释“夏普比率”。
- 指标模块 `performance_stats` 的 `sharpe`。
- 默认年无风险利率为 0；没有单独的界面输入。

### 输入、输出和单位

- 输入：日收益率序列、年无风险利率（默认 0）。
- 日无风险收益：`(1+r_f_annual)^(1/252)−1`。
- 输出：年化夏普比率，无量纲。
- 计算：`(mean_daily − daily_rf) / std_daily × √252`。
- 分母是日收益率样本标准差（`n−1`）；日收益方差为零时不显示。
- 至少需要两个日收益观测；样本太短时数值不稳定。

### 结果应该怎么读

- 先把夏普比率和累计收益、最大回撤一起读；单独一个比值不足以判断策略。
- 夏普为 0 表示历史平均超额收益为 0（在默认无风险利率下），不等于“没有风险”。
- 夏普为负表示历史平均超额收益为负；不是“未来一定亏”。
- 年化夏普使用了 `√252`，但样本可能只有几天；短样本的数值不可靠。
- 比较策略时，确保无风险利率、频率、区间、费用和币种口径一致。

### 当前软件边界

- 当前只提供历史年化夏普比率；不提供夏普置信区间、概率夏普、Deflated Sharpe 或显著性检验。
- 默认无风险利率为 0，不提供界面输入；真实研究应明确无风险利率来源。
- 不处理自相关、厚尾、非平稳、生存偏差和多重检验；这些会削弱夏普解释。
- 不把夏普比率转换为未来收益概率或交易建议。
- 费用/滑点已进入回测净值；但回测不是实盘，夏普不是可实现收益保证。
- 数据/复权/频率口径可能变化；相关行为 NEEDS_REVIEW（核验日期：2026-10-22）。

## 专业原理

### 正式定义

夏普比率（Sharpe ratio）是超额收益均值与收益标准差的比值。日频版本：

`S_daily = (r̄_daily − r_f_daily) / s_daily`

年化近似：

`S_annual ≈ S_daily × √252`

其中 `r̄_daily` 是日收益率算术平均，`r_f_daily` 是日无风险收益，`s_daily` 是日收益率样本标准差。

### 公式与符号

- `r̄_daily`：日收益率算术平均；
- `r_f_daily`：日无风险收益，`(1+r_f_annual)^(1/252)−1`；
- `s_daily`：日收益率样本标准差（`n−1`）；
- `252`：年交易日近似；
- `S`：年化夏普比率，无量纲。

如果 `s_daily = 0`，分母为零，夏普无定义；软件不显示。

### 可手算的小例子

**例 1：两期 +10%、−10%，无风险利率 0。**

- 收益率：`0.10, −0.10`。
- 均值：`(0.10−0.10)/2 = 0`。
- 偏差：`0.10, −0.10`；平方和 `0.01+0.01=0.02`。
- 样本方差：`0.02/(2−1)=0.02`。
- 样本标准差：`√0.02≈0.141421=14.1421%`。
- 夏普：`(0−0)/0.141421×√252=0`。
- 这是一个只有两个观测的教学例子；实际样本应更长。

**例 2：三期 1%、2%、3%，无风险利率 0。**

- 均值 `2% = 0.02`。
- 偏差 `−1%, 0%, +1%`；平方和 `0.0001+0+0.0001=0.0002`。
- 样本方差 `0.0002/(3−1)=0.0001`。
- 样本标准差 `0.01 = 1%`。
- 日夏普 `0.02/0.01=2`。
- 年化夏普 `2×√252≈2×15.8745≈31.75`。
- 这个数值很大，但只有三个观测；不能据此认为策略未来优秀。

**例 3：无风险利率不为零。**

- 若年无风险利率 `r_f=2%`，日无风险收益 `(1.02)^(1/252)−1≈0.0000785`。
- 例 1 的日均收益 0，日超额收益约 `−0.0000785`；夏普为负。
- 例 2 的日均收益 0.02，日超额收益约 `0.0199215`；夏普约 `0.0199215/0.01×√252≈31.63`。
- 无风险利率的选择会改变分子；必须记录口径。

**例 4：百分比与小数。**

- `10% = 0.10`；`14.1421% = 0.141421`。
- 例 1 的分子是 0，所以夏普为 0；如果误把 10 当成 10%，会得到错误的 100 倍数值。

### 前提假设

- 收益率序列近似独立同分布、均值/方差相对稳定；金融收益的自相关、厚尾和波动聚集会削弱该假设。
- 无风险利率在同一频率和区间内可比；默认 0 只是简化。
- 样本能代表所关注的历史区间；短样本、幸存者偏差和过拟合会扭曲夏普。
- 夏普是历史描述，不是未来收益/亏损概率。

### 边界情况

- 日收益方差为零：夏普无定义，软件不显示。
- 样本只有一个收益观测：无法计算样本标准差。
- 负超额收益：夏普为负；不是“没有风险”。
- 非平稳、自相关、厚尾、波动聚集：简单夏普可能误导。
- 多重策略/参数比较：挑最高夏普会产生数据窥探/过拟合。
- 不同频率、不同无风险利率、不同费用/币种口径：不能直接比较。
- 交易成本、滑点、容量限制：夏普不保证可实现。
