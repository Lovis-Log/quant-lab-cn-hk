# 最大回撤（Maximum Drawdown）

## 快速理解

### 一句话解释

最大回撤是净值/价格从历史高点向下的最深跌幅，本软件用负数报告；它描述路径中的阶段性损失，不是未来损失上限，也不说明恢复需要多久。

### 它解决什么问题

它补充累计收益看不到的“过程”：两个策略最终收益相同，路径可能一个平稳、一个中途腰斩。最大回撤帮助研究者理解承受能力和路径风险。

### 最常见的误解

- **“最大回撤就是最大亏损”**：它是历史路径中最深的峰谷跌幅，不是未来最大损失，也不等于期末亏损。
- **“回撤恢复后就不存在了”**：历史回撤已经发生；后来创新高不会抹掉那段路径。
- **“跌 50% 后涨 50% 就回本”**：`0.5×1.5=0.75`，仍亏 25%；回本需要涨 100%。
- **“最大回撤和波动率是一回事”**：波动率描述离散程度；回撤描述从峰值向下的路径。
- **“最大回撤可以单独决定策略好坏”**：还要看收益、样本长度、费用和样本外。

## 软件实践

### 在 Quant Lab 哪里出现

- 风险与组合页“历史最大回撤”：基于当前价格序列。
- 历史回测“最大回撤”：基于策略净值曲线。
- 样本内/样本外表的最大回撤列。
- 知识解释“最大回撤”和 Quant Academy 第 5 课。

### 输入、输出和单位

- 输入：按时间排序的价格或净值序列，必须为正。
- 输出：最大回撤，小数/百分比，通常为负数。
- 例如 `−0.25` 显示为 `−25.00%`。
- 峰值只取当前及之前的历史最高值，不偷看未来。
- 回撤是路径指标，不是收益率的简单函数；同样的累计收益可能有不同回撤。

### 结果应该怎么读

- 先确认是价格回撤还是策略净值回撤：前者不含费用/分红，后者包含模拟成交和费用。
- 看最大回撤发生的区间、峰值和低点；不要只看一个百分数。
- 回本涨幅公式：`1/(1+d)−1`，其中 `d` 是负回撤。跌 20% 需要涨 25%；跌 50% 需要涨 100%。
- 样本起点会影响峰值和回撤；缩短区间可能改变结果。
- 历史最大回撤不是未来损失上限，也不是恢复时间预测。

### 当前软件边界

- 当前计算历史路径最大回撤；不提供未来回撤预测、VaR、CVaR 或压力测试。
- 价格回撤和策略净值回撤是不同对象；页面会分别在风险页/回测页显示。
- 回测净值已扣模拟费用和滑点，但不是实盘可实现收益。
- 不处理外部现金流；输入被当作一次性本金。
- 数据/复权/费用口径可能变化；相关行为 NEEDS_REVIEW（核验日期：2026-10-22）。

## 专业原理

### 正式定义

设净值/价格序列为 `V_0, V_1, ..., V_n`，到时刻 `t` 为止的历史峰值为：

`peak_t = max_{0≤s≤t} V_s`

时刻 `t` 的回撤为：

`D_t = V_t/peak_t − 1`

最大回撤为：

`MDD = min_{0≤t≤n} D_t`

因为 `V_t ≤ peak_t`，所以 `D_t ≤ 0`；最大回撤通常报告为负数或正幅度（例如“−25%”或“25% 回撤”）。

### 公式与符号

- `V_t`：时刻 t 的净值/价格；
- `peak_t`：截至 t 的历史最高值；
- `D_t`：时刻 t 的回撤，小数；
- `MDD`：最大回撤，小数；
- `min`：取最小值；
- `max`：取最大值。

恢复涨幅：若当前回撤为 `d`（`−1<d≤0`），回到峰值需要：

`recovery = 1/(1+d) − 1`

例如 `d=−0.25`，`recovery=1/0.75−1=0.3333=33.33%`？Wait, 1/0.75 = 1.3333, minus 1 = 33.33%. But earlier we said 25% recovery for a 20% drawdown. For 25% drawdown, recovery is 33.33%. For 20% drawdown, recovery 25%. Correct. Need to use correct examples:
- 100 -> 80: d=-20%; recovery=1/0.8-1=25%.
- 100 -> 50: d=-50%; recovery=1/0.5-1=100%.
- 120 -> 90: d=-25%; recovery=1/0.75-1=33.33%.
Use these.

### 可手算的小例子

**例 1：100 → 120 → 90 → 100。**

- 峰值：100、120、120、120。
- 回撤：`0%`、`0%`、`90/120−1=−25%`、`100/120−1≈−16.67%`。
- 最大回撤：`−25%`。
- 期末累计收益：`100/100−1=0%`。
- 从 90 回到 120 需要：`1/(1−0.25)−1=1/0.75−1≈33.33%`；从 90 回到 100 需要 `100/90−1≈11.11%`。
- 后来回到 100 不会消除 −25% 的历史回撤。

**例 2：100 → 80 → 100。**

- 最大回撤：`80/100−1=−20%`。
- 回本需要：`1/0.8−1=25%`。
- 不是 20%；基数变小了。

**例 3：100 → 50 → 100。**

- 最大回撤：`−50%`。
- 回本需要：`1/0.5−1=100%`。
- 不是 50%；亏损和恢复不对称。

**例 4：样本起点影响。**

- 序列 `90, 100, 120, 90, 100`：峰值 90、100、120、120、120；最大回撤 `90/120−1=−25%`。
- 如果只取 `90, 100, 120`：最大回撤为 0（一直创新高）。
- 如果只取 `120, 90, 100`：最大回撤仍是 `−25%`。
- 样本起止点会改变“历史峰值”和“最大回撤”，报告时必须写清区间。

### 前提假设

- 净值/价格序列为正且按时间排序。
- 峰值只使用当前及此前数据，不使用未来信息。
- 回撤是历史路径描述，不是未来损失上限或恢复时间预测。
- 价格回撤与策略净值回撤使用不同序列；不能混读。

### 边界情况

- 序列只有一个观测：回撤为 0，但样本不足。
- 序列一直创新高：最大回撤为 0。
- 零或负净值：比值无定义或不可解释；回测净值应为正。
- 缺失数据、停牌、不同频率：路径可能被截断或平滑。
- 外部现金流、分红、费用：会影响净值序列和回撤。
- 杠杆、做空、期权：损失可能超过本金，简单回撤公式不适用。
- 回撤持续时间、恢复时间、多次回撤：当前只报告最深幅度，不报告持续时间。
