# 对数收益率（Log Return）

## 快速理解

### 一句话解释

对数收益率是 `ln(期末价格/期初价格)`；它把多期收益变成可相加的“连续复利”增长率，但 Quant Lab **当前软件未实现**对数收益率，也没有对应按钮或指标。

### 它解决什么问题

它在时间序列建模、连续复利和跨期相加时很方便：多期对数收益率可以直接相加，价格比的对数等于对数收益之和。它也让“涨 10% 再跌 10%”这类不对称问题在数学上更对称。

### 最常见的误解

- **“对数收益率就是简单收益率”**：数值接近但不相等；10% 简单收益对应约 9.531% 对数收益。
- **“对数收益率一定大于 −100%”**：简单收益率最低接近 −100%，但对数收益率可以更负；价格从 100 跌到 10，对数收益约为 −230.26%。
- **“对数收益率可以直接当百分比读”**：它是小数；转百分数要乘 100。
- **“软件已经在用对数收益率”**：当前软件用简单收益率和复合净值，**未实现**对数收益率。
- **“对数收益率一定更适合投资报告”**：它对建模方便，但对普通读者不如简单收益率直观，且依赖正价格。

## 软件实践

### 在 Quant Lab 哪里出现

- **当前软件未实现**对数收益率：没有对数收益率按钮、字段、图表或指标。
- 软件使用简单收益率（`P_t/P_{t-1}−1`）、累计净值收益率和复合收益。
- 统计与机器学习使用简单日收益率作为特征/标签；组合使用简单日收益率计算协方差和权重。
- 知识解释中的“收益率”在未特别说明时指简单收益率。

### 输入、输出和单位

如果实现，输入应是两个正价格 `P_0`、`P_1`，输出是小数 `r_log`；百分数表示为 `r_log×100%`。当前软件没有这个输入/输出链路。

对数收益率不是价格，也不是金额；它无量纲。价格必须大于零，否则对数无定义。

### 结果应该怎么读

- 当前页面不会显示对数收益率；看到“收益率”时，默认是简单收益率。
- 如果在外部工具计算对数收益率，先把小数和百分数分清：`0.09531` 是 9.531%，不是 95.31%。
- 多期对数收益率可以相加；多期简单收益率不能直接相加，要用乘法复合。
- 对数收益率的负值可能小于 −100%（以百分数表示），这不代表亏损超过本金；它只是连续复利尺度。

## 专业原理

### 正式定义

对正价格 `P_{t-1}`、`P_t`，对数收益率定义为：

`r_t^log = ln(P_t / P_{t-1})`

其中 `ln` 是自然对数。它也称为连续复利收益率（continuously compounded return）。

### 公式与符号

- `P_t`：第 t 期正价格；
- `r_t^log`：对数收益率，小数；
- `ln`：自然对数；
- `exp`：指数函数。

与简单收益率 `R_t = P_t/P_{t-1}−1` 的关系：

`r_t^log = ln(1 + R_t)`

`R_t = exp(r_t^log) − 1`

多期可加性：

`r_{1→n}^log = ln(P_n/P_0) = r_1^log + r_2^log + ... + r_n^log`

而多期简单收益是乘法：

`1 + R_{1→n} = (1+R_1)(1+R_2)...(1+R_n)`

小收益率近似：

`ln(1+R) ≈ R − R²/2 + R³/3 − ...`

当 `R` 很小时，`ln(1+R) ≈ R`；但收益率较大时差异明显。

### 可手算的小例子

**例 1：上涨 10%。**

- `P_0=100`，`P_1=110`。
- 简单收益率：`110/100−1=0.10=10%`。
- 对数收益率：`ln(110/100)=ln(1.10)≈0.09531=9.531%`。
- 二者接近，但不相等；不要把 9.531% 写成 10%。

**例 2：下跌 10%。**

- `P_0=100`，`P_1=90`。
- 简单收益率：`−10%`。
- 对数收益率：`ln(0.90)≈−0.10536=−10.536%`。
- 先涨 10% 再跌 10%：
  - 路径是 `100→110→99`，第二期跌 10% 是按 110 计算的：`110×0.9=99`。
  - 对数收益相加：`ln(1.1)+ln(0.9)=ln(0.99)≈−0.01005`。
  - 简单累计收益：`99/100−1=−1%`。
  - 这说明对数收益相加得到的是价格比的对数，不是简单收益的加法。

**例 3：大幅下跌。**

- `P_0=100`，`P_1=10`。
- 简单收益率：`10/100−1=−0.90=−90%`。
- 对数收益率：`ln(0.10)≈−2.302585`；以百分数表示为 `−230.2585%`。
- 简单收益率不会低于 −100%（价格为正），但对数收益率可以更负；不要把 −230.26% 读成“亏损超过本金 230%”。

**例 4：多期可加性。**

- `100→110→121`：
  - 两期对数收益：`ln(1.1)+ln(1.1)=2×0.09531=0.19062`；
  - 累计价格比：`121/100=1.21`，`ln(1.21)≈0.19062`；
  - 简单累计收益：`21%`；
  - 对数累计收益：`19.062%`。
- 两者都在描述同一价格变化，但尺度不同。

### 前提假设

- 价格严格大于零；零价或负价不能取对数。
- 收益率是连续复利概念；不自动包含分红、费用、税费和滑点。
- 多期可加性要求使用同一价格序列、同一复权口径和同一币种。
- 对数收益率的统计模型（如正态假设）是额外假设，不是定义本身。

### 边界情况

- 价格为零或负数：无定义。
- 价格接近零：对数收益率可能非常负；简单收益率仍接近 −100%。
- 收益率很大：`ln(1+R)` 与 `R` 差异明显。
- 不同频率、不同币种、不同复权口径：不能直接相加。
- 分红、拆股、配股：价格序列需要先调整；对数收益率不自动重建现金流。
- 以百分数表示时，负值可能小于 −100%；不要与简单收益率的下限混淆。
