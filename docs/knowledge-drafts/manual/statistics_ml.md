# 统计分析：t 检验、时间切分与样本外误差

## 这一页是做什么的

“统计分析”页先描述当前价格序列的日收益率，做一次零假设为“平均日收益率为零”的单样本 t 检验；再按时间顺序切分样本，用五个价格/成交量特征线性回归预测下一交易日收盘收益率，并把样本外误差与“每天预测零收益”的基线比较。

这一页是统计推断和预测误差练习，不是分类器、因子框架、深度学习或自动交易系统。预测目标不能让研究者在当日收盘价成交，也不包含交易费用和滑点。

## 使用前需要什么

- 已加载真实历史日线；t 检验至少需要 3 个有效日收益率。
- 机器学习至少需要 60 行有效特征，通常需要 80 个以上交易日；训练集至少 30 行、样本外测试集至少 10 行。均线预热、缺失量价和零成交量会减少有效样本。
- 保持价格口径一致；跨除权事件时，不复权价格可能出现不代表总回报的跳变。
- 不需要 DeepSeek Key；本页全部计算在本地完成。

## 控件和结果说明

### 描述统计与 t 检验

加载数据后自动显示四个指标：

| 指标 | 含义 |
| --- | --- |
| 日收益率样本量 | `close.pct_change()` 后去掉首个缺失值得到的有效日收益个数。 |
| 日均收益率 | 日收益率的算术平均值。 |
| 年化波动率估计 | 日收益率样本标准差 × `√252`。 |
| 均值为零检验 p 值 | 单样本双侧 t 检验的 p 值；标准差为零时显示“—”。 |

零假设是“平均日收益率为零”。p 值是在零假设和检验假设下，得到至少同样极端结果的概率；它不是“零假设为真的概率”，也不是“股票上涨概率”或“策略盈利概率”。

### 时间序列线性回归

| 控件 | 说明 |
| --- | --- |
| 机器学习训练比例 | 0.55–0.85，默认 0.70；较早样本训练，较晚样本测试。 |
| 运行时间序列线性回归 | 按日期训练、标准化和评估；不随机打乱样本。 |

特征只使用当日收盘后可知的信息：

- 1 日收益
- 5 日收益
- 5 日均线 / 20 日均线 − 1
- 成交量日变化（成交量为 0 时先视为缺失）
- 10 日收益标准差

标签是 `下一交易日收盘价 / 当日收盘价 − 1`，即下一日收盘相对当日收盘的收益率。特征日期是 t，标签日期是 t+1；训练/测试按时间排序，中间留一行间隔，避免训练标签使用测试首日。

训练集内部使用 3 折时间序列交叉验证，折与折之间留 1 行间隔；标准化只在训练数据上拟合。样本外结果包括：

| 指标 | 含义 |
| --- | --- |
| 样本外 MAE | 预测收益与实际收益之差的绝对值平均；单位是收益率误差，1% 表示 1 个百分点。 |
| 零收益基线 MAE | 每天都预测 0 时的 MAE。模型必须先胜过这个简单基线。 |
| 样本外 R² | `1 − 预测残差平方和 / 测试收益围绕测试均值的平方和`；可以为负。 |
| 方向一致率 | 预测符号与实际符号一致的比例；零归入非负方向。 |

页面还显示预测与实际曲线（横轴为 `target_date`）、标准化特征系数表，以及训练/测试行数、训练标签截止日期、测试特征起始日期和训练期 3 折交叉验证 MAE。

## 推荐操作顺序

1. 在左侧选择股票，历史区间建议至少一年，设置价格口径并加载日线。
2. 先看日收益率样本量、日均收益、年化波动和 p 值；确认样本量足够，理解 p 值的含义。
3. 保持“机器学习训练比例”70%，点击“运行时间序列线性回归”。
4. 先比较“样本外 MAE”和“零收益基线 MAE”：只有模型 MAE 更小，才说明该历史测试区间的平均误差更低。
5. 再看 R²、方向一致率和预测曲线；R² 为负是有效结果，不要删除或只汇报正值的区间。
6. 查看训练期 3 折交叉验证 MAE 和标准化系数；系数描述训练期关联，不是因果。
7. 换一个未参与调参的区间复核；反复看测试结果再调参会污染测试集。

## 一个可复现的小例子

### t 检验

假设四个日收益率 `1%, 2%, 3%, 4%`（小数 `0.01, 0.02, 0.03, 0.04`）：

- 均值 `= 2.5%`。
- 偏差 `= −1.5%, −0.5%, 0.5%, 1.5%`。
- 样本方差 `= (2.25 + 0.25 + 0.25 + 2.25) / 3 = 1.6667 %²`。
- 样本标准差 `= √1.6667 ≈ 1.291%`。
- 标准误 `= 1.291% / √4 ≈ 0.6455%`。
- `t = 2.5% / 0.6455% ≈ 3.873`，自由度 `4−1=3`。
- 双侧 p 值约为 `0.0305`。

这个例子只说明公式和计算顺序。p≈0.0305 不等于“有 97% 概率上涨”，也不等于“策略有 97% 概率赚钱”；它依赖样本近似独立、同分布等假设，而金融收益常有自相关和厚尾。

### MAE 与 R²

实际收益 `[1%, −1%]`，预测 `[0%, 0%]`：

- 绝对误差 `= 1%, 1%`。
- MAE `= (1% + 1%) / 2 = 1%`。

实际收益 `[1%, 3%]`，预测 `[0%, 0%]`：

- 实际均值 `= 2%`。
- 分子（预测残差平方和）`= (1−0)² + (3−0)² = 10 %²`。
- 分母（实际值围绕均值的平方和）`= (1−2)² + (3−2)² = 2 %²`。
- `R² = 1 − 10/2 = −4`。

负 R² 是有效结果：模型的平方误差比“使用测试样本均值”的参考更大。不能通过删除负值区间让结果看起来更好。

### 方向一致率

实际 `[1%, −1%, 2%]`，预测 `[0.5%, 0.2%, 0.1%]`：

- 实际符号：`+, −, +`
- 预测符号：`+, +, +`
- 一致 2 个，方向一致率 `= 2/3 ≈ 66.7%`。

方向一致率只统计符号，不考虑涨跌幅大小、费用、滑点和可成交性；高一致率不等于能赚钱。

## 怎么判断结果是否有效

- t 检验至少 3 个有效日收益；p 值要结合样本量、自相关、厚尾和检验次数解释。p 值小只表示在零假设下结果较不常见，不是盈利概率。
- 机器学习至少 60 行有效特征；训练/测试按时间排序，中间有间隔；标准化只在训练集拟合。
- 先看 MAE 是否低于零收益基线，再看 R² 和方向一致率；MAE 更高或 R² 为负都是有效失败结果，不应删除。
- 预测曲线横轴是 `target_date`，不是特征日；曲线上的预测不能按特征日收盘价成交。
- 系数是标准化后的训练期关联，不是因果效应；特征之间可能相关，系数符号和大小会随样本变化。
- 训练期 3 折交叉验证 MAE 只用于训练期模型选择，不是样本外证据；真正的样本外是较晚的测试区间。
- 换股票、区间、复权或训练比例后重新运行；如果反复根据测试结果调参，测试集就不再独立。
- 自相关、厚尾、非平稳和多重检验会削弱 t 检验和回归的解释力；当前没有分类器、因子框架或自动交易转换。

## 常见错误与处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| “均值检验至少需要 3 个有效的日收益率” | 区间太短或有效价格不足 | 扩大区间；不要用演示数据补足。 |
| “机器学习实验至少需要 60 个可用样本” | 区间太短、均线预热或缺失量价过多 | 扩大区间；至少准备 80 个以上交易日。 |
| “训练集或样本外测试集过短” | 训练比例不合适或有效样本太少 | 调整比例或扩大区间；训练至少 30 行、测试至少 10 行。 |
| MAE 大于零收益基线 | 模型在该测试区间不如每天预测 0 | 这是有效失败结果；记录并另找未使用区间，不要删除。 |
| R² 为负 | 模型平方误差大于测试均值参考 | 负 R² 是有效结果；结合 MAE 和曲线解释。 |
| 方向一致率高但 MAE 更差 | 符号碰巧一致，幅度误差大 | 不能只看方向；比较 MAE、R² 和实际交易成本。 |
| 系数符号与直觉相反 | 训练期关联、特征共线性或样本特殊 | 不要解释为因果；换区间复核。 |
| 预测曲线看起来“提前” | 把特征日当成目标日 | 横轴是 `target_date`；特征只使用目标日前一交易日收盘后信息。 |
| 换区间后结果大幅变化 | 样本短、市场状态变化或过拟合 | 保留原结果，另做独立检验；不要只汇报最好区间。 |
| 全量数据先标准化或随机划分 | 数据泄漏 | 程序按训练集拟合标准化并按时间切分；自定义研究也要遵守。 |

## 数据、计算和适用边界

- t 检验是单样本、双侧、零假设为平均日收益为零；依赖样本近似独立等条件。金融收益的自相关、厚尾和多重检验会影响解释。
- 线性回归特征为当日收盘后可知的 1 日/5 日收益、5/20 日均线差、成交量变化和 10 日波动率；标签是下一交易日收盘相对当日收盘的收益率。
- 训练/测试按时间排序，中间留一行间隔；标准化只在训练数据拟合，训练内部使用带间隔的 3 折时间序列交叉验证。
- 页面比较模型 MAE 与恒预测零收益的基线，并显示 R² 与方向一致率；这些指标不等于交易收益，不含费用、滑点和可成交性。
- 预测标签不能让研究者按当日收盘价成交；要把预测转成策略，还需要明确的信号、下一开盘执行、成本和样本外回测。
- 当前没有分类器、因子框架、深度学习、超参数搜索或自动交易；当前机器学习是简单线性回归教学研究。
- 日线数据无法还原盘中路径、订单簿、停牌细节和公司行动现金流；历史统计不保证未来。
