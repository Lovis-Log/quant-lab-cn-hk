# 历史回测：下一开盘成交、费用、基准与样本外

## 这一页是做什么的

“历史回测”在明确的成交与成本假设下检验策略规则：第 t 日收盘后形成信号，最早在第 t+1 个交易日开盘尝试成交；只做多，不加杠杆，不执行真实交易。页面同时给出同成本买入并持有基准、样本内/样本外结果、订单与未成交记录、参数敏感性，并允许把输入快照、参数、成本和结果保存为可复算实验。

回测的目标不是证明策略“有效”，而是把规则、数据、成本和样本切分摆出来，让结果可以被复核、被质疑、被下一组独立数据检验。

## 使用前需要什么

- 已加载真实历史日线；左侧市场、代码、区间和价格口径已确定。
- 历史区间足够长：程序要求原始行情至少有两个交易日，且长度至少为 `max(长周期 + 5, 30)`；样本内至少 3 个观察、样本外至少 2 个观察，否则回测报错。
- 理解复权价格与不复权价格的区别：复权价格只用于生成信号；成交和净值始终使用同日不复权开盘/收盘价。
- 准备一组可修改的研究假设：初始资金、交易单位、佣金、最低佣金、买卖附加费用、滑点、A 股简化涨跌停。页面默认值不是当前法定税费或券商报价。

## 控件和结果说明

### 策略参数

| 控件 | 说明 |
| --- | --- |
| 策略类型 | 单均线过滤、双均线趋势、价格与均线同向；与策略实验室相同的三种内置规则。 |
| 短周期（交易日） | 2–249，默认 10。 |
| 长周期（交易日） | 3–250，默认 30；必须大于短周期。 |
| 样本内比例 | 0.50–0.85，默认 0.70；较早区间用于参数研究，较晚区间用于样本外评估。 |

### 成交与费用假设

折叠区“成交与费用假设（均可调整）”包含：

| 控件 | A 股默认值 | 港股默认值 | 作用 |
| --- | --- | --- | --- |
| 初始资金 | 1,000,000 | 1,000,000 | 模拟起始现金。 |
| 买入交易单位（股，请核对标的与板块） | 100 | 100 | 每次买入取该数量的整数倍；港股交易单位需用户自行核对输入。 |
| 佣金（基点） | 3 | 10 | 按成交额计算的佣金，1 基点 = 0.01% = 0.0001。 |
| 单笔最低佣金 | 5 | 0 | 佣金的下限；只作用于佣金，不作用于附加费用。 |
| 买入附加费用（基点） | 0 | 10 | 买入方向按成交额计算的附加费。 |
| 卖出附加费用（基点） | 5 | 10 | 卖出方向按成交额计算的附加费。 |
| 单边滑点（基点） | 2 | 3 | 买入价加、卖出价减，单边计算，和佣金分开。 |
| 简化涨跌停假设 | 10% | 不显示 | A 股可选 10%、5%、20%、30% 或“不模拟”；港股页面不提供该控件。 |

这些默认值只是示例研究假设。实际佣金、最低收费、印花税、过户费、交易征费等会随市场、券商、账户和日期变化；页面不会自动推断，也不声称覆盖交易所全部规则。

### 运行与结果

点击“运行历史回测”后，页面显示：

- **策略累计收益**：策略净值首尾变化。
- **年化收益估计**：按 252 个年交易日换算，不是未来一年预测。
- **最大回撤**：净值相对此前峰值的最深跌幅，以负数报告。
- **夏普比率**：日超额收益均值除以日收益样本标准差，再乘 `√252`；日收益方差为零时不显示。
- **同成本买入并持有基准**：使用相同价格、成本和交易规则的参照策略。
- **实验指纹**：由两份行情快照、策略参数、成本参数和训练比例计算，显示前 16 位十六进制字符。
- **净值图**：策略净值与同成本买入并持有净值，均以初始资金归一；黄色虚线起为样本外区间。
- **样本内/样本外表**：累计收益率、最大回撤、夏普比率。
- **交易与未成交记录**：决策日、成交日、方向、状态、原因、股数、成交价、费用和成交后现金；可导出订单 CSV。
- **参数敏感性（仅样本内）**：在当前短/长周期附近取若干组合，列出样本内累计收益率和成交次数。

### 保存实验

“保存本次实验与研究笔记”折叠区包含：

- 研究标题
- 研究假设
- 学习笔记
- “保存实验”按钮

研究标题和研究假设不能为空。保存后，实验档案包含市场、规范代码、名称、日期区间、策略、成本、训练比例、来源、复权、接收时间、结果、订单、两份行情 CSV 快照和 SHA-256，以及审计指纹。更新行情不会改写已有实验快照；重新研究应另存实验。

## 推荐操作顺序

1. 先加载历史日线，核对来源、币种、价格口径和最新交易日。
2. 选择策略类型和窗口，确认样本长度足以支持预热和样本外切分。
3. 打开“成交与费用假设（均可调整）”，逐项核对市场、交易单位、佣金、最低佣金、买卖附加费用、滑点和涨跌停假设。每次只改一个假设，便于解释差异。
4. 设置样本内比例。第一次使用保持 70%，不要先看样本外结果再回头调参。
5. 点击“运行历史回测”。若报错，先读错误信息，不要用另一批数据或演示值绕过。
6. 先检查订单表：决策日是否早于成交日；成交价是否等于不复权开盘价加/减滑点；费用是否符合公式；未成交原因是否合理。
7. 再比较策略与基准，读样本内/样本外表、最大回撤、夏普和参数敏感性。参数敏感性只计算样本内，不能当作样本外证据。
8. 写下研究假设、你对回撤和成本的理解，以及下一次独立检验计划，然后保存实验。
9. 到“研究笔记”复算并导出 ZIP，确认归档输入能重新得到同一指纹。

## 一个可复现的小例子

下面是一个**成交算术示例**，不是完整回测。两个交易日不足以形成 10/30 均线，只用来说明费用和滑点如何进入现金流。

假设：初始资金 10,000 元；买入交易单位 100 股；某日开盘价 10.00 元；单边滑点 100 基点（1%）；佣金 3 基点；单笔最低佣金 5 元；买入附加费用 0 基点；卖出附加费用 5 基点。

买入：

- 买入成交价 = `10.00 × (1 + 100/10000) = 10.10` 元。
- 买入 100 股，成交额 = `100 × 10.10 = 1,010` 元。
- 佣金 = `max(5, 1,010 × 3/10000) = max(5, 0.303) = 5` 元。
- 买入附加费 = `1,010 × 0/10000 = 0` 元。
- 现金 = `10,000 - 1,010 - 5 = 8,985` 元。

若当日收盘价为 10.20 元，则当日净值 = `8,985 + 100 × 10.20 = 10,005` 元。

下一交易日卖出：

- 卖出成交价 = `10.00 × (1 - 100/10000) = 9.90` 元。
- 成交额 = `100 × 9.90 = 990` 元。
- 佣金 = `max(5, 990 × 3/10000) = 5` 元。
- 卖出附加费 = `990 × 5/10000 = 0.495` 元。
- 现金 = `8,985 + 990 - 5 - 0.495 = 9,969.505` 元。

这次往返的现金变化约为 `-30.495` 元，主要来自买卖价差和最低佣金。实际回测还会按策略信号、整手数量、A 股 T+1、涨跌停和零成交量等条件决定是否成交；示例中的两个交易日不会形成完整的均线策略结果。

若要做一个完整示例，可使用“快速开始”中的 600519、2025 年区间、双均线 10/30、样本内 70% 流程；实际数值以加载到的数据和页面结果为准，不预设收益。

## 怎么判断结果是否有效

- **时间顺序**：订单表的决策日应早于成交日；成交日至少是决策日的下一个交易日。不能出现同日收盘信号按同日收盘价成交。
- **价格口径**：成交价和不复权开盘价一致；复权价格只出现在信号序列。若复权信号与不复权成交数据的交易日不一致，程序应报错而不是混用。
- **费用与滑点**：买入价加滑点、卖出价减滑点；佣金取 `max(最低佣金, 成交额 × 佣金基点/10000)`；买入/卖出附加费分别按方向计算；费用从现金扣除。
- **成交数量**：买入量是交易单位的整数倍，且成交额加费用不超过可用现金；卖出时卖出全部持股。资金不足、零成交量、A 股 T+1 或假设涨跌停会导致未成交，订单表应给出原因。
- **基准公平**：基准使用同一区间、同一成本和同一交易单位，在第二个交易日开盘尝试买入，不强制末日平仓；策略与基准的差异不能来自不同的费用假设。
- **样本切分**：样本内只用于参数研究；样本外从黄色虚线起。样本外统计以分割日前一交易日净值为起点，避免丢掉分割日收益。反复查看样本外再调参，会让测试集不再独立。
- **参数敏感性**：表格只计算样本内，成交次数也只在样本内统计；窗口组合无效或长周期超过样本内长度时会被跳过。
- **可复现**：实验指纹由行情、信号、策略、成本和训练比例决定；复算指纹一致才说明归档输入能重现同一结果。指纹一致不代表策略未来有效。
- **解释边界**：高累计收益、高夏普或低回撤都不是质量门槛；必须同时看样本长度、费用、滑点、基准、样本外和未成交记录。

## 常见错误与处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| “历史交易日不足以支持所选均线和样本外比较” | 区间太短、长周期太长，或样本内/外不足 | 扩大区间或减小长周期；不要用演示数据补足。 |
| “信号与原始成交价格的交易日数量不一致” | 复权信号与不复权成交数据日期不一致 | 重新加载同一区间的两份数据；不要手工拼接不同批次。 |
| “不复权成交数据更新失败；请稍后重试，不能混用不同获取批次” | 复权信号已取得，但不复权成交价请求失败 | 稍后重试；程序停止本次回测是保护措施，不是可跳过的错误。 |
| 没有订单 | 预热不足、信号没有变化、整手数量过大或资金不足 | 查看信号图和订单表；没有交易可能是规则在该样本上的真实结果。 |
| 订单大量 blocked | 零成交量、A 股 T+1、假设涨跌停、资金不足 | 逐项查看“reason”列；不要只调高初始资金来掩盖规则问题。 |
| 买入股数少于预期 | 整手取整、滑点提高成交价、佣金和附加费占用现金 | 用示例公式手算一遍；检查交易单位和资金。 |
| 基准与策略差异很大 | 策略空仓时间、交易次数、成本或样本区间不同 | 核对两者是否使用同一成本、同一交易单位和同一区间。 |
| 样本外结果突然变差 | 样本切分、参数过拟合、市场状态变化或成本假设 | 不要删除样本外；记录结果，另找未使用区间复核。 |
| 保存实验失败 | 标题或假设为空、数据库不可写、磁盘空间不足 | 填写标题和假设；检查资料库。 |
| 复算指纹不一致 | 快照损坏、代码版本变化、参数被改动 | 不覆盖原实验；保留错误信息并记录代码版本。 |
| 参数敏感性表为空 | 短/长周期组合无效或超过样本内长度 | 调整窗口或扩大样本内区间；不要手工伪造表格。 |

## 数据、计算和适用边界

- 回测使用日线，无法还原订单簿、盘口队列、盘中停牌、逐笔成交、不同板块上市初期的特殊规则、分红现金流和真实费用。
- A 股模型模拟 T+1、用户设定的买入单位和简化涨跌停；港股交易单位由用户核对输入，本模型未模拟香港市场的波动调节机制。实际 A 股板块与特殊股票的申报单位、涨跌幅规则不同，不能靠代码自动推断。
- 买价 = `开盘价 × (1 + 滑点基点/10000)`；卖价 = `开盘价 × (1 - 滑点基点/10000)`；单笔费用 = `max(最低佣金, 成交额 × 佣金基点/10000) + 成交额 × 对应附加费基点/10000`。
- 只做多，不做空、不加杠杆；策略只在现金与持股之间切换；日线无法模拟盘中路径。
- 复权价格只生成信号；成交和估值使用同日不复权价格。基准也在第二个交易日开盘买入，使用同一成本和成交规则，不强制末日平仓。
- 最大回撤是历史路径指标，不是未来损失上限；年化收益是按 252 个交易日换算，不是未来一年预测；夏普比率依赖无风险利率、频率和样本口径，默认无风险利率为零。
- 单只仍上市股票的历史样本不能消除幸存者偏差；反复看样本外调参、只汇报最好参数会造成过拟合和数据窥探。
- 回测结果不代表真实可实现收益，不构成投资建议，也不执行实盘交易。
