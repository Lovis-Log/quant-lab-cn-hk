# 工作台与使用手册面板

## 这一页是做什么的

这一页说明 Quant Lab CN/HK 的工作台结构：全局顶栏、左侧导航、三个可停靠面板、设置面板和本地资料库。它还说明“使用手册”面板本身如何阅读，以及怎样在不影响研究数据的前提下调整界面。

工作台不是一个单独的“学习页面”。研究页面负责数据、信号、回测、组合、统计和教学实验；使用手册、DeepSeek 助手、研究笔记是右侧三个可同时打开的面板。面板宽度、顺序和最大化状态只影响本机显示，不改变行情、策略、回测或数据库内容。

## 使用前需要什么

- 已完成资料库创建并重启软件。首次启动的“创建 Quant Lab 专用资料库”是进入工作台的前置步骤。
- 桌面版需要 Microsoft Edge WebView2 Runtime；缺少时启动器会提示安装。浏览器方式打开时需要手动填写资料库路径，不能使用系统目录选择器。
- 阅读本手册不需要网络，也不需要 DeepSeek Key。
- 建议在窗口宽度足够时同时打开两个面板；窗口过窄时，面板会互相挤压，应先收起左侧导航或最大化一个面板。

## 控件和结果说明

### 全局顶栏

顶栏从左到右包含：

| 控件 | 作用 |
| --- | --- |
| `⚙` | 打开或关闭左上角设置面板。 |
| `▥` | 显示或隐藏左侧导航栏；不改变右侧三个面板的打开状态。 |
| `Q/ Quant Lab CN/HK` | 产品标识。 |
| `研究工作台` | 当前区域名称。 |
| `使用手册` | 打开或关闭右侧使用手册面板。按住按钮左右拖动，可与其他面板按钮交换顺序。 |
| `DeepSeek 助手` | 打开或关闭右侧 DeepSeek 面板。 |
| `研究笔记` | 打开或关闭右侧研究笔记面板。 |

顶栏始终保留。最大化某个面板时，面板不会遮住顶栏；按 `Esc` 可以恢复。

### 左侧导航

左侧导航列出研究页面：

- 市场数据
- 策略实验室
- 历史回测
- 风险与组合
- 统计与机器学习
- Quant Academy

左侧导航下方是“研究参数”：市场、股票（代码 / 名称）、历史区间、价格口径和“加载真实历史日线”。这些参数由各研究页面共用；切换页面不会自动重新请求行情。左侧底部显示“本地研究环境 · 历史数据按需查询”和“仅供学习与模拟研究，不执行真实交易”。

### 三个停靠面板

右侧最多可同时停靠三个面板：

1. **使用手册**：包含“快速开始”“功能说明”“专业知识库”三入口，以及目录、离线搜索和文章关联跳转；不记录阅读进度。
2. **DeepSeek 助手**：包含“研究实验”和“对话与辅导”两个工作区；只有明确点击发送、生成假设或审阅实验时才产生付费请求。
3. **研究笔记**：管理分类、笔记草稿、附件、实验档案、回收站、复算和导出。

面板共同行为：

- 每个面板标题栏固定，内容区独立滚动；标题、`⛶` 最大化和 `×` 关闭按钮不会随内容滚走。
- 拖动面板左缘的调整柄可以改宽度；聚焦调整柄后，也可以用左右方向键微调。
- 按住顶栏按钮左右拖动可以调整三个面板的顺序；单击仍然是打开/关闭。
- `⛶` 最大化当前面板；再次点击或按 `Esc` 恢复。左侧导航可见时，最大化面板只占其右侧工作区；左侧导航收起后，面板可扩展到整个应用宽度，顶栏仍然保留。
- 面板宽度和顺序保存在本机 WebView 的本地存储中；最大化状态只在当前会话中保留。它们都不写入研究数据库；清除 WebView 数据会重置宽度/顺序偏好，但不会删除研究实验。

### 设置面板

`⚙` 打开的设置面板固定在左上角，包含三个标签：

| 标签 | 内容 |
| --- | --- |
| 资料文件夹 | 显示当前资料根目录；可修改父目录并“创建资料库并迁移现有数据”。迁移会复制并校验现有数据，原目录保留。 |
| DeepSeek | DeepSeek API Key、记住密钥、应用/读取/清除密钥、测试连接、刷新模型、模型选择和思考强度。Key 只进入当前会话或 Windows 凭据管理器。 |
| 偏好设置 | “显示详细解释提示”“自动刷新行情（仅市场页）”“自动刷新间隔”（5、10、15 分钟）。 |

“显示详细解释提示”只影响页面是否显示可展开的知识解释，不改变行情、信号、回测、统计或组合计算。关闭它不会改变任何数值，只是减少提示密度。

### 使用手册面板的阅读结构

- **快速开始**：从资料库到第一份可复现实验的完整流程。
- **功能说明**：按页面解释控件、结果、操作顺序、常见错误和边界；与左侧研究页面一一对应。
- **专业知识库**：按“市场与数据、收益与风险、策略与执行、回测与研究、组合分析、统计推断、机器学习、Python 与工程”分类的词条。每个词条先给一句话解释，再给软件实践，最后给正式定义、公式、手算例子和边界情况。

手册只提供阅读和检索，不记录学习进度，也不要求提交任何内容。手册中的示例数值如果标注为教学数据，就不是股票行情；如果是操作示例，就不保证上游数据当前可用或结果可复现为某个收益。

## 推荐操作顺序

1. 首次启动先创建资料库，按提示关闭并重新启动软件。
2. 进入工作台后，先用 `▥` 确认左侧导航的显示状态；需要更大阅读区时收起左栏。
3. 从顶栏打开“使用手册”，先读“快速开始”，再按当前需要跳到“功能说明”的对应页面。
4. 打开“研究笔记”并保持停靠，便于在回测后立即保存实验；需要更宽时拖动面板左缘。
5. 打开“DeepSeek 助手”前，先在 `⚙` 的“DeepSeek”标签完成 Key 和模型设置；不配置 Key 也可以使用离线手册、学院和本地回测。
6. 在 `⚙` 的“偏好设置”中决定是否显示详细解释提示、是否自动刷新以及刷新间隔。
7. 调整好面板宽度和顺序后，正常使用研究页面；这些布局偏好会在本机保留。

## 一个可复现的小例子

这是一个界面操作示例，不涉及行情结果：

1. 启动软件，完成资料库创建并重启。
2. 点击顶栏“使用手册”，再点击“研究笔记”，两个面板同时停靠。
3. 将鼠标移到“使用手册”面板左缘的调整柄，向左拖动，使手册变宽；观察“研究笔记”被挤压但内容仍可独立滚动。
4. 点击“使用手册”面板标题栏的 `⛶`，面板最大化；确认全局顶栏仍在，左侧导航可见时面板没有遮住导航。
5. 按 `Esc` 恢复；再点击顶栏 `▥` 收起左侧导航，重复最大化，确认面板扩展到整个应用宽度。
6. 点击顶栏 `⚙`，在“偏好设置”中切换“显示详细解释提示”，关闭设置；回到市场数据页，确认知识解释的显示密度变化，但已加载的行情数值没有变化。
7. 按住顶栏“使用手册”按钮向左拖动，与“DeepSeek 助手”交换顺序；刷新页面后确认顺序仍保留。清除 WebView 本地存储后，顺序会恢复默认，但研究数据不受影响。

如果第 6 步中行情数值发生变化，应先检查是否触发了自动刷新或手动更新，而不是把提示开关当成计算参数。

## 怎么判断结果是否有效

- **面板行为**：标题栏固定、内容区独立滚动；最大化不遮住全局顶栏；`Esc` 能恢复；左栏开关不改变面板开关状态。
- **布局持久化**：宽度和顺序在刷新后保留；这些偏好属于本机 WebView，不属于研究档案。清除 WebView 数据后布局重置是预期行为。
- **设置生效**：自动刷新开关和间隔在“市场数据”页的状态区显示；提示开关只改变解释的显示，不改变数值；资料库路径显示的是当前实际根目录。
- **资料库正确**：设置“资料文件夹”中的路径与首次创建时选择的父目录下的 `QuantLabCNHK` 一致；迁移后原目录仍保留，重启后使用新目录。
- **手册内容**：手册中的控件名称应与当前页面一致；若两者不同，应以当前软件实际控件为准并记录差异。

## 常见错误与处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 启动后只看到“创建 Quant Lab 专用资料库” | 尚未完成资料库配置 | 选择父目录，点击“创建资料库并迁移现有数据”，按提示重启。 |
| 点击“浏览 Windows 文件夹…”没有反应 | 浏览器模式没有 pywebview API | 在“资料库父目录”中手动填写路径。 |
| 提示缺少 WebView2 | 系统未安装 Microsoft Edge WebView2 Runtime | 安装微软官方 Runtime 后重试。 |
| 面板打不开 | 顶栏按钮被其他面板挤压，或窗口过窄 | 收起左侧导航、关闭其他面板或放大窗口；再用顶栏按钮打开。 |
| 面板内容滚不动 | 鼠标位于标题栏或调整柄 | 将鼠标移到内容区再滚动；标题栏固定是设计行为。 |
| 最大化后看不到左侧导航 | 左栏被收起 | 按 `Esc` 恢复，或点击 `▥` 重新显示左栏。 |
| 刷新后宽度/顺序恢复默认 | WebView 本地存储被清除或使用了新的 WebView 配置 | 重新调整即可；研究数据不受影响。 |
| 设置保存失败 | 资料库不可写、SQLite 错误或磁盘空间不足 | 页面会提示“仅在会话中生效”；检查资料库目录和磁盘。 |
| Key 设置后仍显示未连接 | 未选择模型，或模型列表尚未取得 | 在“DeepSeek”标签中测试连接、刷新模型，或手动填写官方模型 ID。 |
| 资料库迁移后仍使用旧数据 | 未按提示重启，或启动的是另一个资料库 | 关闭并重新启动；核对“资料文件夹”中的当前根目录。 |

## 数据、计算和适用边界

- 工作台布局和面板状态是本机显示偏好，不是研究数据；研究数据保存在资料库的 SQLite 数据库、笔记附件和实验快照中。
- 资料库迁移会复制并校验数据库、笔记、备份和证券缓存，原目录保留；迁移不会把 DeepSeek Key 写入资料库。
- “显示详细解释提示”只影响提示密度，不影响金融计算。
- 使用手册是纯阅读内容，不记录学习进度，也不要求提交任何内容；它不联网抓取新数据，也不把手册阅读行为写入研究档案。
- 本手册按文字手册分支的三入口结构接入；任务式学习中心继续保留在 `codex/learning-center-v2`，不与本分支共用界面入口。
- DeepSeek 面板的付费请求只在明确点击发送、生成假设或审阅实验时发生；打开面板、切换页面、重绘和轮询不会自动发送。
- 软件不提供实时行情，不执行实盘交易；工作台中的“研究工作台”不表示连接了交易所或券商。
