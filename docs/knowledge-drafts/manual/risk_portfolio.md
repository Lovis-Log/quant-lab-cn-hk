# 风险与组合：单资产波动、共同日期与权重

## 这一页是做什么的

“风险与组合”页分两部分：先描述当前股票的历史风险，包括日收益率样本方差、样本标准差、年化波动率估计和历史最大回撤；再用 2–4 只**同一市场、同一币种**的股票构造等权和训练期逆波动率组合，在共同交易日上比较样本外净值。

这一页是历史描述和数学组合练习，不是风险预测，也不是资产配置建议。不同币种不能直接相加；当前组合不处理汇率换算。

## 使用前需要什么

- 已加载当前股票的真实历史日线；单资产风险指标至少需要 3 个交易日。
- 组合需要 2–4 只同一市场的股票代码，代码不重复，日期能够对齐。共同交易日少于 8 天时程序拒绝分析。
- 组合训练比例在 0.50–0.85 之间；训练区间和样本外区间各自不能过短，否则程序报错。
- 理解“日收益率”与“价格”的区别：方差、标准差、协方差和相关都基于日收益率；最大回撤基于价格或净值路径。
- 注意复权口径：组合会按当前选择的口径读取每只股票；跨除权事件时，不复权价格的收益率可能包含不代表总回报的跳变。

## 控件和结果说明

### 单资产风险

当历史数据至少有 3 个交易日时，页面显示四个指标：

| 指标 | 计算口径 |
| --- | --- |
| 日收益率样本方差 | 日收盘收益率 `pct_change()` 的样本方差，分母 `n−1`，显示 6 位小数。 |
| 日收益率样本标准差 | 样本方差的平方根，显示为百分比。 |
| 年化波动率估计 | 日收益率样本标准差 × `√252`。 |
| 历史最大回撤 | 价格序列相对此前峰值的最大跌幅，以负数报告。 |

“方差与标准差使用样本口径（分母 n−1）；年化波动率约等于日标准差 × √252。历史波动不保证未来风险。”这是页面的原始提示，也是解释边界。

### 组合输入

| 控件 | 说明 |
| --- | --- |
| 组合股票代码（逗号分隔，2–4 只） | 只允许当前市场的股票；A 股六位，港股可输入 1–5 位并自动补足五位；不混合 CNY 与 HKD。默认填入当前股票和另一只同市场示例代码。 |
| 组合权重训练比例 | 0.50–0.85，默认 0.70；较早的共同交易日用于估计权重，较晚区间用于样本外比较。 |
| 分析同市场组合 | 读取组合股票、按日期内连接、计算权重和样本外曲线。 |

### 组合结果

- **组合权重**：等权 `1/n`；逆波动率权重 `(1/训练期标准差_i)` 归一化。
- **相关系数**：共同交易日日收益率的相关系数矩阵，范围 −1 到 1。
- **日收益率协方差**：共同交易日日收益率的样本协方差矩阵，单位是收益率平方。
- **样本外净值图**：等权与逆波动率两条曲线，按固定权重每日再平衡；起点归一为 1。
- **样本外表**：样本外方法、累计收益率、年化波动率、最大回撤。

需要区分：**权重只使用训练区间**；相关系数和协方差表使用全部共同交易日收益率。样本外曲线以训练期最后一个共同交易日为起点（归一为 1），随后进入样本外交易日。

## 推荐操作顺序

1. 先加载一只股票，读单资产风险指标，确认样本长度、价格口径和币种。
2. 在“组合股票代码”中输入 2–4 只当前市场的股票，确认代码不重复、位数正确。
3. 保持“组合权重训练比例”70%，点击“分析同市场组合”。
4. 先看“共同交易日 N 天”和权重表，确认权重之和为 100%，逆波动率权重只来自训练期。
5. 再看相关系数和协方差，注意它们使用全部共同交易日，不是只使用训练期。
6. 读样本外净值图和样本外表，比较等权与逆波动率；不要只看累计收益，也看年化波动和最大回撤。
7. 记录“未计调仓成本、股息和汇率”的限制，再决定是否需要另做成本更完整的回测。

## 一个可复现的小例子

### 单资产方差与年化波动

假设四个交易日的日收益率（小数）为 `0.01, -0.01, 0.02, 0.00`。

- 均值 = `(0.01 - 0.01 + 0.02 + 0) / 4 = 0.005 = 0.5%`。
- 偏差 = `0.005, -0.015, 0.015, -0.005`。
- 平方和 = `0.000025 + 0.000225 + 0.000225 + 0.000025 = 0.0005`。
- 样本方差 = `0.0005 / (4−1) = 0.00016667`。
- 样本标准差 = `√0.00016667 ≈ 0.01291 = 1.291%`。
- 年化波动率估计 = `1.291% × √252 ≈ 20.49%`。

若用百分数表示，方差是 `1.6667 %²`，标准差是 `1.291%`。不要把方差直接读成“1.6667% 的波动”；方差的单位是百分比的平方。

### 最大回撤

价格路径 `100 → 120 → 90 → 100`：

- 峰值依次为 100、120、120、120。
- 回撤依次为 `0%`、`0%`、`90/120−1 = −25%`、`100/120−1 ≈ −16.67%`。
- 最大回撤 = `−25%`；最终累计收益 = `100/100−1 = 0%`。

最大回撤描述路径中从高点向下的最深跌幅，不是未来损失上限；后来回升不会消除已经发生的回撤。

### 相关系数与协方差

用价格水平做公式练习：`X=[1,2,3]`，`Y=[2,4,6]`。

- 两者完全线性同向，相关系数为 `1`。
- 偏差乘积为 `2、0、2`，样本协方差为 `4/2 = 2`。

这是公式练习，不是组合页的收益率序列；组合页使用日收益率，且要求日期对齐。相关不等于因果，零相关也不保证未来分散风险。

### 逆波动率权重

假设训练期有两只股票 A、B，日收益率样本标准差分别为 `1.291%` 和 `0.957%`（用小数 `0.01291`、`0.00957`）。

- 逆波动率原始值：`1/0.01291 ≈ 77.46`，`1/0.00957 ≈ 104.45`。
- 总和 ≈ `181.91`。
- 权重：A ≈ `77.46/181.91 ≈ 42.58%`，B ≈ `104.45/181.91 ≈ 57.42%`。
- 等权则是各 `50%`。

权重只应用在训练期估计；样本外曲线按固定权重每日再平衡，未计调仓成本。

## 怎么判断结果是否有效

- 单资产指标至少有 3 个交易日；组合至少有 8 个共同交易日，训练和样本外各自满足最小长度。
- 权重表每列之和为 100%；逆波动率权重只使用训练期收益率；训练期某资产波动率为零时，程序应报错而不是编造权重。
- 相关系数在 −1 到 1 之间；协方差单位是收益率平方；两组收益必须同日对齐。
- 样本外净值图起点为 1；两条曲线使用相同共同日期和相同权重规则；样本外表使用同一净值序列。
- 等权与逆波动率的差异应结合权重、波动率、相关性和样本外区间解释；不能只看哪条线最后更高。
- 低历史相关不保证未来分散风险；相关性可能随市场状态变化；协方差和相关都不证明因果。
- 历史波动、回撤和相关性都是样本描述，不是未来风险预测。

## 常见错误与处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| “请输入 2–4 个不重复的当前市场股票代码” | 代码数量不对、重复、位数错误或跨市场 | 只保留 2–4 个当前市场的规范代码，去重。 |
| “共同交易日不足 8 天，无法做组合分析” | 股票停牌、区间太短或日期不重叠 | 扩大区间或换股票；不要手工补齐日期。 |
| “训练集或样本外区间太短” | 训练比例或共同交易日长度不合适 | 调整训练比例或扩大区间。 |
| “训练区间有资产波动率为零，不能计算逆波动率权重” | 某只股票在训练期收益率几乎不变 | 换股票或扩大区间；不要用零波动资产强行计算。 |
| 某只股票读取失败 | 上游无数据、代码错误或字段校验失败 | 检查代码和区间；失败时不要用另一批数据替代。 |
| 相关系数矩阵出现缺失 | 某列在共同日期上无有效收益 | 检查数据对齐和有效价格；程序会按内连接处理。 |
| 样本外曲线很短 | 训练比例过高或共同交易日太少 | 降低训练比例或扩大区间；不要把训练集结果当样本外。 |
| 等权与逆波动率差异很大 | 权重集中、波动率差异或样本外区间特殊 | 看权重和波动率，不要只比较最终收益；另找未使用区间复核。 |
| 把 CNY 与 HKD 股票放进同一组合 | 跨市场输入 | 当前组合只允许同市场同币种；跨币种需要汇率和独立模型，当前未实现。 |

## 数据、计算和适用边界

- 组合要求 2–4 只**同一市场、同一币种**股票；共同交易日按日期内连接。不同币种不能直接加总，当前不处理汇率。
- 等权为 `1/n`；逆波动率权重为 `(1/训练期标准差_i)` 归一化。两者只在之后的样本外交易日比较。
- 曲线按固定权重每日再平衡；未计调仓成本、换手成本、股息、税费或汇率。再平衡和换手是研究假设，不是可执行交易记录。
- 相关系数和协方差使用全部共同交易日收益率；权重只使用训练期。不要把相关矩阵误读为训练期专属。
- 单资产最大回撤基于价格序列；它描述历史路径，不是未来损失上限。年化波动率使用 `√252` 近似，不会自动适应每个市场、年份或停牌。
- 当前没有均值-方差优化、风险平价、因子模型、行业约束或跨币种组合；只有等权和逆波动率两个示例。
- 历史低相关不保证未来分散；相关不等于因果；组合历史表现不代表未来收益。
- 本页不执行真实交易，也不构成投资建议。
