# DeepSeek 助手：密钥、模型与显式请求

## 这一页是做什么的

DeepSeek 助手是可选的研究与学习辅助：它可以把研究问题草拟成有界的内置策略假设，审阅本地回测证据，或在“对话与辅导”中解释当前指标和概念。所有行情、信号、回测、统计和实验指纹都由本地代码计算；模型只生成文字、假设参数和仅供阅读的示例代码。

付费请求只在明确操作时发生：点击“生成 AI 假设”“让 AI 审阅实验”或“发送到 DeepSeek”。打开面板、切换页面、重绘、行情轮询和课程切换不会自动发送对话。没有 Key 时，离线手册、Quant Academy、知识解释和本地受控实验仍然可用。

## 使用前需要什么

- 一个你自己的 DeepSeek API 账户和 API Key；Key 不要发到聊天、笔记或截图里。
- 网络连接。首次真实连接建议在软件内用“测试连接”验证。
- 研究实验需要先加载真实历史日线；对话可以在没有行情时使用教学问答，但模型会明确缺少数据摘要。
- 了解 Key 的存放位置：只进入当前会话或 Windows 凭据管理器；不进入源码、普通设置、SQLite、日志或导出。
- 了解费用边界：测试连接和刷新模型只查询模型列表；生成假设、审阅实验和发送对话会使用你的账户，可能产生费用。软件没有自动付费重试。

## 控件和结果说明

### 设置中的 DeepSeek 标签

从左上角 `⚙` 打开设置，选择“DeepSeek”标签：

| 控件 | 作用 |
| --- | --- |
| DeepSeek API Key | 密码输入框；只在当前会话或系统凭据中保存。 |
| 记住密钥（Windows 凭据管理器） | 勾选并应用后写入 Windows 凭据管理器；下次启动自动读取。 |
| 应用密钥 | 应用当前输入；未勾选记住时只在会话保留。 |
| 读取密钥 | 从 Windows 凭据管理器读取本应用已记住的密钥。 |
| 清除密钥 | 清除会话密钥和本应用记住的凭据，不修改其他工具配置。 |
| 测试连接 | 调用官方模型列表接口，验证 Key 和网络；不生成补全内容。 |
| 刷新模型 | 重新取得官方可用模型列表。 |
| DeepSeek 模型 | 从官方模型列表选择；显示模型名称和 ID。 |
| 手动模型 ID | 尚未取得模型列表时，可手动填写官方模型 ID。 |
| 思考强度（按模型声明） | 仅当模型元数据声明支持时显示；可选择“模型默认”或声明支持的级别。 |

Key 校验要求非空、长度不超过 256 个字符且不含空白字符。系统安全存储不可用时，页面会提示并退回会话模式，不会写入明文文件。

### DeepSeek 面板

顶栏“DeepSeek 助手”打开右侧停靠面板。面板标题栏有 `⛶` 最大化和 `×` 关闭；左缘可拖动调整宽度。面板显示：

- 连接状态：“已连接 · 模型 ID”或“尚未完成 DeepSeek 连接设置”。
- 默认直接显示聊天记录、问题输入框和发送按钮。
- “⚙ 设置”弹层：回答模式、事实摘要、上下文预览、快捷问题、清空对话和保存回答均在需要时展开。
- “研究实验”按钮：进入原有研究工作区；使用“← 返回对话”回到聊天。

### 研究实验

点击“研究实验”后：

| 控件 | 作用 |
| --- | --- |
| 研究问题 | 1–600 个字符的可检验问题；默认给了一个双均线问题。 |
| 生成 AI 假设 | 明确发送付费请求；模型返回 JSON，经本地字段和参数验证。 |
| 运行受控实验（内置策略） | 本地运行内置策略；没有 Key 也可用固定模板。 |
| 让 AI 审阅实验 | 明确发送付费请求；只发送有限指标摘要。 |
| 下载可复核研究报告 | 本地生成 Markdown，包含来源、参数、成本、指纹和本地证据。 |

生成假设后，页面显示实际模型、标题、理由、经本地验证的策略类型和周期、假设列表、统计陷阱，以及“AI 草拟的示例代码（只展示，不执行）”。模型不能执行代码、下单或修改文件；示例代码仅供阅读。

运行受控实验后，页面显示“可独立复核的实验数据”JSON、实验指纹和本地指标。实验指纹由行情、信号、参数和成本假设计算；数值来自本地回测代码，不由 AI 生成。

### 对话与辅导

打开面板后默认进入对话；需要调整选项时点击“⚙ 设置”：

| 控件 | 作用 |
| --- | --- |
| 回答模式 | “研究解释模式”先列可核验事实，再解释含义、假设、局限和下一步检验；“教学辅导模式”先问一个小问题，再分步解释。 |
| 附带当前程序事实摘要 | 默认勾选；关闭后本次不附带研究摘要。 |
| 发送前查看上下文摘要 | 展开查看将要发送的 JSON；提示不附带私人笔记、完整行情或数据库。 |
| 快捷问题 | “解释当前指标”“分析本次回测”“给一个手算例子”“下一步学什么”；只填写草稿，不发送。 |
| 清空当前对话 | 清除当前作用域的对话记录。 |
| 问题（确认后发送） | 最多 3000 个字符；点击“发送到 DeepSeek”才发送。 |
| 选择回答保存为研究笔记 | 把选定的模型回答保存为研究笔记，并记录实际模型和来源；仍然需要人工复核。 |

如果从知识解释点击“向 AI 追问”，面板会保留学习内容并打开 DeepSeek，填入问题草稿；仍然需要确认发送。追问使用点击时的事实摘要；切换数据或实验后，上一份研究的对话历史不会继续发送。

## 推荐操作顺序

1. 打开 `⚙` → “DeepSeek”，填写自己的 API Key。
2. 决定是否勾选“记住密钥（Windows 凭据管理器）”，点击“应用密钥”。
3. 点击“测试连接”或“刷新模型”，取得官方模型列表；如果失败，可手动填写官方模型 ID。
4. 选择模型；如果模型声明支持思考强度，选择“模型默认”或所需级别。
5. 打开顶栏“DeepSeek 助手”，确认状态显示“已连接 · 模型 ID”。
6. 需要 AI 假设时，先在研究页面加载行情，再点击“研究实验”，写研究问题，点击“生成 AI 假设”；核对策略类型和周期是否在允许范围内。
7. 点击“运行受控实验（内置策略）”，由本地代码计算；先看审计 JSON 和指纹，再决定是否点击“让 AI 审阅实验”。
8. 需要概念解释时直接使用默认聊天界面；如需调整回答模式或核对上下文，展开“⚙ 设置”，再点击“发送到 DeepSeek”。
9. 对模型回答保存笔记前，先与原始数据、参数和公式交叉核对；AI 文字可能出错。

## 一个可复现的小例子

这是一个操作示例，不保证模型或上游数据当前可用，也不保证任何收益结果。

1. 在“市场数据”加载 A 股 `600519`，区间 `2025-01-02` 至 `2025-12-31`，不复权。
2. 打开 `⚙` → “DeepSeek”，填写 Key，勾选“记住密钥（Windows 凭据管理器）”，点击“应用密钥”；点击“测试连接”取得模型列表，选择模型。
3. 打开“DeepSeek 助手”，点击“研究实验”。研究问题填写：`双均线过滤能否改善这只股票的历史回撤？`
4. 点击“生成 AI 假设”。这是一次付费请求。检查返回的策略类型、短周期和长周期是否满足 `2 ≤ 短周期 < 长周期 ≤ 250`；若模型给出无效参数，本地验证会拒绝。
5. 点击“运行受控实验（内置策略）”。这一步在本地运行，不发送模型请求。记录实验指纹和本地指标。
6. 需要模型解释时，点击“让 AI 审阅实验”。这是第二次付费请求；发送的是有限指标摘要，不是完整行情或私人笔记。
7. 阅读审阅意见时，把“观察”“局限”“下一步检验”与本地审计 JSON 对照；AI 文字不是计算事实。
8. 点击“下载可复核研究报告”，报告包含来源、价格口径、实际交易日、策略、成本假设、指纹和本地证据；若模型已审阅，报告会标注“未经独立核实”。
9. 如果没有 Key：跳过第 2、4、6 步，直接点击“运行受控实验（内置策略）”，仍可得到本地实验和审计报告；AI 按钮保持不可用。

## 怎么判断结果是否有效

- 连接状态显示“已连接 · 模型 ID”；模型列表来自官方接口，实际模型会在回答或审阅旁显示。
- 研究实验的策略类型和周期通过本地验证；示例代码只展示，不执行；模型不能下单或修改文件。
- 审计 JSON、实验指纹和指标来自本地代码；AI 文字只能作为解释，必须与原始数据、参数、公式和样本外结果交叉核对。
- 对话上下文摘要只包含页面、标的、日期、来源、复权、指纹、指标、策略、成本和实验标识等程序事实；不包含私人笔记、完整行情表或数据库。发送前展开核对。
- 回答模式影响解释方式，不改变事实摘要或计算结果；“教学辅导模式”不会替软件判定学习完成。
- 付费请求只由明确按钮触发；测试连接和刷新模型只查询模型列表；重绘、轮询、切换课程不会自动发送。
- Key 只应在会话或 Windows 凭据管理器中；如果页面、日志、笔记或导出中出现 Key，立即停止使用并轮换密钥。
- 模型回答可能不完整、过时或错误；页面会标注“回答不完整”或错误信息，不会自动重试付费请求。

## 常见错误与处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示“请在左上齿轮设置中填写有效的 DeepSeek API Key” | Key 为空、过长或含空白 | 在 `⚙` → “DeepSeek”重新填写；不要把 Key 粘贴到问题或笔记。 |
| 401 鉴权失败 | Key 错误、失效或账户不匹配 | 核对 Key；必要时在 DeepSeek 账户中轮换。 |
| 402 余额不足 | 账户余额不足 | 检查你自己的 API 账户；软件不会自动充值或重试。 |
| 429 请求过于频繁 | 触发账户或服务限频 | 稍后手动重试；没有自动付费重试。 |
| 400/404/422 | 模型 ID、参数或接口不被支持 | 刷新模型列表、核对手动模型 ID，或使用模型默认设置。 |
| 请求超时 | 网络或服务端较慢 | 稍后手动重试；流式回答等待超过三分钟会停止。 |
| 模型列表为空 | 网络、Key 或接口异常 | 检查连接；可手动填写官方模型 ID。 |
| 提示“模型研究 JSON 未通过本地格式验证” | 模型输出字段、类型或参数不完整 | 手动重试或换模型；不要手工绕过验证。 |
| 提示“上下文摘要过长” | 附带信息超过摘要长度上限 | 减少附带信息，关闭“附带当前程序事实摘要”后重试。 |
| 提示安全存储不可用 | Windows 凭据管理器不可用 | 使用会话模式；不会写入明文文件。下次启动需要重新输入。 |
| 回答显示“不完整” | 流式连接中断或输出额度耗尽 | 手动重试；可尝试模型声明的较低思考强度。 |
| 尚未完成 DeepSeek 连接设置 | 尚未配置 Key 或模型 | 到左上角 `⚙` → “DeepSeek”配置密钥、测试连接并选择模型。 |
| 保存回答为研究笔记失败 | 数据库不可写或内容为空 | 检查资料库；笔记内容必须非空。 |

## 数据、计算和适用边界

- DeepSeek 只在你明确点击发送、生成假设或审阅实验时请求；打开面板、切换页面、重绘和行情轮询不发送对话。
- 模型列表和能力来自官方接口；模型 ID 和思考强度按接口声明使用。模型输出可能出错，不能代替本地计算。
- 研究实验只允许内置策略 `single_ma`、`dual_ma`、`trend`，周期满足 `2 ≤ 短周期 < 长周期 ≤ 250`；模型生成的示例代码只展示，永不执行。
- 实验指纹、指标、行情快照和审计 JSON 由本地代码生成；AI 审阅只读取有限摘要，不能修改实验、文件或数据库。
- 上下文摘要按当前数据指纹和实验隔离；切换数据或实验后不会发送上一份研究的对话历史。默认排除私人笔记、完整行情和数据库。
- Key 只进入当前会话或 Windows 凭据管理器；安全存储失败时回退会话，不使用明文文件。Key 不进入源码、普通设置、SQLite、日志或导出。
- 软件不提供实时行情，不执行实盘交易，不构成投资建议；AI 文字不是收益承诺，也不能证明策略未来有效。
- 付费请求没有自动重试；超时、限频和服务错误需要用户手动重试。请自行核对账户费用和额度。
