# 快速开始：从资料库到第一份可复现实验

## 这一页是做什么的

这一页把第一次使用 Quant Lab 的完整路径串起来：创建或选择本地资料库，选择市场和股票，加载并核对历史日线，生成收盘信号，运行一次带成本和成交假设的历史回测，最后把输入、参数、结果和你的判断保存为可复算的实验。

“可复现”在这里有明确含义：保存的不只是一张图或一个收益数字，还包括市场、规范代码、日期区间、复权口径、数据来源、接收时间、策略参数、费用与滑点假设、样本内比例、两份行情快照和实验指纹。只截图或只记下收益率，不算可复现实验。

## 使用前需要什么

- Windows 桌面版需要 Microsoft Edge WebView2 Runtime；源码运行方式需要能启动 Streamlit。两种方式都在本机运行，不执行真实交易。
- 第一次启动必须选择一个本地父目录，应用会在其中创建 `QuantLabCNHK` 资料库。资料库保存数据库、笔记附件、备份、日志、缓存和 WebView 数据；DeepSeek Key 不写入这个目录。
- 查询真实历史日线需要网络。离线时仍可阅读本手册、使用 Quant Academy 的固定教学样本；没有有效行情时，市场页的金融指标保持空白，不会用演示数据冒充真实行情。
- A 股使用六位代码（例如 `600519`），港股使用五位代码（例如 `00700`）。港股也接受 1–5 位数字并补足为五位。代码格式检查不等于验证证券身份，也不证明当前仍上市或可交易。
- 做一次均线回测，历史区间应明显长于所选长周期。程序要求回测至少有两个交易日，并且样本内、样本外各自不能过短；均线还需要预热。第一次使用建议选择至少一年的区间。

## 控件和结果说明

### 资料库

首次启动页面标题为“创建 Quant Lab 专用资料库”，主要控件如下：

| 控件 | 作用 |
| --- | --- |
| 选择新的存放文件夹 | 选择一个本地目录；应用会在其下创建 `QuantLabCNHK` 子目录。 |
| 浏览 Windows 文件夹… | 桌面版调用系统目录选择器；浏览器模式不能调用时，需要手动填写路径。 |
| 创建资料库并迁移现有数据 | 创建目录结构，复制并校验现有数据库、笔记、备份和证券缓存；原目录保留。 |
| 关闭并重新启动软件 | 资料库激活后按提示重启，后续页面才使用新资料库。 |

设置面板的“资料文件夹”标签会显示“当前资料库位置”，并提供同一套创建/迁移控件；复制校验成功后显示“迁移后的资料库位置”。未创建托管资料库时，Windows 默认目录是 `%LOCALAPPDATA%\QuantLabCNHK`。

### 左侧研究参数

| 控件 | 作用 |
| --- | --- |
| 市场 | 选择“A 股”或“港股”；市场决定代码规则、币种和默认数据源。 |
| 股票（代码 / 名称） | 可按代码或中文名称搜索候选；未收录代码可直接输入并选择新增项。支持 `SH`、`SZ`、`BJ`、`HK` 前后缀的常见写法。 |
| 历史区间 | 选择开始和结束日期；只使用上游实际返回的交易日。 |
| 价格口径 | 不复权、前复权、后复权。口径影响信号和历史价格展示；回测成交始终另取不复权价格。 |
| 加载真实历史日线 | 联网获取并验证数据；失败时显示错误，不用演示值补齐。 |
| 更新股票候选目录 | 联网更新代码/名称目录；失败保留旧目录和获取时间。 |
| 重新获取证券名称 | 绕过名称成功缓存和失败冷却，重新查询证券基础资料。 |
| 从自选股选择 | 从已保存的自选股中切换市场和代码。 |

### 市场数据页

加载后重点核对：

- “数据更新状态”中的行情日期、上次成功获取时间、来源、缓存状态、缓存年龄、自动刷新、间隔、下次尝试时间和最近更新结果。
- “研究概览”中的区间简单价格收益率、区间最高价、区间最低价和样本交易日。
- “行情图表”中的“收盘价与成交量”和“日 K 线”两个标签页。
- “历史数据”表格及“导出 CSV”按钮。
- “自选股 · 最近历史日线收盘参考”中的“加入自选”“移除所选”“立即更新自选股”。

### 策略实验室

选择“策略类型”，设置“短周期（交易日）”和“长周期（交易日）”。图表同时显示收盘价、短均线、长均线和信号变化标记；下方表格显示最近 30 个交易日的收盘价、短均线、长均线和“目标持仓信号（1=持有）”。

### 历史回测

“成交与费用假设（均可调整）”中包含初始资金、买入交易单位、佣金、单笔最低佣金、买入/卖出附加费用、单边滑点和 A 股简化涨跌停假设。设置“样本内比例”后点击“运行历史回测”，页面显示策略累计收益、年化收益估计、最大回撤、夏普比率、同成本买入并持有基准、净值图、样本内外表、交易与未成交记录、参数敏感性表，以及“保存本次实验与研究笔记”折叠区。

### 研究笔记

在顶栏打开“研究笔记”面板，可按分类、内容类型和关键词查找笔记或实验。选择保存的实验后，可以“从存档数据重新计算”“导出 Markdown 研究报告”或“导出可复现研究包 ZIP”。

## 推荐操作顺序

1. 创建或选择资料库，按提示重启软件。资料库路径确定后，不要在不同目录之间来回覆盖研究数据。
2. 在左侧选择市场，搜索并选择股票，设置历史区间和价格口径，点击“加载真实历史日线”。
3. 先读“数据更新状态”和“数据说明”，确认来源、币种、价格口径、最新交易日、接收时间和缓存状态，再读收益与图表。
4. 进入“研究工作台”的“策略信号”，选择“双均线趋势”，先用短周期 10、长周期 30，观察均线和收盘后信号。
5. 进入“研究工作台”的“历史回测”，核对成交与费用假设，保持样本内比例 70%，点击“运行历史回测”。
6. 先看订单表：决策日和成交日是否相差至少一个交易日，成交价是否使用不复权开盘价，是否存在因零成交量、T+1、涨跌停或资金不足而未成交的订单。
7. 再比较策略与同成本买入持有基准，读样本内/样本外表、最大回撤、夏普和参数敏感性；不要只挑收益最高的参数。
8. 在“保存本次实验与研究笔记”中填写研究标题、研究假设和学习笔记，点击“保存实验”。
9. 打开“研究笔记”，选择刚保存的实验，点击“从存档数据重新计算”，确认指纹一致；再导出 ZIP，检查报告和两份行情 CSV。
10. 记录下一次独立检验要用的未参与调参的区间。若已经反复查看某个测试区间，该区间就不再是干净的样本外。

## 一个可复现的小例子

下面是一个**操作示例**，不是收益承诺。上游数据可能变化、延迟或暂时不可用；若示例代码没有数据，换一个区间或股票，不要用演示数据替代。

1. “选择新的存放文件夹”设为 `D:\QuantLabData`，应用创建 `D:\QuantLabData\QuantLabCNHK`。按提示重启。
2. 市场选择“A 股”，股票输入 `600519`，历史区间设为 `2025-01-02` 至 `2025-12-31`，价格口径选择“不复权”，点击“加载真实历史日线”。
3. 核对“数据说明”：数据类型应为 A 股历史日线，来源显示腾讯证券经 AKShare 获取，币种为 CNY，成交量单位为股，延迟状态为“历史日线；确切延迟未知”。记录最新交易日和“接收时间（北京时间）”。
4. 在“研究概览”读取区间首尾收盘价。口径检查可以手算：若首日收盘价为 100、末日收盘价为 110，则区间简单价格收益率是 `110/100 - 1 = 10%`。这是价格收益率，不含分红、费用和滑点；不要把它当成总回报。实际数值以页面显示为准，不要填入虚构价格。
5. 进入“研究工作台”的“策略信号”，选择“双均线趋势”，短周期 10，长周期 30。先观察前 29 个交易日没有长均线，目标持仓信号为 0；这是预热，不是程序故障。
6. 进入“研究工作台”的“历史回测”，在“成交与费用假设（均可调整）”中设置：初始资金 1,000,000，买入交易单位 100 股，佣金 3 基点，单笔最低佣金 5 元，买入附加费用 0 基点，卖出附加费用 5 基点，单边滑点 2 基点，简化涨跌停假设 10%。这些是可修改的研究假设，不是当前法定税费或券商报价。
7. 保持“样本内比例”70%，点击“运行历史回测”。记下“实验指纹”。检查净值图黄色虚线起为样本外区间，订单表的决策日早于成交日，成交价与不复权开盘价加滑点一致。
8. 在保存区填写：
   - 研究标题：`600519 双均线 10/30 实验`
   - 研究假设：`在样本外，双均线 10/30 的风险收益特征是否与样本内一致？`
   - 学习笔记：写下你对回撤、费用、订单未成交和样本长度的判断。
   点击“保存实验”。
9. 打开“研究笔记”，选择该实验，点击“从存档数据重新计算”。若页面显示复算成功且指纹与保存记录一致，说明归档输入、参数和成本假设能重新得到同一指纹。
10. 点击“导出可复现研究包 ZIP”，解压后应看到 `report.md`、`raw_history.csv`、`signal_history.csv` 和 `assumptions.json`。检查两份 CSV 的日期、价格和信号是否与保存时一致。

这个例子只验证流程和口径，不说明该股票、该区间或该策略未来会盈利。

## 怎么判断结果是否有效

- **数据有效**：表格非空；日期是实际交易日；来源、币种、价格口径与左侧选择一致；最新交易日和接收时间都有记录；更新失败时页面明确保留旧数据并提示可能过期。
- **信号有效**：均线预热足够；信号只使用当日及此前收盘价；图表三角标记表示信号变化，不是成交；信号为 0 也可能是合法结果。
- **回测有效**：决策日与成交日至少相差一个交易日；买入价为不复权开盘价加滑点，卖出价为不复权开盘价减滑点；费用按成交额和最低佣金计算；A 股 T+1、零成交量和简化涨跌停限制被执行；基准使用同一成本和交易单位。
- **比较公平**：策略和基准使用同一区间、同一币种、同一成交规则；样本内用于选择参数，样本外用于评估；参数敏感性只应作为样本内证据。
- **可复现**：保存记录包含两份行情快照、参数、成本和指纹；复算指纹一致；导出的 ZIP 能独立检查。
- **解释克制**：回测收益不是未来收益；最大回撤不是未来损失上限；夏普比率不是盈利概率；方向一致率高也不等于扣除费用后能赚钱。

## 常见错误与处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示“请选择完整的开始和结束日期” | 日期控件只选了一个端点 | 重新选择完整的开始和结束日期。 |
| 提示 A 股六位、港股 1–5 位代码 | 代码位数或前缀不符合规范 | 输入六位 A 股代码或 1–5 位港股代码；港股会自动补足为五位。 |
| 提示“该股票在所选日期内没有历史交易记录” | 区间内无交易日、代码无数据或上游不覆盖 | 调整区间或核对代码；不要据此断言证券不存在。 |
| 历史行情加载失败 | 网络、上游接口或字段校验失败 | 阅读页面错误和资料库 `logs/data_errors.log`；保留旧数据时注意获取时间，不要把缓存读取当作新行情。 |
| 证券名称显示“名称暂不可用” | 名称资料接口失败或冷却中 | 点击“重新获取证券名称”；失败只说明名称暂不可用，不代表证券不存在。 |
| 策略图没有买入/卖出标记 | 预热不足、信号一直不变或窗口设置不合适 | 延长区间、减小长周期，或确认当前信号本来就是 0；没有信号不是程序故障。 |
| 回测提示历史交易日不足 | 区间太短或长周期相对区间过长 | 扩大区间或减小长周期；至少满足长周期加预热和样本内外要求。 |
| 回测提示不复权成交数据更新失败 | 复权信号已取得，但不复权成交价请求失败 | 稍后重试；程序会停止本次回测，避免混用不同获取批次。 |
| 订单大量未成交 | 零成交量、A 股 T+1、假设涨跌停、资金不足或交易单位过大 | 查看订单表的“reason”列；逐项核对假设，不要只改收益目标。 |
| 保存实验失败 | 研究标题或假设为空，或数据库写入失败 | 填写标题和假设；检查资料库可写性和磁盘空间。 |
| 复算指纹不一致 | 存档快照损坏、代码版本变化或归档参数不一致 | 不要覆盖原实验；保留错误信息，交给 Codex 复核。 |
| 自选股无法加入 | 已满 10 只或数据库写入失败 | 先移除不需要的股票；检查资料库目录。 |

## 数据、计算和适用边界

- 软件只提供 A 股和港股**历史日线研究**，不提供实时行情，不执行实盘交易。自选股是最近历史日线收盘参考，行情日期是交易日，确切延迟未知。
- A 股历史主链路为 AKShare 腾讯接口；港股主链路为 AKShare 东方财富接口，失败时可能回退新浪并明确显示来源。价格和成交额分别使用 CNY/HKD，成交量单位为股。
- 收盘信号只能使用当日及更早数据，最早下一交易日开盘模拟成交。复权价格可以生成信号，成交和估值只能使用同日不复权价格。
- 费用、滑点、整手、T+1 和涨跌停都是研究假设。程序不声称覆盖交易所全部规则，也不还原订单簿、盘中停牌、涨跌停队列、分红现金流或幸存者偏差。
- 不同币种不能直接加总；当前组合要求同市场、同币种。
- 当前策略只有内置单均线、双均线和趋势过滤；当前统计分析是描述性统计、均值为零的 t 检验和时间顺序线性回归，不是分类器、因子框架或自动交易系统。
- 本手册按 2.2.0 的纯阅读使用手册结构编写。早期版本的入口名称、学习面板内容可能不同；以当前界面实际控件为准。手册只提供阅读和检索，不记录学习进度，也不要求提交任何内容。
