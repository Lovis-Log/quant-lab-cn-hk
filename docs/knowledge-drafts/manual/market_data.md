# 市场数据：代码、名称、区间、复权、来源与缓存

## 这一页是做什么的

“市场数据”页负责研究的第一步：把一只 A 股或港股股票的历史日线取回来，验证字段，标明来源、币种、价格口径、交易日和接收时间，然后用图表、区间指标和表格展示，并允许导出 CSV 和管理自选股。

这一页描述的是已经发生的交易，不是实时行情。它不预测价格，也不产生买卖建议。自选股中的“最近日线收盘”只是最近一个历史交易日的收盘参考，不是盘中报价。

## 使用前需要什么

- 已完成资料库配置；查询真实行情需要网络。
- 知道市场与代码规则：A 股六位数字（例如 `600519`），港股五位数字（例如 `00700`）。港股也接受 1–5 位数字并补足为五位；`SH`、`SZ`、`BJ`、`HK` 前缀或 `.SH`、`.SZ`、`.BJ`、`.HK` 后缀会在规范化时处理。
- 选择一个包含足够交易日的区间。只有一个交易日时不会显示区间收益率；跨除权除息事件时，不复权价格的变化不等于总回报。
- 决定价格口径：不复权、前复权或后复权。口径会影响页面收益率和信号价格；回测成交始终另取不复权价格。

## 控件和结果说明

### 左侧“研究参数”

| 控件 | 具体行为 |
| --- | --- |
| 市场 | 在“A 股”和“港股”之间切换；不同市场有各自的代码选择和默认代码。 |
| 股票（代码 / 名称） | 可搜索代码或中文名称；候选来自证券目录。未收录代码可以输入后选择新增项确认。候选排序不是买入推荐。 |
| 历史区间 | 默认最近一年；结束日期不能晚于今天。只使用上游实际返回的交易日。 |
| 价格口径 | “不复权”“前复权”“后复权”三选一。 |
| 加载真实历史日线 | 联网获取、验证并加载；失败显示错误，不用演示数据补齐金融指标。 |
| 更新股票候选目录 | 联网更新代码/名称目录；失败保留旧目录和获取时间。 |
| 重新获取证券名称 | 绕过名称成功缓存（24 小时）和失败冷却（5 分钟），重新查询证券基础资料。 |
| 从自选股选择 | 从已保存的自选股切换市场与代码。 |

左侧底部会显示当前来源提示：A 股为“腾讯证券，经 AKShare 获取；历史日线”，港股为“东方财富，经 AKShare 获取；历史日线”。港股实际回退到新浪时，页面数据说明会显示“东方财富请求失败后回退”，不会隐藏来源切换。

### 数据更新状态

市场页顶部有“立即更新历史日线”和“暂停自动刷新/恢复自动刷新”。状态区显示：

- 行情日期（交易日）或“无有效日期”
- 上次成功获取时间（北京时间 `UTC+08:00`）
- 来源
- 缓存状态：“本次取得上游响应”“本地缓存/会话快照”或“上次有效数据（更新失败）”
- 缓存年龄
- 自动刷新：开启/暂停
- 间隔：5、10 或 15 分钟
- 下次尝试时间
- 最近更新结果：“取得新数据”“检查成功，数据未变化”或“请求失败；数据可能过期”

“立即更新”会绕过当前查询的缓存，实际请求上游；连续点击有 5 秒防抖。自动刷新只在市场页和当前应用会话运行时生效，关闭软件或离开市场页后不会后台轮询。缓存读取不会更新“上次成功获取时间”；成功但数据未变化会明确显示“检查成功，数据未变化”。

### 研究概览与图表

“研究概览”显示：

- 区间简单价格收益率：首尾两个实际交易日收盘价的 `P_end/P_start - 1`
- 区间最高价：区间内日线最高价的最大值
- 区间最低价：区间内日线最低价的最小值
- 样本交易日：仅统计上游返回并验证通过的交易日

“行情图表”有两个标签页：

- **收盘价与成交量**：收盘价折线和成交量柱形。
- **日 K 线**：开、高、低、收 K 线和成交量；红色上涨，绿色下跌。

图表标题使用“市场 代码（名称）”。名称不可用时显示“名称暂不可用”，不代表证券不存在。

### 数据说明

“数据说明”逐项显示数据类型、数据来源、本地缓存、价格口径、价格币种、最新交易日、接收时间（北京时间）、延迟状态、成交量单位和实时行情。当前软件明确写“历史日线；确切延迟未知”和“实时行情：不提供”。

### 历史数据与导出

“历史数据”表格列出日期、开盘价、最高价、最低价、收盘价、成交量（股）和成交额。价格单位：A 股为元/股、港股为港元/股；成交额使用同一币种；成交量单位为股。“导出 CSV”导出当前已验证的日线，文件名为市场、代码、首尾日期和口径的组合，编码为 UTF-8 with BOM，便于 Windows Excel 识别中文列名。

### 自选股

“自选股 · 最近历史日线收盘参考”区域：

- “加入自选”：保存当前市场与代码，最多 10 只。
- “移除自选股”与“移除所选”：从已保存列表移除。
- “立即更新自选股”：绕过自选股快照缓存；连续点击需等 5 秒，不同股票的上游请求至少间隔 1 秒。
- 表格列包括股票、最近日线收盘、币种、行情日期、上次成功获取时间、来源、缓存状态、缓存年龄、自动刷新、间隔、下次尝试时间、最近更新结果和延迟状态。

自选股快照缓存为 5 分钟；失败保留最近有效数据和成功获取时间，不用页面重绘时间冒充上游获取时间。

### 证券名称与候选目录

- 公司简称来自东方财富证券基础资料接口：A 股使用公司基础资料，港股使用证券资料；按“市场＋规范代码”缓存 24 小时，失败冷却 5 分钟。失败时只显示名称暂不可用，不据此断言证券不存在。
- 搜索候选来自内置基础资料快照和可选的联网更新。内置快照接收于 2026-10-14，包含 6,181 条 A 股和 3,033 条五位港股资料；联网更新会写入用户资料库，不覆盖安装目录中的发行资源。
- 候选目录只含身份字段，不含价格、复权或金额，不验证当前上市或可交易状态，也不构成买入推荐。

## 推荐操作顺序

1. 选择市场。
2. 用代码或中文名称搜索并选择股票；未收录代码手动输入后选择新增项。
3. 设置历史区间，建议至少一年；确认开始日期不晚于结束日期。
4. 选择价格口径。第一次研究建议先用“不复权”核对原始价格，再决定是否用复权口径生成信号。
5. 点击“加载真实历史日线”，等待获取与字段验证。
6. 先读“数据更新状态”和“数据说明”，核对来源、币种、价格口径、最新交易日、接收时间和缓存状态。
7. 再读“研究概览”、收盘价与成交量图、日 K 线和历史数据表。
8. 需要离线检查时导出 CSV；注意 CSV 是当前查询的快照，不是自动更新文件。
9. 需要长期观察时加入自选股，最多 10 只；失败时先看状态区，不要把缓存读取当作新行情。

## 一个可复现的小例子

### A 股示例

1. 市场选择“A 股”，股票输入 `600519`，区间设为 `2025-01-02` 至 `2025-12-31`，价格口径“不复权”，点击“加载真实历史日线”。
2. 在“数据说明”核对：数据类型为 A 股历史日线；来源为腾讯证券 · AKShare；价格币种为 CNY；成交量单位为股；延迟状态为“历史日线；确切延迟未知”；实时行情为“不提供”。
3. 在“研究概览”读取首尾收盘价。假设页面显示首日收盘 100、末日收盘 110（这只是口径示例，不是该股票的真实价格），则区间简单价格收益率为 `110/100 - 1 = 10%`。用页面实际首尾收盘价做同样计算，结果应与“区间简单价格收益率”一致。
4. 检查“区间最高价”和“区间最低价”是否分别来自日线最高价的最大值和最低价的最小值，而不是收盘价。
5. 在“历史数据”中检查日期升序、无重复交易日、开盘/最高/最低/收盘都大于零、最高价不低于最低价、开盘和收盘位于最高与最低之间。
6. 导出 CSV，用 Excel 打开，确认中文列名和 UTF-8 BOM 正常；不要用 CSV 中的价格除以成交量来解释价格。

### 港股示例

1. 市场切换为“港股”，股票输入 `700` 或 `00700`，区间同样设置，点击加载。
2. 核对价格币种为 HKD，成交量单位为股；来源可能是“东方财富 · AKShare”，也可能是“新浪财经 · AKShare（东方财富请求失败后回退）”。
3. 不要把 HKD 价格与 A 股 CNY 价格相加，也不要把两者的区间收益率直接比较为同一组合收益。

## 怎么判断结果是否有效

- 表格非空，日期是实际交易日；只有一个交易日时不显示区间收益率是预期行为。
- 价格大于零，成交量与成交额非负，最高价不低于最低价，开盘/收盘在最高与最低之间；字段校验失败会显示错误，不应手动修补后继续。
- 来源、币种、价格口径与左侧选择一致；港股回退时来源文字明确变化。
- 最新交易日和上次成功获取时间都有记录；`received_at` 是本机收到响应的时间，不是交易所报价时间。
- 缓存状态与缓存年龄能解释为什么同一交易日的收盘价多次检查都不变化；缓存不是新行情。
- 区间收益率是简单价格收益率，不含现金分红、费用和滑点；除权除息附近的不复权价格跳变不应解释为总回报。
- 图表不是实时行情；自选股是最近历史日线收盘参考，不是盘中价格。

## 常见错误与处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| “A 股请输入 6 位数字；港股可输入 1–5 位数字” | 代码位数或前缀不符合规范 | 输入六位 A 股代码或 1–5 位港股代码；港股会自动补足五位。 |
| “请选择完整的开始和结束日期” | 日期只选了一个端点 | 重新选择完整区间。 |
| “开始日期不能晚于结束日期” | 区间反向 | 交换开始和结束日期。 |
| “该股票在所选日期内没有历史交易记录” | 区间无交易日、代码无数据或上游不覆盖 | 调整区间或核对代码；不要据此断言证券不存在。 |
| “数据源缺少必要字段”或字段校验失败 | 上游接口变化、列名异常、重复日期、非正价格、最高价小于最低价等 | 阅读页面错误和 `logs/data_errors.log`；不要用演示数据补齐。 |
| “历史行情暂时无法获取” | 网络、上游接口或超时 | 稍后重试；保留旧数据时注意“上次成功获取时间”和“可能过期”提示。 |
| 名称显示“名称暂不可用” | 名称资料接口失败或处于 5 分钟冷却 | 点击“重新获取证券名称”；失败不代表证券不存在。 |
| “更新股票候选目录”失败 | 网络或目录响应异常 | 保留旧目录和获取时间；稍后重试，不要手工覆盖用户目录。 |
| 点击“立即更新”提示等待 | 5 秒防抖尚未结束 | 等待提示秒数后再点；本次没有重复请求。 |
| 自选股加入失败 | 已满 10 只或数据库写入失败 | 移除不需要的股票；检查资料库可写性。 |
| 自选股没有参考价格 | 从未成功获取，或自动刷新暂停 | 点击“立即更新自选股”；暂停时不会发起请求。 |
| 前复权价格与之前看到的不同 | 新公司行动导致历史复权值变化 | 记录查询日期和口径；不要跨时间混用不同复权序列。 |

## 数据、计算和适用边界

- 软件只读取股票历史日线，不提供指数模块；代码位数校验不等于交易所名录验证，请勿用指数代码代替股票。
- A 股通过 AKShare 腾讯接口；港股以 AKShare 东方财富历史接口为主，失败时回退新浪并显示来源。价格和成交额币种分别为 CNY/HKD，成交量单位为股。
- 不复权保留原始报价；前复权调整历史价格使近期价格保持原值；后复权调整后续价格使早期价格保持原值。复权值会随公司行动变化，不等于当时可成交报价。
- 页面区间收益率使用当前选择的价格序列；回测可以选用复权价格生成信号，但模拟成交和净值始终使用同日不复权价格。
- 上游失败、字段缺失或校验失败会显示错误并写入 `logs/data_errors.log`；缓存只能复用已校验数据，不能在失败后伪装成功。
- 证券名称和候选目录是身份辅助信息，不是上市状态、可交易状态或买入推荐；名称失败不等于证券不存在。
- 不同市场、不同币种不能直接加总；本页的区间收益率是价格收益率，不含分红、费用、滑点和汇率。
- 历史日线无法还原订单簿、盘中停牌细节、涨跌停队列、公司行动现金流和幸存者偏差。
