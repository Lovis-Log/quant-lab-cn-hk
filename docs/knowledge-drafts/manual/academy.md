# Quant Academy：固定教学样本与参数实验

## 这一页是做什么的

Quant Academy 是内置的金融数学实验室：用固定、可手算的教学数据演示收益率、均线、方差、波动率、最大回撤、夏普比率、相关系数和回测偏差。每个课程都给出公式、Python 代码、可拖动参数、结果表和结论，并链接到对应的知识解释。

这里的“价格”“净值”“收益”都是教学样本，不是任何股票的真实行情，也不是未来收益预测。它的用途是先把公式和单位弄清楚，再回到“市场数据”“策略实验室”“历史回测”等页面观察同样的概念在真实历史数据上的表现。

## 使用前需要什么

- 不需要网络，不需要 DeepSeek Key，也不需要先加载真实行情。
- 建议先准备纸笔。每个课程先手算一个小样本，再拖动参数，比较手算与表格/结论是否一致。
- 理解“教学样本”和“历史行情”的区别：教学样本是固定的、可重复的演示数值；真实行情有来源、交易日、复权、币种和延迟。
- 不需要提交任何内容；本页是阅读和参数实验，不记录学习进度。

## 推荐操作顺序

1. 选择一节课程，先读“Python 实现”上方的课程标题和公式。
2. 先不要拖滑块，用纸笔计算默认参数下的一个结果。
3. 拖动“调参数试一试”，观察表格和结论条如何变化；一次只改一个参数。
4. 展开“知识解释”，核对定义、符号、手算例子和边界；注意“当前结果怎么读”使用的是教学样本，不是行情。
5. 读“思考问题”，用纸笔回答，再回到表格验证。
6. 到对应的真实数据页面观察同一概念：收益率到“市场数据”，均线到“策略实验室”，方差/波动/回撤/相关到“风险与组合”，回测偏差到“历史回测”。
7. 记录教学样本与真实行情的差异：来源、样本长度、复权、币种、成本和成交假设。

## 一个可复现的小例子

### 最大回撤课程

默认净值路径 `100 → 120 → 90 → 100 → 130`：

- 峰值依次为 `100, 120, 120, 120, 130`。
- 回撤依次为 `0%, 0%, 90/120−1 = −25%, 100/120−1 ≈ −16.67%, 0%`。
- 最大回撤 = `−25%`；期末收益 = `130/100−1 = 30%`。

把“低点净值”拖到 60：路径变为 `100, 120, 60, 100, 130`，最大回撤 = `60/120−1 = −50%`；期末收益仍为 30%。这说明最大回撤描述路径中的阶段性损失，不是期末收益，也不是未来损失上限。

### 简单收益率与复利课程

默认每期收益率 10%，本金 100，6 期（0–5）：

- 第 5 期本金 = `100 × (1.10)^5 = 161.051`。
- 总收益率 = `161.051/100−1 = 61.051%`。

若把收益率改为 0%，第 5 期仍为 100；若改为 −10%，第 5 期约为 `100 × 0.9^5 = 59.049`。先涨 10% 再跌 10% 的结果是 `100 × 1.1 × 0.9 = 99`，不是 100；每期基数在变化。

### 移动平均线课程

固定收盘价 `10, 12, 14, 13, 15, 18, 16, 17, 19, 20`，窗口 3：

- 第 3 日均线 = `(10+12+14)/3 = 12`。
- 第 4 日均线 = `(12+14+13)/3 = 13`。
- 最后一天 3 日均线 = `(17+19+20)/3 = 18.667`。

窗口加长会更平滑、反应更慢；当天均线只能在当天收盘后确认。

### 方差与标准差课程

默认样本 `1, 2, 3`：

- 均值 = 2。
- 偏差 = `−1, 0, 1`。
- 样本方差 = `(1+0+1)/(3−1) = 1`。
- 样本标准差 = 1。

把第三个样本值改为 5：样本 `1, 2, 5`，均值 `2.667`，样本方差 `4.333`，标准差约 `2.082`。分母是 `n−1`，不是 `n`。

### 波动率课程

默认价格 `100, 101, 99, 102, 103, 104`，先算日收益率，再算样本标准差，最后乘 `√252`。课程结论条会显示当前教学样本的日标准差和年化近似。若日标准差为 1%，年化约为 `1% × √252 ≈ 15.87%`；这是近似，不是未来波动预测。

### 夏普比率课程

默认日收益 `1%, 3%, −1%, 2%`：

- 均值 = `1.25%`。
- 样本标准差 ≈ `1.708%`。
- 日无风险收益参数为 0 时，年化夏普 ≈ `1.25/1.708 × √252 ≈ 11.62`。

这是四个样本的公式练习，数值很大但不可靠；课程会提示“样本极短”。把日无风险收益调高，分子变小，夏普下降；若分子为负，夏普为负。

### 相关系数课程

默认 `X=[1,2,3,4]`，`Y=[2,4,6,8]`：

- 两者完全线性同向，相关系数为 1。
- 把第二组中间值改为 0，`Y=[2,0,6,8]`，相关不再是 1；具体数值以表格为准。

相关不等于因果；教学样本的完全相关不代表真实资产未来也完全同向。

### 回测偏差与过拟合课程

“尝试的参数组数”从 1 到 100。表格列出每组参数的训练期演示收益和测试期演示收益；结论条给出训练期最佳组及其测试期表现。训练期最佳不一定在测试期最佳；尝试组数越多，挑到训练期“看起来最好”的偶然结果的机会越大。这里的收益是固定模拟值，不能推断普遍胜率，也不是概率估计。

## 怎么判断结果是否有效

- 表格和结论条都来自固定教学样本；数值应能用手算复现。若手算与程序不一致，先检查是价格还是收益率、样本还是总体、分母是 `n` 还是 `n−1`。
- 滑块只改变教学参数，不访问网络、不读取真实行情、不写入研究实验；课程结果不随股票选择变化。
- 知识解释中的“当前结果怎么读”使用教学样本，不是行情；不要把它当成某只股票的风险或收益。
- 过拟合课程展示的是参数组对照，不产生单一“当前值”；知识解释区可能提示没有足够的计算值，应以表格和结论条为准。
- 教学数据中的高夏普、低回撤或完全相关都是演示结果，不是策略质量证明，也不是未来收益。
- 若页面没有网络或没有 Key，八节课程仍应可用；不可用时先检查应用启动和资料库，不要用真实行情替代教学样本。

## 常见错误与处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 把表格数值当成真实股票价格 | 教学样本与行情页面混淆 | 看页面标题和“固定教学样本”提示；真实行情到“市场数据”加载。 |
| 手算方差与程序不一致 | 分母用了 `n` 而不是 `n−1`，或把百分数当小数 | 用样本方差 `Σ(x−x̄)²/(n−1)`；收益率统一用小数或统一用百分数。 |
| 均线最后一天为空 | 窗口大于样本长度或数据不足 | 减小窗口；教学样本固定为 10 个价格，窗口最大 10。 |
| 夏普数值异常大 | 样本极短、波动很小或参数设置特殊 | 把结果当公式练习；不要外推为真实策略表现。 |
| 相关系数不是 1 或 −1 | 中间值改变后不再完全线性 | 以表格为准；完全相关只是特例。 |
| 过拟合课程知识解释提示“没有足够计算值” | 该课程不产生单一当前指标 | 看表格和结论条；这是教学设计，不是行情缺失。 |
| 没有 Key 时担心课程不可用 | 误以为所有功能都需要 DeepSeek | 课程、知识解释和参数实验都离线可用；只有明确发送的 AI 请求需要 Key。 |
| 想把教学实验保存为研究实验 | 教学样本不是行情，不能当作真实研究 | 真实研究请到“历史回测”加载行情并保存实验。 |

## 数据、计算和适用边界

- 八节课程全部使用固定教学数据，不是任何证券的历史行情，也不是随机生成的“行情”；模拟/教学数据必须明确标记。
- 课程覆盖简单收益率与复利、移动平均线、方差与标准差、波动率、最大回撤、夏普比率、相关系数、回测偏差与过拟合。
- 参数范围由课程定义；滑块不会产生超出范围的值。教学表格和结论条由本地函数计算，不调用模型 API。
- 课程中的公式、单位、分母和边界与 `docs/METHODOLOGY.md` 和知识解释保持一致；出现差异时以代码和文档为准，并记录给 Codex。
- Quant Academy 是可选固定样本实验，不记录学习进度，也不要求提交任何内容；本手册按 2.2.0 的纯阅读结构编写。早期版本若仍显示学习中心入口，以本手册的目标结构为准。
- 教学结果不构成投资建议，不执行真实交易，也不代表未来收益。
