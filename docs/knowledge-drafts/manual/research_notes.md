# 研究笔记：分类、草稿、附件、回收站与实验复算

## 这一页是做什么的

“研究笔记”面板统一管理两类内容：你手写或从 AI 回答保存的研究笔记，以及从“历史回测”保存的研究实验档案。它支持层级分类、标题/正文/假设搜索、草稿自动保存、Markdown 正文、托管附件、回收站、实验复算和 ZIP 导出。

笔记是私人学习内容，实验档案是可复算的研究快照。两者可以放在同一分类树下，但用途不同：笔记记录你的理解和判断，实验档案保存当时的行情输入、策略参数、成本假设、结果和指纹。更新行情不会修改已有实验快照；新研究应另存实验。

## 使用前需要什么

- 已完成资料库配置；研究笔记、附件和实验都写入当前资料库。
- 要导出或复算实验，先在“历史回测”运行并保存至少一个实验。
- 笔记标题和正文不能为空；附件必须符合类型和大小限制。
- 不要把 DeepSeek Key 粘贴到笔记、附件或 AI 问题中；笔记导出和 AI 上下文默认不包含 Key，但手工粘贴无法自动保护。
- 了解回收站与永久删除的区别：移到回收站可恢复；永久删除不可撤销。

## 控件和结果说明

### 分类管理

展开“分类管理”：

| 控件 | 作用 |
| --- | --- |
| 父分类 | 选择“根目录”或已有分类；新分类创建在其下。 |
| 分类名称 | 1–80 个可见字符；同一父分类下不能重名。 |
| 新增分类 | 创建分类；最多 8 层。 |
| 编辑分类 | 选择非系统分类进行重命名、移动或删除。 |
| 新名称 | 重命名输入。 |
| 移动到 | 选择新的父分类；不能移到自己的子分类。 |
| 重命名 / 移动 / 删除 | 执行对应操作；系统分类不能重命名、移动或删除。 |

删除分类时，其子分类上移，笔记、实验和草稿移到父分类；没有父分类时移到未分类。分类名称会去除多余空白；空名称、超长名称、控制字符和循环父子关系会被拒绝。

### 搜索与列表

| 控件 | 作用 |
| --- | --- |
| 搜索标题、正文或假设 | 笔记搜索标题和正文；实验搜索标题、假设和笔记。 |
| 内容类型 | 全部、笔记、实验。 |
| 分类范围 | 全部分类或某个分类；选择父分类时包含其子分类。 |
| 查看回收站 | 切换正常内容与回收站。 |
| 选择内容 | 从结果中选择笔记或实验；显示“类型 · 标题”。 |
| 移动到分类 | 把当前内容移动到另一个分类。 |

结果按更新时间/创建时间倒序排列。没有结果时显示提示；正常视图下仍会显示新建笔记编辑器。

### 笔记

选择笔记后可以：

- 查看渲染后的 Markdown。
- 下载附件；下载时会校验附件的 SHA-256。
- “导出笔记与附件 ZIP”：包含 `note.md`、`attachments.json` 和 `attachments/` 下的原始附件。
- “编辑”：把笔记载入编辑器。
- 在正常视图中“移到回收站”。

### 笔记编辑器

| 控件 | 作用 |
| --- | --- |
| 笔记标题 | 必填；字段变化时自动保存草稿。 |
| 笔记分类 | 选择分类；变化时自动保存草稿。 |
| Markdown 正文 | 必填；变化时自动保存草稿。 |
| 添加附件 | 选择文件；支持图片、PDF、Word、Excel、PowerPoint、CSV、TXT、Markdown。 |
| 保存所选附件到草稿 | 把上传文件复制到托管资料目录；附件先写临时文件，再原子改名。 |
| 插入 | 对图片附件，在 Markdown 中插入 `attachment://附件ID` 标记；渲染时由受控组件显示。 |
| 保存笔记 | 把草稿保存为正式笔记；标题和正文不能为空。 |
| 新笔记 | 清空编辑器并创建新草稿。 |
| 放弃草稿 | 删除当前数据库草稿及其草稿附件，重置编辑器。 |
| Markdown 预览 | 预览正文和附件图片。 |

附件限制：

- 每个附件不超过 200 MB。
- 每篇笔记最多 20 个附件，总大小不超过 1 GB。
- 允许的扩展名：`png`、`jpg`、`jpeg`、`gif`、`webp`、`bmp`、`pdf`、`doc`、`docx`、`xls`、`xlsx`、`ppt`、`pptx`、`csv`、`txt`、`md`。
- 图片、PDF、Office 文件会校验文件头与扩展名是否匹配；文本附件必须是 UTF-8 编码。
- 附件保存在资料库的托管目录，不进入 SQLite BLOB；数据库记录相对路径、MIME、大小和 SHA-256。

草稿会自动保存到 SQLite：标题、正文和分类变化时写入数据库；编辑器还会在 WebView 本地存储保留一份输入镜像，用于页面重绘或重连时恢复尚未同步的输入。清除 WebView 本地存储不会删除 SQLite 已保存的草稿，只可能丢失尚未同步到 SQLite 的那部分输入。只有点击“放弃草稿”才会删除数据库草稿及其草稿附件；点击“保存笔记”才会把草稿转为正式笔记。

### 实验档案

选择实验后可以：

- 查看研究假设、市场、代码、名称、日期区间和审计指纹。
- “导出 Markdown 研究报告”：包含标题、假设、标的、区间、来源、复权、接收时间、实验时间、指纹、策略与成本 JSON、结果、学习笔记和复现说明。
- “导出可复现研究包 ZIP”：包含 `report.md`、`raw_history.csv`、`signal_history.csv` 和 `assumptions.json`。
- “从存档数据重新计算”：读取归档的两份行情快照，校验 SHA-256，使用原参数、成本和训练比例重新运行，并核对实验指纹。

复算只使用存档输入，不使用当前页面行情。若快照校验失败或复算指纹不一致，页面显示错误，不会用新行情替代归档。旧实验缺少名称时仍可打开，名称可能显示“名称暂不可用”；后来改名不会重写保存时的名称。

### 回收站

在正常视图点击“移到回收站”后，内容从默认列表消失。打开“查看回收站”可以：

- “恢复”：回到正常列表。
- “确认永久删除”复选框与“永久删除”按钮：永久删除笔记会删除其附件和草稿；永久删除实验会解除学习笔记与实验的关联。永久删除不可撤销。

## 推荐操作顺序

1. 打开“研究笔记”面板，先在“分类管理”创建一个顶层分类，例如“均线研究”。
2. 点击“新笔记”，填写标题、分类和 Markdown 正文；需要图片或资料时添加附件。
3. 点击“保存所选附件到草稿”，再点击“保存笔记”。确认列表出现该笔记。
4. 用“搜索标题、正文或假设”和“内容类型/分类范围”找到内容；需要调整分类时用“移动到分类”。
5. 到“历史回测”运行并保存实验，填写研究标题、假设和学习笔记。
6. 回到“研究笔记”，选择该实验，先点击“从存档数据重新计算”，确认指纹一致。
7. 再“导出可复现研究包 ZIP”，检查 `report.md`、两份 CSV 和 `assumptions.json`。
8. 不再需要的内容先“移到回收站”；确认无误后再永久删除。

## 一个可复现的小例子

1. 在“分类管理”中，父分类选“根目录”，分类名称填“均线研究”，点击“新增分类”。
2. 点击“新笔记”，标题填 `600519 双均线观察`，分类选“均线研究”，正文写：
   `假设：双均线 10/30 在样本外仍具有可观察的风险收益特征。下一步：用未参与调参的区间复核。`
3. 添加一张 PNG 截图，点击“保存所选附件到草稿”，再点击“保存笔记”。列表应出现该笔记；打开后能看到正文和图片。
4. 到“历史回测”保存一个实验，标题和假设非空，学习笔记写下你的判断。
5. 回到“研究笔记”，内容类型选“实验”，选择该实验。记录页面显示的审计指纹和日期区间。
6. 点击“从存档数据重新计算”。成功时应显示复算指纹；若与保存记录不一致，页面会报错。
7. 点击“导出可复现研究包 ZIP”。解压后检查：
   - `report.md` 是否包含假设、标的、区间、来源、复权、成本和指纹；
   - `raw_history.csv` 是否为不复权成交价格快照；
   - `signal_history.csv` 是否为信号价格快照；
   - `assumptions.json` 是否包含策略、成本、训练比例、来源、复权、市场和指纹。
8. 把笔记“移到回收站”，再打开“查看回收站”并“恢复”，确认内容回来；如果只是测试，最后不要勾选“确认永久删除”。

这个例子验证归档和复算流程，不说明实验收益或未来表现。

## 怎么判断结果是否有效

- 笔记只有在点击“保存笔记”后才进入正式列表；草稿自动保存不等于正式保存。标题和正文都非空。
- 附件下载成功且能打开；图片能通过 `attachment://` 标记显示；下载时 SHA-256 校验通过。附件类型、大小、文件头和文本编码符合限制。
- 实验详情中的市场、代码、名称、区间、来源、复权和指纹与保存时一致；旧实验名称缺失不影响读取。
- “从存档数据重新计算”成功且指纹一致；若失败，先检查快照校验和代码版本，不要用当前行情覆盖归档。
- ZIP 中的两份 CSV 是保存时的快照，不是当前查询；`assumptions.json` 与研究详情一致。
- 回收站中的内容不再出现在默认列表；恢复后回到原分类；永久删除前必须勾选确认。
- 私人笔记默认不发送给 AI；AI 回答保存为研究笔记时，内容仍需人工复核，并记录实际模型和来源。

## 常见错误与处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| “没有符合条件的笔记或实验” | 搜索词、内容类型、分类范围或回收站状态不匹配 | 清空搜索、切换内容类型或分类范围；检查是否在回收站视图。 |
| “笔记标题与内容不能为空” | 标题或正文为空 | 填写标题和正文后再保存。 |
| “附件类型不在安全白名单中” | 扩展名不在允许列表 | 转换为允许的格式；不要改扩展名绕过校验。 |
| “附件必须非空且不超过 200MB” | 空文件或单个文件过大 | 压缩或拆分文件；每篇笔记总大小不超过 1GB、最多 20 个附件。 |
| “附件内容与扩展名不匹配” | 文件头与扩展名不一致 | 使用真实格式；不要伪造扩展名。 |
| “文本附件必须使用 UTF-8 编码” | TXT/MD/CSV 不是 UTF-8 | 转换为 UTF-8 后重新上传。 |
| “同一父分类下已有同名分类” | 分类重名 | 换一个名称或移动父分类。 |
| “分类最多 8 层” | 分类层级过深 | 减少层级。 |
| “系统分类不能重命名/移动/删除” | 操作系统保留分类 | 在非系统分类中操作。 |
| “已保存的行情快照校验失败” | 数据库中的快照损坏或被改写 | 不要继续复算；保留错误信息，检查资料库备份。 |
| “复算指纹与保存记录不一致” | 代码版本变化、快照不一致或参数被改动 | 不覆盖原实验；记录代码提交和错误信息，交给 Codex 复核。 |
| “导出笔记与附件 ZIP”失败 | 附件文件缺失、SHA-256 不匹配或磁盘空间不足 | 检查附件是否被外部移动/修改；从备份恢复。 |
| 永久删除后无法恢复 | 已执行永久删除 | 永久删除不可撤销；只能从资料库备份恢复。 |
| 笔记草稿看起来丢失 | 清除了 WebView 本地存储，或输入尚未同步到 SQLite | SQLite 已保存草稿不会因清除 WebView 本地存储而删除；重新打开编辑器会加载最近草稿。清除 WebView 存储只可能丢失尚未同步的输入。“放弃草稿”才会删除数据库草稿和草稿附件；正式笔记不受影响。 |

## 数据、计算和适用边界

- 笔记、分类、草稿、附件和实验都保存在当前资料库；附件作为托管文件保存，不进入数据库 BLOB。数据库使用 `PRAGMA user_version` 管理迁移；旧库升级前备份，迁移失败回滚。
- 附件先写临时文件，再原子改名；记录相对路径、MIME、大小和 SHA-256。下载和导出时校验 SHA-256；校验失败不会静默返回损坏文件。
- 实验档案保存两份行情 CSV 快照、SHA-256、策略、成本、训练比例、来源、复权、接收时间、结果和审计指纹。复算只读归档输入，不使用当前行情；更新行情不会改写旧实验。
- 私人笔记和附件默认不附带给 AI；AI 上下文默认排除笔记、完整行情和数据库。不要把 Key 粘贴到笔记或附件。
- 笔记搜索是本地 SQLite 查询，不是语义搜索；搜索词按标题/正文/假设匹配，结果按更新时间排序。
- 当前没有云同步、多人协作、版本历史或自动备份到外部服务；资料库备份需要用户自行管理。永久删除不可撤销。
- 实验复算验证的是归档输入和参数能否重现同一指纹，不证明策略未来有效；回测边界见“历史回测”页。
- 本页不执行真实交易，不构成投资建议。
