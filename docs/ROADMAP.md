## 已锁定决定

- 学习与研究并重，高中数学、零 Python 基础，内容直接围绕量化金融。
- Academy 共 48 节（含原八课），专题目录与受控实验；不恢复打卡、进度和强制测验。每六节一批核验。
- Windows 桌面优先，克制的中性深色工作台；浏览器暂不单独适配。
- 先解决真实卡顿和阻塞，再做视觉统一；加载骨架屏扫光与计算提速分别验收。
- 历史 1/3/5/10 年及自定义，默认一年；实际覆盖与请求范围分别显示。
- 美股包含分析、回测和 USD 组合；零费用，可自行注册免费账号；来源、原始价、公司行动或许可不可靠时禁止相关区间回测。
- 优先多股票与组合终端，然后深化研究实验台。
- 保留 Python 单体、Streamlit、桌面入口、AI、笔记与旧实验；计算模块不依赖 UI。
- Claude 由用户自己启动，可在独立 worktree 接棒或分模块工作；不由 Codex 代调用。
- 没有打包、标签或 Release 授权；源码工作包按 AGENTS.md 验证并提交推送。

## 阶段与依赖

0 → 1 → 2 → 用户验收 → 3，后续各阶段同样设置用户验收关卡。以下依赖只表示技术上可拆分，不构成跨阶段或并行开工授权。课程按六节一批交付验收；需要并行时先由用户明确指定范围。阶段 5 依赖美股免费来源质量关卡，阶段 6 美股部分依赖 5，A/H 股终端不必等待美股。阶段 7 在终端后深化。

每阶段完成后交付：可运行源码提交、具体操作清单、实际验证结果、未达项。等待用户明确验收通过后，再启动下一阶段；用户要求修改则只修当前阶段。视觉方向“可以”仅批准设计稿，不代表实现已验收。当前界面源码为 f6a1dab；未验收的阶段3内容已本地备份及暂存隔离，未推送，不自动恢复，位置见 HANDOFF.md。

阶段 2 必须先提交市场、Academy、多股票三张可审查设计稿，用户确认后才全面铺开。阶段 1/2 两轮修复仍不达标且证据指向 Streamlit 限制时，只评估 React/TypeScript/Vite + 薄 FastAPI 隔离原型；整体迁移另确认。

阶段 3 维护来源、接收时间、币种、复权、覆盖、缺失重复异常和零成交量；分段与快照仅复用已校验数据，不拼接不同复权基准，不把无行情自动当停牌。

阶段 5 正常时段下一开盘模拟、只做多无杠杆整数股且只用已结算现金；历史结算规则版本化；拆股、分红应收及支付、同成本基准一致。不支持的并购分拆等事件阻断跨事件回测。所有免费源均不合格则只交付适配框架和离线验收，其他阶段继续。

阶段 6 支持 2–10 只同市场同币种、共同覆盖下的净值/回撤/滚动风险/相关性比较；核对现金、持仓、费用和样本外结果；保存学习/单股/多股预设。

阶段 7 增强成本与未成交解释、规则版本、换手和风险暴露；有界扫描、滚动样本外、成本压力；2–6 实验比较与完整离线复算报告。

## 内容与公共合同

课程统一包含目标、直觉、量化场景、公式单位、手算、交互实验、结果解释、误读、Python逐行说明、思考题展开答案及来源。教学数据不冒充行情，不执行任意代码。

内部接口：
- 任务：提交/查询/取消/结果，绑定会话和输入指纹；工作者不调用 Streamlit。
- 课程：稳定 ID、专题、先修、实验 ID，旧八课映射；course_id + parameters 返回教学结果。
- 数据：扩展覆盖/价格基准/质量/能力元数据，原 Provider 可读。
- 公司行动和市场规则独立、按日期版本化；未知不同于无事件。
- 新实验记录数据、规则、算法和指纹版本，旧档按旧算法复算。

SQLite 逐版本备份及事务迁移，失败回滚；不重写旧行情 BLOB 和指纹。Key 仅会话或 Windows 凭据管理器；付费 AI 仅明确发送。

## 统一验收

同一电脑、实际 WebView2、热状态每类至少 20 次：反馈 P95 ≤150ms，课程本地操作 ≤500ms，热切页 ≤800ms。网络单列，骨架屏不算提速。十年十股计算与导出使用完整数据。
实际 DOM 检查 1366×768、1920×1080、面板拖宽/最大化/焦点/滚动/各状态；测试副本使用独立资料目录与 AppId。
每个代码交付执行完整 pytest；断网/超时/限频/重复/取消/切查询/晚结果/失败保留均验证。金融新增计算有手算样本，所有新页面离线启动。
依赖或启动变更增加桌面检查；未构建时记录原因，不用源码启动替代安装包验收。
