# 研究方法与模型边界

阶段七新增[研究验证协议](RESEARCH_STAGE7.md)：固定训练扫描、逐折过去窗口选参/连续样本外执行、固定基础策略成本压力；新验证只用不复权信号，不免费重置持仓。费用拆解与原订单核对，滑点价差另列；换手=累计双边成交金额/平均日权益，暴露=持仓市值/权益。多个元组不等于独立经济假设，多次改网格/看测试仍可能过拟合。旧算法与指纹保留，新报告明确公司行动未知而非没有事件。

美股阶段五使用独立的[US_RULES v1](US_RULES.md)：原始价成交、只花已结算USD、独立结算日历、普通股息应收/支付与拆股持仓。均线只用已观察前缀的拆股调整，价格收益基准与含分红基准同成本分列。真实来源未通过完整关卡，因此当前只提供明确的教学验证；不更改以下A/H旧实验公式或指纹。

## 策略信号与回测成交

- 单均线：`close_t > MA_long,t`。双均线：`MA_short,t > MA_long,t`。趋势过滤：`close_t > MA_long,t` 且长均线正在上升。均线只使用当日及此前收盘价；不足周期的日期信号为 0。
- 收盘后形成的信号只能在**下一交易日开盘**尝试成交。策略只在现金与持股之间切换，不做空、不加杠杆。基准也在第二个交易日开盘买入，使用同一成本与成交规则。
- 买入量取用户设置交易单位的整数倍。A 股模型不允许同日买入后卖出，且在用户指定的简化涨跌停阈值处保守地视为无法成交；成交量为零也不成交。港股交易单位由用户核对并输入，本模型未模拟香港市场的波动调节机制。实际 A 股板块与特殊股票的申报单位、涨跌幅规则不同，不能靠股票代码自动推断；参阅[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、[港交所交易单位说明](https://www.hkex.com.hk/Global/Exchange/FAQ/Securities-Market/Trading/Securities-Market-Operations?sc_lang=en)与[波动调节机制说明](https://www.hkex.com.hk/Global/Exchange/FAQ/Securities-Market/Trading/VCM?sc_lang=en)。
- 买入成交价为 `open × (1 + 滑点基点/10000)`；卖出为 `open × (1 − 滑点基点/10000)`。单笔费用为 `max(最低佣金, 成交额 × 佣金基点/10000) + 成交额 × 对应附加费基点/10000`。页面默认值只是**可修改的研究假设**，不是当前法定税费或券商报价。

日线不能还原订单簿、实际队列、盘中停牌、不同板块上市初期的特殊规则、分红现金流和逐笔成交。输入的复权价格仅生成信号，不能作为成交价格。回测曲线不代表真实可实现收益。

## 指标

- 简单价格收益率：`P_end / P_start − 1`，不自动含分红。
- 累计净值收益率：`E_end / E_start − 1`。年化收益估计：`(E_end/E_start)^(252/观察间隔数) − 1`。
- 最大回撤：`min(E_t / max_{s≤t}(E_s) − 1)`。
- 日收益率样本标准差使用分母 `n−1`；年化波动率为 `std_daily × √252`。
- 夏普比率使用日超额收益均值与样本标准差，再乘 `√252`。日收益率方差为零时不显示夏普。默认无风险利率为零。

这里的 252 是年交易日近似值，不会自动适应每个市场、年份或个股停牌。

交易日覆盖核对使用版本化社区参考日历，按源响应接收时间判断是否已过参考收市时刻，不把本机再次读取时间当作新接收时间。A股XSHG、港股XHKG仅作日期参考；缺少记录、零成交量、日历不一致和源端截断都不直接证明停牌或上市状态。尚未收市或末日状态无法核验的当日日线不进入新的收盘信号/回测；旧档按其原算法复算。具体覆盖与未知状态见数据质量报告，不补造交易日价格。

长原始价分段的重叠记录必须逐字段一致；复权价整段获取。新复权研究使用“复权前检→原始价→复权后检”，对比当前图及两次复权指纹，并检查来源、币种和日期严格一致。发生修订、返回旧缓存或日期缺口时拒绝混用，不插值成交价格。输入配对清单v1记录各响应接收时间与SHA，不改变旧实验审计算法；它验证获取一致性，不证明复权因子、拆股或现金分红已经认证。

市场概览使用同一套样本波动和回撤定义，输入为当前价格口径的收盘序列。至少三条价格才显示样本年化波动，至少两条才显示价格最大回撤；常数序列波动为零，空样本和不足样本显示缺省值。非正、无效、无限价格或收益，以及风险计算溢出均明确报错。价格回撤不自动包含分红、拆股现金流或交易成本，不等同策略净值回撤。

## 样本内、样本外与组合

回测按日期切分样本内外，参数敏感性表**只计算样本内**。改变参数后仍需看样本外表现；反复查看样本外再调参数，也会造成过拟合。单只仍上市股票的历史样本不能消除幸存者偏差。

旧“风险与组合”简化模型要求2–4只同市场同币种，共同日内连接；等权`1/n`及逆波动率`(1/训练期标准差_i)`归一化，仅在样本外比较，假设每日固定权重再平衡，不计成本/现金/股息或汇率。该旧算法保留不改写。

阶段六新模型支持2–10只A/H同币种：比较以共同日期、起点100的价格净值、运行最高点回撤、样本相关和滚动样本波动为准；相对基准收益是期末标准化值之比减1。共同缺口可跨日，年化252仅近似，零波动相关性留空。现金模型不允许删除缺失成交日；用完整原始价收益的训练片段冻结等权/逆波动权重，从最后训练日现金状态起步，最早样本外首日正常开盘成交。费用/滑点、逐股单位和调仓进入现金及持仓核算，不计分红/送转或汇兑。公式、版本和限制见[PORTFOLIO_STAGE6](PORTFOLIO_STAGE6.md)，不把价格与成本模型说成总回报。

## 假设检验与机器学习

单样本 t 检验的零假设为“平均日收盘收益率为零”。其 p 值依赖近似独立等条件；金融收益的自相关、厚尾和多重检验会影响解释，p 值不是盈利概率。

线性回归特征为当日收盘后可知的 1 日/5 日收益、5/20 日均线差、成交量变化和 10 日波动率；标签是**次日收盘相对当日收盘**的收益率。训练/测试按时间排序，中间留一行间隔；标准化只在训练数据拟合，训练内部使用带间隔的时间序列交叉验证。页面比较模型 MAE 与恒预测零收益的基线，并显示 R² 与方向一致率。这个预测标签不能让研究者按当日收盘价成交。

## AI 研究助手

未配置用户自己的 API Key 时，平台仍可运行固定模板的受控实验。配置后，模型可以草拟有界的内置策略参数、说明文字和仅供阅读的示例代码。模型**不能执行任意代码、下单或修改文件**。报告旁的数值与实验指纹由本地函数计算，AI 文字可能出错，必须与原始数据、参数、计算公式和样本外结果交叉核对。研究页共用侧栏 DeepSeek 连接，按 [DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode/) 取 JSON 后验证字段类型、策略类别与周期边界；JSON 格式正确不代表研究判断正确。
