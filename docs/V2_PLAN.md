## P1 模块与数据结构

- `guidance.py`：真实页面教程、四条路径及先修引用、八项任务、七层课程结构、练习与可复用教学实验。内容不导入 Streamlit。
- `learning_store.py`：进度、测验记录、学习目标、实验完成记录；沿用 SQLite 连接、脱敏与用户数据目录。
- `ui_guidance.py`：主导航学习中心、首次欢迎、可跳过/重启引导、统一页面帮助、回到研究任务、交互课程/测验、进度/笔记/目标与显式重置。
- schema v3：追加 `learning_progress` 与 `learning_quiz_attempts`；已有 `learning_notes` 复用。迁移前备份、事务升级与失败回滚，不重写任何行情 BLOB 或旧指纹。
- 使用原生 Streamlit 回调导航，保护研究控件状态；新手/专业模式复用 `learning_mode`，不参与计算。
- 仅使用现有 DeepSeek 侧栏，增加研究解释/教学辅导选项。发送上下文限当前指南/课程、已核对统计或回测摘要；练习答案、目标、私人笔记、整表不自动发送。点击解释只生成草稿，显式发送才请求 API。

任务 1/2/5/6/8 分别以真实选择事件、成功验证的非演示行情、有效策略信号、成功本地回测、成功保存实验为证据；3/4/7 用明确学习确认或练习验证。进度是历史完成记录，不证明当前股票数据有效。失败、空结果、代码位数和默认值均不能伪造完成。
