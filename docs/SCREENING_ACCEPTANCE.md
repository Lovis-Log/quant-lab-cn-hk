# 批量条件选股操作与验收

入口：市场数据→批量选股；左侧选择市场和日期，本页选择筛选口径、自选/手动候选，最多20只。选择条件后点“应用条件”设置上下限，再点“运行筛选”；“立即更新并筛选”绕过查询缓存并替换当前批次。所有已启用条件须同时满足。结果显示逐股失败、质量和来源，表格可横向滚动查看全部字段。

命名方案可保存/覆盖、加载、删除；只存条件、候选及排序，不保存日期或行情。加载后按当前日期手动重新运行。勾选命中股票一只进入行情/回测，2–10只进入比较，不自动取数、计算或加入自选；目标页“返回筛选结果”恢复条件、日期和结果。取消批次停止安排后续股票，已发送请求仍可能结束，但晚结果不会发布。

## 边界

仅候选池筛选，不扫描全市场、不提供实时行情或实盘下单。不新增公司行动核算、来源授权或行情持久化资格。原自选股及多股比较仍最多10只，筛选20只上限独立。停牌/上市/数据缺口原因未知时不推断身份，名字失败仅显示名称暂不可用。
