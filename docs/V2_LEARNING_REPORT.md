# V2 开发学习报告

这次交付的是可使用的 Learning Center MVP。四条学习路径提供结构，八节已有实验升级为七层课程与测验；没有把全部金融、数学、Python 或机器学习课程冒充成已完成。下一阶段计划见 `V2_PLAN.md`。

## 金融：用不同指标回答不同问题

收益率 `P₁/P₀−1` 描述首尾比例；复利是每期乘上 `1+r`。本金 200 先涨 10% 再跌 10% 得 198，因为两次计算的基数不同。价格收益没有自动含股息和交易摩擦；用不同复权序列得到的收益不能直接视为同一研究对象。

波动率描述日收益围绕均值的起伏，最大回撤描述相对过去峰值的最深下跌，夏普描述单位历史波动对应的平均超额收益。这三个指标不相互替代：100→120→90→100 的最终收益是 0、最大回撤是 −25%；净值能回到起点也经历了显著损失。最高净值只取当前及过去，不能先读未来最高点。

相关系数用于描述两个同日收益序列的线性共同变化。`[1,2,3]` 与 `[6,4,2]` 相关为 −1；这不证明因果，也不保证未来关系。组合页必须同市场、同币种、日期对齐，其逆波动权重只用训练期；目前日再平衡曲线未计调仓成本，不能解释成可实现收益。

验证方式：先在纸上写输入、公式、单位和结果，再在课程中调一个参数。最后返回真实研究页核对相同口径；不要用教学样本替代股票行情。

## 数学与统计：尺度、分母与假设

样本均值是数据中心；样本方差 `Σ(x−x̄)²/(n−1)` 描述离散程度，标准差开平方恢复原单位。1、3、5 的均值 3，平方偏差和 8，样本方差 4、标准差 2。金融日收益用小数，1%=0.01；方差单位是收益率的平方，不能直接读成百分比。

年化波动 `s_daily√252` 是近似，假设时间尺度关系适用，252 是研究用年交易日约数。日标准差 2% 时约 31.749%；自相关、厚尾、非平稳和停牌会削弱近似。夏普分母为零或近零时不能报告无穷大，高夏普也不等于盈利保证。

t 检验的零假设是平均日收益为 0；p 值是零假设及相关条件下数据极端程度的证据，不是股价上涨概率。反复查看许多股票或窗口再只汇报小 p 值，会带来多重检验偏差。

实际回归使用当日收盘后已知的 1/5 日收益、5/20 日均线比值减 1、成交量变化和 10 日波动，预测下一交易日收盘收益。标准化器仅拟合训练样本；按日期切分并留一行间隔，训练期内进行 3 折时间序列验证。验证集帮助检验训练过程，最终测试集应保持不参与参数选择；看过测试结果再调参会失去独立性。

MAE 的量纲与标签相同，1% 表示日收益预测平均差 1 个百分点。先比较每天预测 0 的基线；R² 使用测试样本均值作为参考，可以为负。方向一致率只比较符号，没计幅度或成本。预测下一日收盘收益与下一日开盘才能成交的策略目标不同，需要单独执行回测。

## Python：数据与界面的边界

`guidance.py` 用冻结 dataclass 和稳定 ID 管理指南、课程、任务与引用。学习路径共享同一课程 ID，使“数学中的相关”与“金融中的相关”共用进度；图结构测试检查引用有效和先修关系无环。计划中节点使用明确空课程引用，不提供虚假的完成按钮。

`learning.py` 的纯函数返回教学 DataFrame 和解释，`ui_guidance.py` 用滑块、Plotly、表单展示，不让计算模块导入 Streamlit。已有金融计算函数继续复用，专业模式只减少提示，不修改输入或公式。测验由本地数值检查，不靠 AI 判断学生掌握。

原生导航回调在控件创建前修改导航状态；研究控件使用显式 key，并在页面切换时保护会话值。查看指南后返回，不丢掉成本、窗口和未保存判断。会话保留不等于重启后的数据恢复；长期学习记录靠 SQLite，研究恢复靠归档输入。

## SQLite：迁移、记录与复现

schema v3 追加进度表（类别＋项目 ID 为主键）和测验尝试表。课程实验、指南阅读、任务证据、目标与恢复位置使用进度记录；每次测验追加尝试，不覆盖历史。私人笔记复用原有表，金融实验的行情 BLOB 与指纹保持原样。

升级前使用 SQLite backup 获取一致性备份；`BEGIN IMMEDIATE` 中执行结构升级和版本更新，异常时回滚。测试故意在创建新表后抛异常，确认版本和旧笔记不变。这比删除数据库重建更能保护用户研究。

重置仅删除学习进度和测验，并保留首次欢迎偏好；保留研究快照、学习笔记、设置与密钥。保存失败在界面显示，不用临时勾选状态冒充持久化成功。API Key 仍仅在会话或 Windows 凭据管理器，显式笔记和目标写入也脱敏。

## 软件架构与 AI

保持模块化单体：内容模型、进度服务、金融计算、Streamlit UI、DeepSeek 客户端、桌面启动器各有职责。将来 FastAPI 可调用相同服务，而不复制公式或另建存储。

现有 DeepSeek 增加研究解释与教学辅导两种提示策略；知识按钮只准备草稿，付费请求仍需明确发送。上下文使用白名单里的当前课程/指南、教学参数与结论、统计评价或回测审计摘要。对话按数据指纹、实验、课程和模式隔离；不附带练习答案、学习目标、私人笔记、整表或数据库。AI 解释仍必须与程序事实核对，不承担计算、实盘下单或代码执行。

## 你可以亲自完成的验证练习

1. 在回撤课程把低点从 90 调到 80，先手算峰值 120 下的回撤，再解释“回本涨幅”为什么不同于下跌幅度；保存实验和测验。
2. 写一个只接收 Series 的函数计算 `equity/equity.cummax()-1`，用 100、120、90、100 与零波动样本核对已有测试，别导入 Streamlit。
3. 用小数据建立特征日期、标签日期表，故意错位一次；写断言保证所有训练标签早于测试特征边界。解释为何全样本标准化会偷看未来。
4. 用测试临时库读取 `PRAGMA user_version`、查看进度和测验表，再练习失败事务回滚。不要直接编辑自己的真实研究库。
5. 跟踪一项任务从按钮成功 → 证据校验 → SQLite → 重启恢复。尝试空数据和 API 失败，确认它们不能变成已完成状态。
6. 选一个从未用于选参的新区间，预先写下均线假设与费用，再运行和保存。即使失败也保留结果，比较 MAE、风险与基准，而不只追求最好收益。

这些练习的价值是训练可检查的推理与数据边界；不能靠完成测验、得到高 R² 或让 AI 赞同来证明策略具有未来盈利能力。
