# 批准多股票设计稿与阶段六实现

参考：comparison-concept-v1.png，已随三稿获用户确认。实施使用既有中性背景/表面/边线、蓝/琥珀/灰色及中文/数字令牌，没有新建视觉路线或复制概念图中的收益数字。

原生界面保留当前导航和顶栏；市场移到侧栏，与现有平台研究方式一致，解决表单内动态市场/代码与紧凑主区的冲突。日期与统一口径一行，代码与加载动作一行，高级基准/窗口折叠；首屏优先曲线。2–10只取代旧概念图中的最多5只，以锁定计划为准，10只图例简写代码、悬停显示名称。

主体为大幅标准化价格图、下方回撤/滚动波动页签、右侧相关性与下方风险表；窄空间允许相关区换行。数据全部来自计算；相关性使用类别轴Heatmap，10只不挤入固定HTML数字单元格，零波动留空。图表同查询保持缩放，隐藏风险页签不绘图。

现金表与观察表保持原生可核对表格，现金高级参数和流水默认折叠，预设按钮使用足宽文字以避免窄侧栏省略。当前与批准稿背景、控件高度、信息层级、价格/回撤/相关性结构、颜色、表格、空/等待/失败状态均实际检查；两种尺寸都使用真实WebView2。长页滚动与控件原生边距不同于1600像素概念，不声称逐像素复制或整体性能已达标。
