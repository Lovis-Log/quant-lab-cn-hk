# 已批准视觉的实现约定

批准：2026-10-27，用户回复“可以”。恢复点：aae6f97；恢复分支 codex/recovery-approved-design-20261027-aae6f97。

## 设计系统

- 应用底色 #151719，表面 #1C1F22，较深导航 #181B1E，边线 #303438。
- 主文字 #E8EBEE，次文字 #929AA3，强调 #78A7DB；涨 #D7797E、跌 #73B798，仅用于金融方向语义。辅助比较采用灰 #A8B3BF 与琥珀 #C6A56D。
- Windows 本地字体 Microsoft YaHei UI / Microsoft YaHei / Segoe UI；数字启用 tabular-nums。正文 14–15px，阅读区 15px/1.8，主标题 24px，分区 17px，控件 13–14px，表格 13px。
- 顶栏 52px；左栏默认约 248px，可继续调宽；内容水平内边距 24px。面板、表格和图表使用 4px 圆角及一层细边框，不叠加卡片。
- 主图约 420px 高、量价共用日期轴；学院教学图约 300px，图形和数值均由函数生成。
- 原生控件保持可访问名称、焦点和键盘行为；使用已捆绑 Material 图标和文字，不增加图像按钮或外部字体请求。

## 页面与状态

- 市场：小标题与来源信息；一行四个紧凑指标；量价图为主，字段口径按需查看；数据表保留完整导出。原有最高/最低信息仍可查阅。
- 学院：目录/搜索与正文分栏；直觉、公式、手算在前；参数、图表、结果/明细在中；Python 和进一步解释展开阅读；前后课及手册入口在末尾。当前八课按实际可用专题组织，不添加空课程。
- 各研究页采用同一控件、图表、表格与提示样式，保留所有已实现功能。多股票比较稿的完整工作区在任务26交付，不提前展示伪结果或无效控件。
- 首次加载保留骨架；刷新保留旧结果；未知、空、错误与成功有清楚文案。状态颜色只是辅助，文字不可省略。

## 空间与交互

- 至少保留主工作区 560px。多个辅助面板的合计期望宽度超出空间时，显示最近主动打开的一个，其余仍可从顶栏切换；空间恢复后可并排。
- 顶栏按钮打开/切换相应面板，再次点击当前面板可收起；标题栏关闭与最大化继续工作。拖宽时不播放宽度过渡动画，结束后保存非敏感偏好。
- 不删改计算、数据来源、付费请求触发方式、档案、指纹、凭据及交易假设。必要的页面差异记录在验收偏差表中。

## 视觉验收

实际 WebView2 在 1366×768 与 1920×1080 检查：背景与图表统一、排版层次、紧凑指标行、目录阅读、面板收纳、控件状态与焦点、空/错误/加载。读取设计稿与最新桌面截图逐项对照，记录原生控件和现阶段功能造成的差异。
